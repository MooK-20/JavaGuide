บทที่ 7

Object-Oriented Programming (OOP)

7.1 ความรู้เบื้องต้นเกี่ยวกับ Object-Oriented Programming

Object-Oriented Programming หรือ OOP คือแนวคิดในการเขียนโปรแกรม ที่มองข้อมูลและการทำงานเป็นวัตถุหรือ Object โดยแต่ละ Object จะมีข้อมูล และพฤติกรรมที่เกี่ยวข้องกันอยู่ภายใน

ภาษา Java เป็นภาษาที่สนับสนุนแนวคิด OOP อย่างเต็มรูปแบบ ทำให้สามารถสร้างโปรแกรม ที่มีโครงสร้างชัดเจน สามารถนำกลับมาใช้ใหม่ และง่ายต่อการดูแลรักษา

  • อธิบายความแตกต่างระหว่าง Class และ Object ได้
  • สร้าง Class ในภาษา Java ได้
  • สร้างและเรียกใช้งาน Object ได้

  • ใช้ Encapsulation เพื่อควบคุม การเข้าถึงข้อมูลได้
  • อธิบายแนวคิด Inheritance, Polymorphism และ Abstraction ได้

7.2 Class คืออะไร?

Class คือโครงสร้างหรือแบบพิมพ์เขียว ที่ใช้กำหนดคุณสมบัติและพฤติกรรมของ Object

ภายใน Class สามารถประกอบด้วยตัวแปร ซึ่งเรียกว่า Attributes หรือคุณสมบัติ และเมธอด ซึ่งใช้กำหนดการทำงานของ Object

📌 ตัวอย่างแนวคิด

หากต้องการสร้างโปรแกรมสำหรับจัดการข้อมูลนักเรียน สามารถสร้าง Class ชื่อ Student เพื่อกำหนดข้อมูล เช่น ชื่อ อายุ และคะแนน รวมถึงกำหนดเมธอดสำหรับแสดงข้อมูลนักเรียน

โครงสร้างพื้นฐานของ Class 

class Student {

    String name;
    int age;

    void showInfo() {

        System.out.println("ชื่อ: " + name);
        System.out.println("อายุ: " + age);

    }

}

public class Mainn {

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "สมชาย";
        student.age = 20;

        student.showInfo();

    }

}
ตัวอย่าง

จากตัวอย่าง Class Student มีตัวแปร name และ age สำหรับเก็บข้อมูล และมีเมธอด showInfo() สำหรับแสดงข้อมูล

7.3 Object คืออะไร?

Object คือสิ่งที่ถูกสร้างขึ้นจาก Class โดย Class เปรียบเสมือนแบบพิมพ์เขียว ส่วน Object คือสิ่งที่สร้างขึ้นตามแบบพิมพ์เขียวนั้น

Class
แบบพิมพ์เขียว
→
Object
สิ่งที่สร้างขึ้น

การสร้าง Object 

class Student {

    String name;
    int age;

    void showInfo() {

        System.out.println("ชื่อ: " + name);
        System.out.println("อายุ: " + age);

    }

}

public class Mainn {

    public static void main(String[] args) {

        Student student1 = new Student();

        student1.name = "สมชาย";
        student1.age = 20;

        student1.showInfo();

    }

}

คำสั่ง new Student() ใช้สร้าง Object จาก Class Student และตัวแปร student1 ใช้สำหรับอ้างอิง Object ที่สร้างขึ้น

ตัวอย่าง
✅ ผลลัพธ์ตัวอย่าง

ชื่อ: สมชาย
อายุ: 20

7.4 Attributes หรือคุณสมบัติของ Object

Attribute คือ ตัวแปรที่อยู่ภายใน Class และใช้เก็บข้อมูลหรือสถานะของ Object

ตัวอย่างเช่น Class Student อาจมี Attribute สำหรับเก็บชื่อ อายุ และคะแนนของนักเรียน 

class Student {

    String name;
    int age;
    double score;

}

public class Mainn {

    public static void main(String[] args) {

        Student student1 = new Student();

        student1.name = "สมชาย";
        student1.age = 20;
        student1.score = 85.5;

        System.out.println("ชื่อ: " + student1.name);
        System.out.println("อายุ: " + student1.age);
        System.out.println("คะแนน: " + student1.score);

    }

}
ตัวอย่าง
Attribute ชนิดข้อมูล หน้าที่
name String เก็บชื่อของนักเรียน
age int เก็บอายุ
score double เก็บคะแนน

7.5 Method หรือพฤติกรรมของ Object

Method คือ ชุดคำสั่งที่กำหนดพฤติกรรม หรือการทำงานของ Object

Method สามารถรับข้อมูลเข้ามาประมวลผล และสามารถส่งค่าผลลัพธ์กลับไปได้ ขึ้นอยู่กับรูปแบบของ Method

ตัวอย่าง Method 

class Calculator {

    int add(int a, int b) {

        return a + b;

    }

}

public class Mainn {

    public static void main(String[] args) {

        Calculator calculator = new Calculator();

        int result = calculator.add(10, 20);

        System.out.println("ผลบวก: " + result);

    }

}
ตัวอย่าง

Method add() รับตัวเลขจำนวนเต็ม 2 ค่า แล้วนำมาบวกกัน จากนั้นส่งผลลัพธ์กลับด้วยคำสั่ง return

7.6 Constructor

Constructor คือเมธอดพิเศษที่ใช้กำหนดค่าเริ่มต้น ให้กับ Object ในขณะที่ Object ถูกสร้างขึ้น

Constructor จะมีชื่อเหมือนกับชื่อ Class และไม่มีการระบุชนิดข้อมูลที่ส่งกลับ

ตัวอย่าง Constructor 

class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;

    }

}
ตัวอย่าง

การเรียกใช้ Constructor 

Student student1 =
    new Student("สมชาย", 20);
💡 Constructor จะถูกเรียกโดยอัตโนมัติ เมื่อมีการสร้าง Object ด้วยคำสั่ง new

7.7 คำสั่ง this

คำว่า this ใช้สำหรับอ้างอิงถึง Object ปัจจุบันที่กำลังทำงานอยู่

มักพบการใช้ this เมื่อชื่อ Parameter และชื่อ Attribute มีชื่อเหมือนกัน 

class Student {

    String name;

    Student(String name) {

        this.name = name;

    }

}

public class Mainn {

    public static void main(String[] args) {

        Student student1 =
            new Student("สมชาย");

        System.out.println(
            "ชื่อ: " + student1.name
        );

    }

}
ตัวอย่าง

this.name หมายถึง Attribute ของ Object ส่วน name หมายถึง Parameter ที่ส่งเข้ามาใน Constructor

7.8 Encapsulation

Encapsulation หรือการห่อหุ้มข้อมูล เป็นแนวคิดที่ใช้ควบคุมการเข้าถึงข้อมูลภายใน Object เพื่อป้องกันการแก้ไขข้อมูลโดยตรงจากภายนอก

ในภาษา Java มักใช้ private เพื่อจำกัดการเข้าถึง Attribute และใช้ Method เช่น getter และ setter สำหรับเข้าถึงหรือแก้ไขข้อมูล

ตัวอย่าง Encapsulation 

class Student {

    private String name;

    public void setName(String name) {

        this.name = name;

    }

    public String getName() {

        return name;

    }

}


public class Main {

    public static void main(String[] args) {

        Student student1 = new Student();

        student1.setName("สมชาย");

        System.out.println("ชื่อนักเรียน: " + student1.getName());

    }

}
ตัวอย่าง
📌 หลักการสำคัญ

private ใช้ป้องกันการเข้าถึงข้อมูลโดยตรง
setName() ใช้กำหนดหรือแก้ไขข้อมูล
getName() ใช้เรียกดูข้อมูล

7.9 Inheritance

Inheritance หรือการสืบทอด เป็นแนวคิดที่ทำให้ Class หนึ่งสามารถสืบทอด Attribute และ Method จากอีก Class หนึ่งได้

Class ที่ถูกสืบทอดเรียกว่า Superclass ส่วน Class ที่สืบทอดเรียกว่า Subclass

ตัวอย่าง Inheritance 

class Animal {

    void eat() {

        System.out.println("กำลังกินอาหาร");

    }

}


class Dog extends Animal {

    void bark() {

        System.out.println("สุนัขกำลังเห่า");

    }

}


public class Mainn {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.eat();

        dog.bark();

    }

}
ตัวอย่าง

Class Dog ใช้คำสั่ง extends เพื่อสืบทอดความสามารถจาก Class Animal

7.10 Polymorphism

Polymorphism หรือพหุรูป เป็นแนวคิดที่ช่วยให้ Object สามารถแสดงพฤติกรรมที่แตกต่างกันได้ แม้จะใช้ชื่อ Method เดียวกัน

ตัวอย่างการ Override Method 

class Animal {
    void sound() {
        System.out.println("สัตว์ส่งเสียง");
    }
}
class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("โฮ่ง โฮ่ง");
    }
}
public class Mainn {
    public static void main(String[] args) {
        Animal animal = new Animal();
        animal.sound();
        Dog dog = new Dog();
        dog.sound();
    }
}
ตัวอย่าง

Class Dog ทำการ Override Method sound() ที่ได้รับมาจาก Class Animal เพื่อให้มีการทำงานที่เหมาะสมกับ Dog

7.11 Abstraction

Abstraction หรือการซ่อนรายละเอียด เป็นแนวคิดที่เน้นเฉพาะสิ่งสำคัญ และซ่อนรายละเอียดของการทำงานที่ไม่จำเป็น จากผู้ใช้งาน

Java สามารถสร้าง Abstraction ผ่าน abstract class และ interface

ตัวอย่าง Abstract Class 

abstract class Animal {

    abstract void sound();

}


class Dog extends Animal {

    @Override
    void sound() {

        System.out.println("โฮ่ง โฮ่ง");

    }

}


public class Mainn {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();

    }

}

7.12 Access Modifier

Access Modifier คือ ตัวกำหนดระดับการเข้าถึง Class, Attribute และ Method ภายในโปรแกรม Java

Access Modifier ความหมาย
public สามารถเข้าถึงได้จากส่วนต่าง ๆ ของโปรแกรมตามขอบเขตของ Java
private เข้าถึงได้ภายใน Class เดียวกัน
protected ใช้ควบคุมการเข้าถึงภายใน Class และ Class ที่เกี่ยวข้องตามกฎของ Java
default สามารถเข้าถึงได้ภายใน Package เดียวกัน

7.13 static

คำว่า static ใช้กำหนดสมาชิกของ Class ที่สามารถใช้งานร่วมกันได้โดยไม่จำเป็นต้องสร้าง Object ใหม่สำหรับสมาชิกนั้น

ตัวอย่าง static Variable 

class Counter {

    static int count = 0;

}

7.14 ตัวอย่างโปรแกรม OOP

ตัวอย่างต่อไปนี้แสดงการสร้าง Class การสร้าง Object การกำหนด Attribute และการเรียกใช้งาน Method 

class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;

    }

    void showInfo() {

        System.out.println("ชื่อ: " + name);
        System.out.println("อายุ: " + age);

    }

}


public class Main {

    public static void main(String[] args) {

        Student student =
            new Student("สมชาย", 20);

        student.showInfo();

    }

}
ตัวอย่าง
✅ ผลลัพธ์

ชื่อ: สมชาย
อายุ: 20

7.15 หลักการสำคัญของ OOP

หลักการ ความหมาย
Encapsulation การห่อหุ้มและควบคุมการเข้าถึงข้อมูล
Inheritance การสืบทอดคุณสมบัติและพฤติกรรม จาก Class อื่น
Polymorphism การที่ Method หรือ Object สามารถมีรูปแบบการทำงานที่แตกต่างกันได้
Abstraction การซ่อนรายละเอียดที่ไม่จำเป็น และแสดงเฉพาะส่วนสำคัญ

7.16 ข้อควรระวังในการเขียนโปรแกรมแบบ OOP

⚠️ ข้อควรระวัง

1. ควรตั้งชื่อ Class ให้สื่อความหมาย
2. ควรตั้งชื่อ Attribute และ Method ให้เข้าใจหน้าที่ของตัวแปรหรือเมธอด
3. ควรกำหนด Access Modifier ให้เหมาะสมกับข้อมูล
4. ไม่ควรเปิดเผยข้อมูลภายใน Object โดยไม่จำเป็น
5. ควรแบ่ง Class ตามหน้าที่ เพื่อให้โปรแกรมดูแลรักษาได้ง่าย

7.17 สรุปบทเรียน

OOP คือแนวคิดการเขียนโปรแกรม ที่จัดข้อมูลและพฤติกรรมให้อยู่ในรูปแบบ Object

Class คือแบบพิมพ์เขียว สำหรับสร้าง Object

Object คือสิ่งที่สร้างขึ้นจาก Class

Attribute ใช้เก็บข้อมูลหรือสถานะ ของ Object

Method ใช้กำหนดพฤติกรรม หรือการทำงานของ Object

Constructor ใช้กำหนดค่าเริ่มต้น ให้กับ Object

Encapsulation ใช้สำหรับห่อหุ้ม และควบคุมการเข้าถึงข้อมูล

Inheritance ใช้สำหรับการสืบทอด คุณสมบัติและพฤติกรรมจาก Class อื่น

Polymorphism ช่วยให้ Object สามารถมีพฤติกรรมที่แตกต่างกันได้

Abstraction ใช้ซ่อนรายละเอียด และแสดงเฉพาะส่วนสำคัญ

7.18 ☕ ความรู้เพิ่มเติม

🔹 OOP เหมาะกับโปรแกรมแบบใด?

OOP เหมาะกับโปรแกรมที่มีข้อมูล และการทำงานหลายส่วนที่เกี่ยวข้องกัน เช่น ระบบร้านค้า ระบบจัดการนักเรียน ระบบธนาคาร ระบบโรงพยาบาล และโปรแกรม GUI

🔹 Class และ Object ต่างกันอย่างไร?

Class เปรียบเสมือนแบบพิมพ์เขียว ส่วน Object คือสิ่งที่ถูกสร้างขึ้น ตามแบบพิมพ์เขียวนั้น

🔹 ทำไมต้องใช้ OOP?

การใช้ OOP ช่วยให้สามารถแบ่งโปรแกรม ออกเป็นส่วน ๆ ตามหน้าที่ ทำให้โครงสร้างโปรแกรมเป็นระบบ และสามารถนำส่วนต่าง ๆ กลับมาใช้งานใหม่ได้
