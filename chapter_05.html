บทที่ 5

การสร้างและใช้งาน Methods

1. ความรู้พื้นฐานเกี่ยวกับ Method

1.1 ความหมายของ Method

Method หรือ เมธอด คือกลุ่มคำสั่งที่ถูกรวบรวมไว้ภายใน Class เพื่อทำหน้าที่อย่างใดอย่างหนึ่งโดยเฉพาะ เมธอดช่วยแบ่งโปรแกรมที่มีขนาดใหญ่ให้เป็นส่วนย่อย ๆ ทำให้สามารถอ่าน ทำความเข้าใจ แก้ไข และนำกลับมาใช้งานซ้ำได้ง่ายขึ้น

ในภาษา Java เมธอดจะทำงานเมื่อมีการเรียกใช้งาน โดยสามารถรับข้อมูลเข้ามาผ่าน Parameters และสามารถส่งค่ากลับออกไปด้วยคำสั่ง return ได้

การใช้ Method เป็นแนวทางสำคัญในการจัดโครงสร้างโปรแกรม เพราะช่วยแยกขั้นตอนการทำงานที่มีความซับซ้อนออกจากกัน เช่น โปรแกรมคำนวณคะแนนอาจแยก Method สำหรับคำนวณคะแนนรวม Method สำหรับคำนวณคะแนนเฉลี่ย และ Method สำหรับแสดงผล แต่ละ Method จะรับผิดชอบหน้าที่ของตนเอง ทำให้โปรแกรมมีความเป็นระเบียบและตรวจสอบการทำงานได้ง่ายขึ้น

Method สามารถถูกเรียกใช้งานได้มากกว่าหนึ่งครั้ง และในการเรียกแต่ละครั้งสามารถส่งข้อมูลที่แตกต่างกันเข้าไปได้ จึงช่วยลดการเขียนคำสั่งเดิมซ้ำหลายครั้ง ตัวอย่างเช่น Method สำหรับแสดงข้อความต้อนรับ สามารถนำไปใช้กับผู้ใช้งานหลายคน โดยเปลี่ยนข้อมูลที่ส่งผ่าน Parameters แทนการเขียนคำสั่งใหม่สำหรับแต่ละคน

1.2 ความสำคัญของ Method

Method เป็นส่วนสำคัญในการออกแบบโปรแกรมภาษา Java เนื่องจากช่วยแบ่งการทำงานของโปรแกรมออกเป็นส่วน ๆ แต่ละ Method สามารถรับผิดชอบงานเฉพาะด้าน ทำให้โครงสร้างของโปรแกรมมีความชัดเจนมากขึ้น

เมื่อโปรแกรมมีขนาดใหญ่ขึ้น การเขียนคำสั่งทั้งหมดไว้ภายใน main() เพียงส่วนเดียวจะทำให้โปรแกรมมีความยาวมาก และยากต่อการตรวจสอบหรือแก้ไข การนำ Method มาแบ่งการทำงานจึงช่วยให้ผู้เขียนโปรแกรม สามารถมองเห็นขั้นตอนการทำงานแต่ละส่วนได้อย่างชัดเจน

นอกจากนี้ Method ยังช่วยให้การบำรุงรักษาโปรแกรมทำได้สะดวก หากต้องการแก้ไขการทำงานของส่วนใด สามารถแก้ไขคำสั่งภายใน Method ที่เกี่ยวข้อง โดยไม่จำเป็นต้องแก้ไขคำสั่งในทุกจุดที่มีการเรียกใช้งาน

💡 แนวคิดสำคัญ

Method คือชุดคำสั่งที่สร้างขึ้นเพื่อทำงานเฉพาะอย่าง เช่น คำนวณผลรวม แสดงข้อความ ตรวจสอบข้อมูล หรือคำนวณคะแนน และสามารถเรียกใช้ซ้ำได้หลายครั้ง

1.3 ประโยชน์ของ Method

  • ลดการเขียนคำสั่งซ้ำ
  • ทำให้โปรแกรมอ่านและทำความเข้าใจง่ายขึ้น
  • แบ่งโปรแกรมขนาดใหญ่ออกเป็นส่วนย่อย
  • ช่วยให้แก้ไขและบำรุงรักษาโปรแกรมได้ง่าย
  • สามารถนำชุดคำสั่งกลับมาใช้งานซ้ำได้

การออกแบบ Method ที่ดีควรให้แต่ละ Method มีหน้าที่ที่ชัดเจน และไม่ควรให้ Method หนึ่งทำงานหลายอย่างที่ไม่เกี่ยวข้องกันมากเกินไป เพราะการแบ่งหน้าที่อย่างเหมาะสมจะช่วยให้สามารถนำ Method ไปใช้งานซ้ำและทดสอบการทำงานได้ง่าย

การใช้ Method ยังช่วยให้การพัฒนาโปรแกรมเป็นระบบมากขึ้น โดยผู้เขียนโปรแกรมสามารถออกแบบโครงสร้างการทำงานก่อน แล้วจึงสร้าง Method สำหรับแต่ละขั้นตอน วิธีนี้เหมาะกับโปรแกรมที่มีหลายส่วนและมีขั้นตอนการทำงานต่อเนื่องกัน

1.4 องค์ประกอบของ Method

Method ในภาษา Java โดยทั่วไปประกอบด้วย ตัวกำหนดการเข้าถึง ชนิดข้อมูลที่ส่งกลับ ชื่อ Method Parameters และชุดคำสั่งภายใน Method

ตัวกำหนดการเข้าถึง เช่น public หรือ private ใช้กำหนดขอบเขตในการเข้าถึง Method ส่วน return type ใช้ระบุชนิดข้อมูลที่ Method จะส่งกลับ หาก Method ไม่มีค่าที่ส่งกลับจะใช้คำว่า void

ชื่อ Method ควรสื่อความหมายถึงหน้าที่ของ Method เช่น calculateTotal() ใช้สำหรับคำนวณยอดรวม หรือ showMessage() ใช้สำหรับแสดงข้อความ การตั้งชื่อที่สื่อความหมายช่วยให้ผู้ที่อ่านโปรแกรมเข้าใจการทำงาน ได้โดยไม่จำเป็นต้องเปิดดูคำสั่งภายในทุกครั้ง

accessModifier returnType methodName(parameters) {
    // คำสั่งภายใน Method
}

2. การสร้างและเรียกใช้งาน Method

2.1 รูปแบบการสร้าง Method

การสร้าง Method ต้องกำหนดชนิดข้อมูลที่ Method จะส่งกลับ ชื่อของ Method และ Parameters ที่ต้องการรับข้อมูล

หาก Method ทำหน้าที่เพียงดำเนินการบางอย่างและไม่ต้องส่งค่ากลับ สามารถกำหนด return type เป็น void ได้ แต่หากต้องการนำผลลัพธ์ไปใช้งานต่อ จะต้องกำหนดชนิดข้อมูลที่ต้องการส่งกลับ เช่น int, double หรือ String

ภายในเครื่องหมายปีกกา { } คือส่วนที่ใช้เขียนคำสั่งสำหรับการทำงานของ Method เมื่อ Method ถูกเรียกใช้งาน โปรแกรมจะดำเนินการตามคำสั่ง ภายในส่วนนี้ตามลำดับ 

public static void sayHello() {

    System.out.println("Hello Java");

}

2.2 การประกาศ Method

การประกาศ Method คือการกำหนดชื่อ Method ชนิดข้อมูลที่ส่งกลับ และชุดคำสั่งที่ต้องการให้ Method ทำงาน

ในตัวอย่าง public เป็นตัวกำหนดการเข้าถึง static ระบุว่า Method สามารถใช้งานในรูปแบบ Static Method void หมายถึงไม่มีค่าที่ส่งกลับ และ sayHello คือชื่อของ Method

หาก Method มี Parameters จะต้องระบุชนิดข้อมูลและชื่อของ Parameters ภายในวงเล็บหลังชื่อ Method โดย Parameters ทำหน้าที่เป็นข้อมูลที่ Method จะนำไปประมวลผล

2.3 การเรียกใช้งาน Method

หลังจากสร้าง Method แล้ว จะต้องเรียกใช้งาน Method จึงจะทำให้คำสั่งภายใน Method ทำงาน การเรียก Method สามารถทำได้โดยเขียนชื่อ Method ตามด้วยวงเล็บ

การเรียกใช้งาน Method ถือเป็นการสั่งให้โปรแกรม เข้าไปทำงานตามชุดคำสั่งที่กำหนดไว้ใน Method เมื่อทำงานเสร็จแล้ว โปรแกรมจะกลับมาทำงานต่อ จากตำแหน่งที่เรียก Method

ตัวอย่าง 
public class Mainn {

    static void sayHello() {

        System.out.println("Hello Java");

    }

    public static void main(String[] args) {

        sayHello();

    }

}
ผลลัพธ์
Hello Java

2.4 ตัวอย่างการสร้างและเรียกใช้งาน Method

จากตัวอย่าง เมื่อโปรแกรมทำงานที่คำสั่ง sayHello(); โปรแกรมจะเรียก Method sayHello() และดำเนินการตามคำสั่งที่อยู่ภายใน Method

ขั้นตอนการทำงานเริ่มจาก Method main() ซึ่งเป็นจุดเริ่มต้นของโปรแกรม จากนั้นโปรแกรมพบคำสั่ง sayHello(); จึงเข้าไปทำงานภายใน Method sayHello() และแสดงข้อความออกทางหน้าจอ เมื่อทำงานเสร็จแล้วจึงกลับมายัง Method main()

3. Method แบบไม่มีค่าตอบกลับ

3.1 ความหมายของ void

คำว่า void ใช้ระบุว่า Method นั้นไม่มีค่าที่ส่งกลับ ไปยังจุดที่เรียกใช้งาน เหมาะสำหรับ Method ที่มีหน้าที่ดำเนินการบางอย่าง เช่น แสดงข้อความ บันทึกข้อมูล หรือเปลี่ยนแปลงค่าบางอย่าง

Method แบบ void ยังสามารถรับ Parameters ได้ ดังนั้นคำว่า void หมายถึงเฉพาะการไม่มีค่าที่ส่งกลับ ไม่ได้หมายความว่า Method จะไม่สามารถรับข้อมูลได้ ตัวอย่างเช่น Method สามารถรับชื่อผู้ใช้งาน แล้วนำชื่อนั้นไปแสดงผลได้

3.2 การสร้าง Method แบบ void

ตัวอย่าง 
public class Mainn {

    static void showMessage() {

        System.out.println("ยินดีต้อนรับสู่ Java");

    }

    public static void main(String[] args) {

        showMessage();

    }

}

3.3 การเรียกใช้งาน Method แบบ void

Method แบบ void สามารถเรียกใช้งานได้เหมือน Method ทั่วไป แต่ไม่สามารถนำผลลัพธ์ไปเก็บไว้ในตัวแปรเพื่อรับค่ากลับได้

การเรียกใช้งาน Method แบบ void เหมาะกับงานที่ต้องการให้โปรแกรม ดำเนินการบางอย่าง เช่น แสดงข้อความ แสดงเมนู บันทึกข้อมูล หรือเปลี่ยนแปลงค่าของ Object โดยไม่ได้ต้องการผลลัพธ์กลับมาในรูปแบบค่าข้อมูล

3.4 ตัวอย่างการใช้งาน void

ข้อควรจำ

Method ที่กำหนดเป็น void จะไม่มีค่าข้อมูลส่งกลับจาก Method แต่สามารถใช้คำสั่ง return; เพื่อหยุดการทำงานของ Method ได้

หาก Method แบบ void มีคำสั่ง return; โปรแกรมจะหยุดการทำงานของ Method ณ จุดนั้น และกลับไปยังคำสั่งที่เรียก Method โดยคำสั่ง return ในกรณีนี้จะไม่มีข้อมูลต่อท้าย

4. Parameters และ Arguments

4.1 ความหมายของ Parameters

Parameters คือ ตัวแปรที่กำหนดไว้ในวงเล็บของ Method เพื่อรับข้อมูลจากผู้เรียกใช้งาน ทำให้ Method สามารถทำงานกับข้อมูลที่แตกต่างกันได้ โดยไม่ต้องเขียน Method ใหม่ทุกครั้ง

Parameter จะทำหน้าที่เป็นตัวแทนของข้อมูลที่ Method ต้องการ โดยกำหนดชนิดข้อมูลและชื่อของ Parameter ไว้ในตอนสร้าง Method เมื่อมีการเรียกใช้งานจึงส่งค่าที่ต้องการเข้ามา เพื่อให้ Method นำไปประมวลผล

returnType methodName(dataType parameterName) { ... }

4.2 ความหมายของ Arguments

Arguments คือค่าที่ส่งเข้าไปใน Method ขณะที่มีการเรียกใช้งาน Method โดยค่าที่ส่งเข้ามาจะถูกนำไปเก็บไว้ใน Parameters

Parameters และ Arguments มีหน้าที่เกี่ยวข้องกัน แต่เกิดขึ้นในคนละตำแหน่ง Parameter จะอยู่ในส่วนประกาศ Method ส่วน Argument จะอยู่ในส่วนที่เรียกใช้งาน Method และค่าของ Argument ควรสอดคล้องกับชนิดข้อมูลของ Parameter

4.3 การส่งข้อมูลเข้าสู่ Method

ตัวอย่าง 
static void greet(String name) {

    System.out.println("สวัสดี " + name);

}

public static void main(String[] args) {

    greet("Somchai");

    greet("Somsri");

}
ผลลัพธ์
สวัสดี Somchai
สวัสดี Somsri

ในตัวอย่าง name คือ Parameter ส่วนค่าที่ส่งเข้าไป เช่น "Somchai" และ "Somsri" เรียกว่า Arguments

จากตัวอย่างเดียวกันจะเห็นว่า Method greet() สามารถนำกลับมาใช้งานซ้ำได้ โดยไม่ต้องสร้าง Method ใหม่ สำหรับแต่ละชื่อ เพียงส่ง Argument ที่แตกต่างกันเข้าไป Method จึงสามารถทำงานกับข้อมูลหลายชุดได้

4.4 การใช้หลาย Parameters

Method สามารถรับ Parameters ได้มากกว่าหนึ่งตัว โดยกำหนดชนิดข้อมูลและชื่อตัวแปรแต่ละตัว คั่นด้วยเครื่องหมายจุลภาค

Parameters แต่ละตัวสามารถมีชนิดข้อมูลแตกต่างกันได้ เช่น Parameter หนึ่งเป็น String และอีก Parameter เป็น int การเรียกใช้งานจะต้องส่งข้อมูลให้ตรงตามลำดับ และชนิดข้อมูลที่ Method กำหนดไว้

ตัวอย่าง 
static void studentInfo(String name, int age) {

    System.out.println("ชื่อ: " + name);

    System.out.println("อายุ: " + age);

}

public static void main(String[] args) {

    studentInfo("Somchai", 20);

}

4.5 ตัวอย่างการใช้ Parameters

การใช้ Parameters หลายตัวช่วยให้ Method สามารถรับข้อมูลที่เกี่ยวข้องกัน และนำข้อมูลเหล่านั้นไปประมวลผลภายใน Method ได้

การส่งข้อมูลเข้าสู่ Method ยังช่วยให้ Method มีความยืดหยุ่น เนื่องจาก Method เดียวสามารถทำงานกับข้อมูลหลายรูปแบบ โดยเปลี่ยนเฉพาะ Arguments ที่ส่งเข้ามา ทำให้ไม่จำเป็นต้องสร้าง Method หลายตัว สำหรับงานที่มีลักษณะเหมือนกัน

5. Method ที่มีค่าตอบกลับ

5.1 ความหมายของค่าตอบกลับ

Method ไม่จำเป็นต้องเป็น void เสมอไป หากต้องการให้ Method ส่งค่ากลับ สามารถกำหนดชนิดข้อมูล เช่น int, double หรือ String และใช้คำสั่ง return เพื่อส่งค่ากลับ

ค่าที่ส่งกลับสามารถนำไปเก็บไว้ในตัวแปร นำไปคำนวณต่อ หรือใช้เป็นส่วนหนึ่งของเงื่อนไข ในโปรแกรมได้ จึงเหมาะกับ Method ที่มีหน้าที่ประมวลผลข้อมูล และต้องการนำผลลัพธ์ไปใช้งานในส่วนอื่นของโปรแกรม

5.2 การใช้ return

คำสั่ง return ใช้สำหรับส่งค่าจาก Method กลับไปยังส่วนที่เรียกใช้งาน โดยชนิดข้อมูลที่ส่งกลับต้องสอดคล้องกับ return type ของ Method

เมื่อโปรแกรมทำงานถึงคำสั่ง return Method จะหยุดการทำงานและส่งค่ากลับไปยังตำแหน่ง ที่มีการเรียกใช้งาน Method ดังนั้นคำสั่งที่อยู่หลัง return ภายใน Method เดียวกัน จะไม่ถูกทำงานในเส้นทางการทำงานนั้น

5.3 Method ที่ส่งค่า int กลับ

ตัวอย่าง 
static int add(int a, int b) {

    return a + b;

}

public static void main(String[] args) {

    int result = add(10, 20);

    System.out.println(result);

}
ผลลัพธ์
30

Method add() รับตัวเลขสองค่า แล้วนำมาบวกกัน จากนั้นใช้ return ส่งผลลัพธ์กลับมาเก็บไว้ในตัวแปร result

ในตัวอย่าง Method กำหนด return type เป็น int ดังนั้นค่าที่ส่งกลับด้วยคำสั่ง return ต้องเป็นข้อมูลที่สามารถใช้เป็นชนิด int ได้ โปรแกรมจึงสามารถนำค่าที่ได้ไปเก็บไว้ในตัวแปร และนำไปใช้งานต่อได้

5.4 Method ที่ส่งค่า double กลับ

ตัวอย่าง 
static double calculate(double price, double tax) {

    return price + tax;

}

public static void main(String[] args) {

    double total = calculate(100, 7);

    System.out.println(total);

}

Method calculate() รับข้อมูลประเภท double จำนวนสองค่า และส่งผลลัพธ์ประเภท double กลับมา ผู้เรียกใช้งานสามารถนำค่าที่ได้รับไปเก็บไว้ในตัวแปร หรือใช้ในการคำนวณขั้นตอนอื่นต่อไปได้

5.5 Method ที่ส่งค่า String กลับ

ตัวอย่าง 
static String getName() {

    return "Java Learning Guide";

}

public static void main(String[] args) {

    String name = getName();

    System.out.println(name);

}
ผลลัพธ์
Java Learning Guide

Method สามารถส่งข้อมูลประเภทข้อความกลับได้เช่นเดียวกับข้อมูลตัวเลข โดยกำหนด return type เป็น String และใช้คำสั่ง return ส่งข้อความกลับ ทำให้สามารถนำค่าที่ได้ไปเก็บในตัวแปร String และนำไปแสดงผลหรือใช้งานในส่วนอื่นของโปรแกรมได้

6. Method Overloading

6.1 ความหมายของ Method Overloading

Method Overloading คือการสร้าง Method ที่มีชื่อเดียวกัน แต่มี Parameters แตกต่างกัน เช่น จำนวน Parameters แตกต่างกัน หรือชนิดข้อมูลของ Parameters แตกต่างกัน

แนวคิดของ Method Overloading คือการใช้ชื่อ Method เดียวกัน สำหรับการทำงานที่มีลักษณะใกล้เคียงกัน แต่สามารถรับข้อมูลในรูปแบบที่แตกต่างกันได้ ทำให้ชื่อ Method มีความสอดคล้องกับหน้าที่ และช่วยให้เรียกใช้งานได้สะดวก

6.2 หลักการทำงานของ Method Overloading

Java จะพิจารณาจากจำนวนและชนิดข้อมูลของ Arguments ที่ส่งเข้าไป เพื่อเลือก Method ที่มีรูปแบบ Parameters ตรงกับการเรียกใช้งาน

สิ่งสำคัญคือ Method ที่มีชื่อเหมือนกัน จะต้องมีรายการ Parameters แตกต่างกัน การเปลี่ยนเฉพาะชนิดข้อมูลที่ส่งกลับ ไม่ถือว่าเป็น Method Overloading ดังนั้น Method ที่มีชื่อและ Parameters เหมือนกัน แต่ต่างกันเฉพาะ return type ไม่สามารถใช้เป็น Overloading ได้

6.3 Overloading ด้วยจำนวน Parameters

ตัวอย่าง 
static int add(int a, int b) {

    return a + b;

}

static int add(int a, int b, int c) {

    return a + b + c;

}

6.4 Overloading ด้วยชนิดข้อมูล

ตัวอย่าง 
static int multiply(int a, int b) {

    return a * b;

}

static double multiply(double a, double b) {

    return a * b;

}

6.5 ตัวอย่าง Method Overloading

ตัวอย่าง 
static int add(int a, int b) {

    return a + b;

}

static int add(int a, int b, int c) {

    return a + b + c;

}

public static void main(String[] args) {

    System.out.println(add(10, 20));

    System.out.println(add(10, 20, 30));

}

ทั้งสอง Method ใช้ชื่อ add() เหมือนกัน แต่รับ Parameters ไม่เท่ากัน Java จึงสามารถแยกได้ว่าในแต่ละกรณีต้องเรียก Method ใด

Method Overloading ช่วยให้โปรแกรมมีความยืดหยุ่นมากขึ้น เพราะผู้เขียนโปรแกรมสามารถเรียกใช้ชื่อ Method เดิม โดยส่งข้อมูลในจำนวนหรือชนิดที่เหมาะสมกับงาน แทนการตั้งชื่อ Method หลายชื่อสำหรับงานประเภทเดียวกัน

7. Static Method และ Instance Method

7.1 ความหมายของ Static Method

Method ที่กำหนดด้วยคำว่า static สามารถเรียกใช้งานได้โดยไม่จำเป็นต้องสร้าง Object ของ Class ก่อน

Static Method เป็น Method ที่ผูกกับ Class มากกว่ากับ Object แต่ละตัว จึงเหมาะกับการทำงานทั่วไปที่ไม่จำเป็นต้องใช้ข้อมูล เฉพาะของ Object เช่น การคำนวณทางคณิตศาสตร์ หรือการทำงานที่รับข้อมูลผ่าน Parameters แล้วส่งผลลัพธ์กลับ

7.2 การเรียกใช้ Static Method

ตัวอย่าง 
class Calculator {

    static int square(int number) {

        return number * number;

    }

}

public class Mainn {

    public static void main(String[] args) {

        int result =
            Calculator.square(5);

        System.out.println(result);

    }

}

7.3 ความหมายของ Instance Method

Instance Method คือ Method ที่ไม่ประกาศด้วย static และโดยทั่วไปจะถูกเรียกใช้งานผ่าน Object ที่สร้างขึ้นจาก Class

Instance Method สามารถทำงานร่วมกับข้อมูลของ Object หรือข้อมูลสมาชิกของ Class ในรูปแบบ Instance ได้ จึงเหมาะกับการออกแบบโปรแกรมเชิงวัตถุ ที่ Object แต่ละตัวอาจมีข้อมูลแตกต่างกัน และมีพฤติกรรมที่ต้องดำเนินการกับข้อมูลของตัวเอง

7.4 การสร้าง Object เพื่อเรียกใช้ Instance Method

ตัวอย่าง 
class Student {

    void showName() {

        System.out.println("ชื่อ: Somchai");

    }

}

public class Mainn {

    public static void main(String[] args) {

        Student student =
            new Student();

        student.showName();

    }

}

7.5 ความแตกต่างระหว่าง Static Method และ Instance Method

  • Static Method สามารถเรียกผ่านชื่อ Class ได้ โดยไม่ต้องสร้าง Object
  • Instance Method ต้องสร้าง Object ก่อนจึงสามารถเรียกใช้งานได้
  • Static Method เหมาะกับการทำงาน ที่ไม่จำเป็นต้องอาศัยข้อมูลเฉพาะของ Object
  • Instance Method เหมาะกับการทำงาน ที่เกี่ยวข้องกับข้อมูลและพฤติกรรมของ Object

การเลือกใช้ Static Method หรือ Instance Method ควรพิจารณาจากลักษณะของข้อมูลและหน้าที่ของ Method หาก Method ไม่จำเป็นต้องทำงานกับข้อมูลเฉพาะของ Object สามารถพิจารณาใช้ static ได้ แต่หาก Method ต้องทำงานกับข้อมูลของ Object การใช้ Instance Method จะเหมาะสมกว่า

8. การประยุกต์ใช้ Methods

8.1 Method สำหรับคำนวณข้อมูล

Method สามารถนำมาใช้แยกส่วนของการคำนวณ ออกจากส่วนหลักของโปรแกรม ทำให้สามารถนำการคำนวณกลับมาใช้ซ้ำได้

ตัวอย่างเช่น โปรแกรมคำนวณราคาสินค้า สามารถสร้าง Method สำหรับคำนวณราคารวม Method สำหรับคำนวณส่วนลด หรือ Method สำหรับคำนวณภาษี จากนั้น Method หลักของโปรแกรมสามารถเรียกใช้ แต่ละส่วนตามลำดับที่ต้องการ

8.2 Method สำหรับตรวจสอบข้อมูล

ตัวอย่าง 
public class Mainn {

    static boolean isAdult(int age) {

        return age >= 18;

    }

    public static void main(String[] args) {

        System.out.println(
            isAdult(20)
        );

    }

}

ตัวอย่างนี้ Method isAdult() รับอายุผ่าน Parameter และตรวจสอบว่าอายุมีค่ามากกว่าหรือเท่ากับ 18 หรือไม่ จากนั้นส่งค่าประเภท boolean กลับมา ซึ่งมีค่าเป็น true หรือ false ผลลัพธ์ที่ได้สามารถนำไปใช้ร่วมกับคำสั่งเงื่อนไข เช่น if เพื่อควบคุมการทำงานของโปรแกรมได้

8.3 Method สำหรับแสดงผล

ตัวอย่าง 
public class Mainn {

    static void showWelcome() {

        System.out.println(
            "ยินดีต้อนรับสู่ Java"
        );

    }

    public static void main(String[] args) {

        showWelcome();

    }

}

Method สำหรับแสดงผลเหมาะกับการรวบรวมคำสั่ง ที่เกี่ยวข้องกับการแสดงข้อความหรือข้อมูล เมื่อมีหลายตำแหน่งในโปรแกรมที่ต้องแสดงข้อมูลในรูปแบบเดียวกัน สามารถเรียกใช้ Method เดิมซ้ำได้ ทำให้ไม่จำเป็นต้องเขียนคำสั่งแสดงผลซ้ำในหลายตำแหน่ง

8.4 ตัวอย่างโปรแกรมคำนวณคะแนนด้วย Methods

ตัวอย่าง

ตัวอย่างต่อไปนี้นำ Method มาประยุกต์ใช้กับการคำนวณคะแนน โดยแยกหน้าที่การคำนวณออกมาเป็น Method ทำให้โปรแกรมอ่านง่าย และสามารถนำ Method ไปเรียกใช้งานซ้ำได้ 

public class Mainn {

    static double calculateAverage(
            double score1,
            double score2,
            double score3) {

        return (score1 + score2 + score3) / 3;

    }

    public static void main(String[] args) {

        double average =
            calculateAverage(80, 75, 90);

        System.out.println(
            "คะแนนเฉลี่ย = " + average
        );

    }

}
ผลลัพธ์
คะแนนเฉลี่ย = 81.66666666666667

ตัวอย่างนี้แสดงให้เห็นว่า Method สามารถรับข้อมูลหลายค่า นำไปประมวลผล และส่งผลลัพธ์กลับมาให้โปรแกรมส่วนอื่น นำไปใช้งานต่อได้

การแยกการคำนวณคะแนนออกเป็น Method ช่วยให้ส่วนของ main() มีหน้าที่ควบคุมลำดับการทำงาน ในขณะที่ Method calculateAverage() รับผิดชอบเฉพาะการคำนวณคะแนนเฉลี่ย การแบ่งหน้าที่ในลักษณะนี้ทำให้โปรแกรมมีโครงสร้างชัดเจน และสามารถแก้ไขสูตรการคำนวณได้ง่ายขึ้น

9. สรุปบทเรียน

9.1 สรุปความรู้เกี่ยวกับ Methods

Method คือกลุ่มคำสั่งที่สร้างขึ้นเพื่อทำงานอย่างใดอย่างหนึ่ง และสามารถเรียกใช้งานซ้ำได้

Method สามารถรับข้อมูลผ่าน Parameters และสามารถส่งค่ากลับด้วย return

หาก Method ไม่ต้องการส่งค่ากลับ สามารถใช้ void

การใช้ Method ช่วยให้โปรแกรมมีโครงสร้างที่เป็นระเบียบ โดยสามารถแบ่งการทำงานออกเป็นส่วนต่าง ๆ ตามหน้าที่ของแต่ละ Method นอกจากนี้ยังช่วยลดการเขียนคำสั่งซ้ำ เพิ่มความสามารถในการนำโค้ดกลับมาใช้ใหม่ และทำให้การแก้ไขโปรแกรมในภายหลังทำได้สะดวก

9.2 แนวคิดสำคัญที่ควรจดจำ

  • Method ช่วยแบ่งโปรแกรมออกเป็นส่วนย่อย
  • Method สามารถรับข้อมูลผ่าน Parameters
  • Arguments คือค่าที่ส่งเข้า Method
  • Method สามารถส่งค่ากลับด้วย return
  • void ใช้กับ Method ที่ไม่มีค่าข้อมูลส่งกลับ
  • Method Overloading สามารถใช้ชื่อ Method เดียวกัน แต่มี Parameters แตกต่างกัน
  • Static Method สามารถเรียกใช้งานโดยไม่ต้องสร้าง Object
  • Instance Method โดยทั่วไปเรียกใช้งานผ่าน Object

9.3 สิ่งที่ควรรู้หลังเรียนจบ

  • อธิบายความหมายของ Method ได้
  • สามารถสร้าง Method ในภาษา Java ได้
  • สามารถเรียกใช้งาน Method ได้
  • เข้าใจการใช้ void
  • สามารถส่งข้อมูลผ่าน Parameters ได้
  • สามารถใช้ return ส่งค่ากลับจาก Method ได้
  • เข้าใจหลักการของ Method Overloading
  • เข้าใจความแตกต่างระหว่าง Static Method และ Instance Method
  • สามารถนำ Method ไปใช้สร้างโปรแกรมที่เป็นระบบได้
