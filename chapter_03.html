ลำดับขั้นตอนการพัฒนาโปรแกรมด้วยภาษา Java

1. ลำดับขั้นตอนการพัฒนาโปรแกรมด้วยภาษา Java

1.1 ภาพรวมกระบวนการพัฒนาโปรแกรม

การพัฒนาโปรแกรมด้วยภาษา Java เป็นกระบวนการที่ประกอบด้วยขั้นตอนต่าง ๆ ตั้งแต่การวิเคราะห์ปัญหา การออกแบบแนวทางการทำงาน การเขียนคำสั่ง การบันทึก Source Code การตรวจสอบและ Compile โปรแกรม ไปจนถึงการ Run โปรแกรม เพื่อแสดงผลลัพธ์ที่ผู้เขียนต้องการ

ในการพัฒนาโปรแกรม ผู้เขียนควรเริ่มจากการทำความเข้าใจ วัตถุประสงค์ของโปรแกรมก่อนว่าโปรแกรมต้องการแก้ปัญหาอะไร ต้องรับข้อมูลอะไรจากผู้ใช้ ต้องประมวลผลข้อมูลอย่างไร และต้องแสดงผลลัพธ์ในรูปแบบใด การวางแผนก่อนเขียนโปรแกรมจะช่วยลดความผิดพลาด และทำให้สามารถเขียนคำสั่งได้อย่างเป็นระบบมากขึ้น

Java มีรูปแบบการทำงานที่แตกต่างจากภาษาบางประเภท เนื่องจาก Source Code ที่เขียนขึ้น จะถูก Compile โดย Java Compiler ให้กลายเป็น Bytecode ซึ่งถูกจัดเก็บไว้ในไฟล์นามสกุล .class จากนั้น Bytecode จะถูกนำไปทำงานผ่าน JVM (Java Virtual Machine)

Bytecode ถือเป็นรูปแบบคำสั่งที่อยู่ระหว่าง Source Code กับการทำงานจริงของโปรแกรม โปรแกรมเมอร์สามารถเขียน Source Code ให้อยู่ในรูปแบบที่มนุษย์สามารถอ่านและแก้ไขได้ จากนั้น Java Compiler จะตรวจสอบคำสั่ง และสร้าง Bytecode สำหรับ JVM ทำให้ขั้นตอนการพัฒนาและขั้นตอนการประมวลผล สามารถแยกออกจากกันได้อย่างชัดเจน

กระบวนการดังกล่าวช่วยให้โปรแกรม Java สามารถทำงานบนระบบปฏิบัติการที่แตกต่างกันได้ หากระบบนั้นมี JVM ที่รองรับ จึงเป็นหนึ่งในแนวคิดสำคัญของภาษา Java ที่มักอธิบายด้วยแนวคิด Write Once, Run Anywhere

แนวคิดนี้หมายถึง โปรแกรมเมอร์สามารถเขียน และ Compile โปรแกรม Java แล้วนำ Bytecode ที่ได้ไปทำงานบนสภาพแวดล้อมอื่น ที่มี JVM รองรับได้ โดยไม่จำเป็นต้องเขียน Source Code ใหม่ทั้งหมดสำหรับระบบปฏิบัติการแต่ละประเภท อย่างไรก็ตาม ความสามารถในการทำงานข้ามระบบ ยังขึ้นอยู่กับสภาพแวดล้อม ไลบรารี และการตั้งค่าของระบบ ที่โปรแกรมใช้งานด้วย

ในระหว่างการพัฒนาโปรแกรม หากพบข้อผิดพลาดในการเขียน Source Code หรือพบข้อผิดพลาดขณะ Compile ผู้พัฒนาจะต้องกลับไปตรวจสอบและแก้ไขคำสั่ง จากนั้นจึง Compile โปรแกรมอีกครั้ง และเมื่อ Compile สำเร็จ จึงสามารถ Run โปรแกรมเพื่อทดสอบผลลัพธ์ได้

การพัฒนาโปรแกรมจึงเป็นกระบวนการที่สามารถทำซ้ำได้หลายครั้ง ไม่จำเป็นต้องเขียนโปรแกรมให้สมบูรณ์ตั้งแต่ครั้งแรก ผู้พัฒนาสามารถเขียนคำสั่ง ทดลอง Compile ตรวจสอบ Error ทดสอบการทำงาน และปรับปรุงโปรแกรมอย่างต่อเนื่อง กระบวนการนี้ช่วยให้สามารถค้นหาและแก้ไขปัญหา ได้ตั้งแต่ระยะเริ่มต้นของการพัฒนา

นอกจากนี้ การแยกขั้นตอนระหว่างการเขียน การ Compile และการ Run ยังช่วยให้ผู้เรียนเข้าใจว่า โปรแกรมที่เราเขียนไม่ได้ถูกนำไปทำงานโดยตรงทันที แต่ต้องผ่านกระบวนการตรวจสอบและแปลง ก่อนที่จะถูกนำไปประมวลผลโดย JVM

💡 แนวคิดสำคัญ

การพัฒนาโปรแกรม Java ไม่ได้จบเพียงการเขียนโค้ดเท่านั้น แต่ต้องมีการ Compile ตรวจสอบข้อผิดพลาด และ Run โปรแกรม เพื่อทดสอบว่าการทำงานเป็นไปตามที่ออกแบบไว้หรือไม่

ผู้พัฒนาควรมองกระบวนการทั้งหมดเป็นวงจร ได้แก่ การเขียนโค้ด การ Compile การตรวจสอบข้อผิดพลาด การ Run การทดสอบผลลัพธ์ และการปรับปรุงโปรแกรม ซึ่งสามารถทำซ้ำได้จนกว่าโปรแกรม จะทำงานได้ตามวัตถุประสงค์

1.2 สามขั้นตอนหลักของการพัฒนาโปรแกรม

กระบวนการพื้นฐานในการพัฒนาโปรแกรม Java สามารถแบ่งออกเป็น 3 ขั้นตอนหลัก ได้แก่

  • การสร้าง Source Code
  • การ Compile Source Code
  • การ Run โปรแกรม

ทั้งสามขั้นตอนมีความสัมพันธ์กัน และไม่สามารถมองแยกออกจากกันโดยสิ้นเชิง เพราะ Source Code เป็นข้อมูลเริ่มต้น สำหรับการ Compile ส่วนผลลัพธ์จากการ Compile จะถูกนำไปใช้ในขั้นตอนการ Run หากขั้นตอนใดเกิดข้อผิดพลาด ก็อาจส่งผลให้ขั้นตอนถัดไปไม่สามารถทำงานได้

1

สร้าง Source Code

เขียนคำสั่ง Java และบันทึกเป็นไฟล์ .java

เป็นขั้นตอนที่ผู้พัฒนา กำหนดคำสั่งและรูปแบบการทำงาน ของโปรแกรม

Source Code เป็นส่วนที่ผู้พัฒนาสามารถอ่าน ทำความเข้าใจ แก้ไข และปรับปรุงได้ เช่น การประกาศตัวแปร การสร้าง Method การรับข้อมูล การคำนวณ การใช้เงื่อนไข และการแสดงผล

2

Compile

ใช้คำสั่ง javac เพื่อ Compile Source Code ให้เป็น Bytecode

ผลลัพธ์จะได้ไฟล์ .class

ในขั้นตอนนี้ Compiler จะตรวจสอบโครงสร้างและไวยากรณ์ของ Source Code หากพบข้อผิดพลาด โปรแกรมจะไม่สามารถ Compile ได้สำเร็จจนกว่าจะมีการแก้ไข

3

Run

ใช้คำสั่ง java เพื่อเรียกใช้งานโปรแกรม และแสดงผลลัพธ์

Bytecode จะถูกประมวลผลผ่าน JVM

ในระหว่างการ Run โปรแกรมจะดำเนินการตามคำสั่ง และข้อมูลที่ผู้พัฒนาเขียนไว้ จากนั้นจะแสดง Output หรือผลลัพธ์ให้ผู้ใช้เห็น

1.3 แผนผังการทำงานของโปรแกรม Java

การทำงานตั้งแต่ Source Code จนถึงผลลัพธ์ของโปรแกรม สามารถมองเห็นเป็นลำดับขั้นตอนได้ดังนี้

จุดสำคัญของแผนผังนี้คือ Source Code ไม่ได้ถูกนำไป Run โดยตรง แต่ต้องผ่าน Java Compiler ก่อน เพื่อสร้าง Bytecode หลังจากนั้น JVM จึงสามารถโหลด และประมวลผล Bytecode เพื่อให้โปรแกรมทำงานได้

Source Code TestJava.java
→
Compile javac TestJava.java
→
Bytecode TestJava.class
→
Run java TestJava

จากแผนผังจะเห็นได้ว่าไฟล์ TestJava.java เป็นไฟล์ต้นฉบับ เมื่อใช้คำสั่ง javac TestJava.java ระบบจะสร้าง TestJava.class ซึ่งเป็น Bytecode และเมื่อใช้คำสั่ง java TestJava JVM จะนำ Class ดังกล่าวไปประมวลผล เพื่อให้เกิด Output ของโปรแกรม

💡 จำง่าย ๆ

.java → ไฟล์ Source Code
javac → คำสั่ง Compile
.class → ไฟล์ Bytecode
java → คำสั่ง Run
JVM → ประมวลผล Bytecode

1.4 บทบาทของ JVM ในการทำงานของ Java

JVM (Java Virtual Machine) เป็นส่วนสำคัญที่ใช้ในการประมวลผล Bytecode ของโปรแกรม Java โดย JVM จะทำหน้าที่จัดการการทำงาน ของโปรแกรมในระหว่างที่โปรแกรมกำลัง Run

JVM ทำหน้าที่เป็นสภาพแวดล้อมเสมือน สำหรับการประมวลผลโปรแกรม Java โดยรับ Bytecode ที่ได้จากการ Compile แล้วดำเนินการตามคำสั่งที่อยู่ภายใน ทำให้โปรแกรมสามารถทำงานได้บนระบบ ที่มี JVM ที่เหมาะสม

เมื่อผู้ใช้สั่ง Run โปรแกรม JVM จะโหลด Class ที่จำเป็น ตรวจสอบข้อมูลของ Class และเตรียมส่วนต่าง ๆ ที่จำเป็น สำหรับการทำงานของโปรแกรม จากนั้นจึงดำเนินการตามคำสั่ง ที่อยู่ใน Bytecode

JVM ยังมีหน้าที่เกี่ยวข้องกับการจัดการหน่วยความจำ และทรัพยากรที่ใช้ระหว่างการทำงานของโปรแกรม เช่น การจัดการพื้นที่สำหรับ Object และการจัดการหน่วยความจำที่ไม่ถูกใช้งานแล้ว ซึ่งช่วยลดภาระบางส่วนที่ผู้เขียนโปรแกรม ต้องจัดการด้วยตนเอง

แนวคิดของ JVM ยังเป็นปัจจัยสำคัญ ที่ทำให้ภาษา Java สามารถนำ Bytecode ไปทำงานบนระบบปฏิบัติการหลายประเภทได้ เพราะแต่ละระบบจะมี JVM ที่ทำหน้าที่เป็นตัวกลางระหว่าง Bytecode กับสภาพแวดล้อมของระบบนั้น

💡 ข้อควรรู้

ผู้เขียนโปรแกรมไม่จำเป็นต้องเขียน Bytecode ด้วยตนเอง เพราะ Bytecode จะถูกสร้างขึ้น โดย Java Compiler หลังจากทำการ Compile Source Code

ผู้พัฒนาจึงทำงานกับ Source Code เป็นหลัก ส่วน Bytecode จะถูกสร้างขึ้นเป็นผลลัพธ์จากกระบวนการ Compile และถูกนำไปใช้โดย JVM ในขั้นตอนการ Run

2. ขั้นตอนที่ 1 : การสร้าง Source Code

2.1 ความหมายของ Source Code

ขั้นตอนแรกของการพัฒนาโปรแกรม Java คือการสร้างโปรแกรมหรือ ซอร์สโค้ด (Source Code) โดยการพิมพ์คำสั่งต่าง ๆ ตามหลักไวยากรณ์ของภาษา Java

Source Code เป็นคำสั่งต้นฉบับ ที่โปรแกรมเมอร์เขียนขึ้น เพื่อกำหนดรูปแบบและลำดับการทำงาน ของโปรแกรม เช่น การประกาศตัวแปร การรับข้อมูลจากผู้ใช้ การคำนวณ การใช้เงื่อนไข การทำงานแบบวนซ้ำ และการแสดงผลลัพธ์

Source Code ยังสามารถมองได้ว่าเป็น รูปแบบการสื่อสารระหว่างผู้พัฒนา กับคอมพิวเตอร์ โดยผู้พัฒนาใช้ไวยากรณ์ของภาษา Java เพื่ออธิบายว่าต้องการให้โปรแกรมทำงานอย่างไร จากนั้น Compiler จึงนำคำสั่งเหล่านี้ ไปตรวจสอบและแปลงเป็น Bytecode

Source Code ของภาษา Java จะถูกจัดเก็บไว้ในไฟล์ ที่มีนามสกุล .java เช่น TestJava.java

ภายใน Source Code สามารถมีคำสั่งจำนวนมากได้ และโปรแกรมหนึ่งโปรแกรม อาจประกอบด้วยหลาย Class หลาย Method และหลายไฟล์ ดังนั้นการจัดโครงสร้าง Source Code ให้เป็นระเบียบ และตั้งชื่อไฟล์ให้สื่อความหมาย จึงมีความสำคัญต่อการดูแลโปรแกรม

💡 ข้อควรรู้

Source Code คือคำสั่งต้นฉบับ ที่โปรแกรมเมอร์เขียนขึ้น ส่วนไฟล์ .java คือไฟล์ที่ใช้จัดเก็บ Source Code ของโปรแกรม Java

2.2 โปรแกรมที่ใช้เขียน Source Code

ในการเขียน Source Code สามารถใช้โปรแกรมประเภท Editor หรือ Text Editor รวมถึงโปรแกรมประเภท IDE (Integrated Development Environment) ซึ่งช่วยอำนวยความสะดวก ในการเขียนและพัฒนาโปรแกรม

โปรแกรมสำหรับเขียน Source Code มีหน้าที่ช่วยให้ผู้พัฒนาสามารถ สร้างไฟล์ พิมพ์คำสั่ง แก้ไข Source Code และบันทึกไฟล์ได้สะดวก โดยบางโปรแกรมยังสามารถช่วย ตรวจสอบรูปแบบคำสั่ง แนะนำคำสั่ง และแสดงตำแหน่งของข้อผิดพลาด ได้อีกด้วย

ตัวอย่างโปรแกรมที่สามารถใช้ สำหรับเขียน Source Code ได้แก่

  • Notepad โปรแกรมแก้ไขข้อความพื้นฐาน ที่สามารถใช้เขียนไฟล์ Java ได้
  • EditPlus โปรแกรมแก้ไขข้อความ ที่สามารถใช้สำหรับเขียน Source Code
  • Visual Studio Code (VS Code) โปรแกรมแก้ไขโค้ดที่รองรับ การพัฒนาโปรแกรมหลายภาษา
  • IDE เช่น โปรแกรมที่ออกแบบมา สำหรับช่วยเขียน Compile และทดสอบโปรแกรม

สำหรับผู้เริ่มต้น การใช้ Text Editor ช่วยให้เข้าใจกระบวนการของ Java ได้อย่างชัดเจน เพราะผู้เรียนจะเห็น ขั้นตอนการสร้างไฟล์ การ Compile ด้วยคำสั่ง และการ Run โปรแกรมด้วยตนเอง ส่วน IDE จะช่วยลดขั้นตอนทางเทคนิค และเพิ่มความสะดวกเมื่อพัฒนาโปรแกรม ที่มีขนาดใหญ่ขึ้น

Source Code ของโปรแกรม Java มักประกอบด้วยส่วนสำคัญหลายส่วน เช่น ชื่อ Class เมธอด และคำสั่งที่ใช้ในการทำงาน โดยโปรแกรม Java ที่สามารถเริ่มทำงานได้ มักจะมีเมธอด main() เป็นจุดเริ่มต้นของโปรแกรม

  • ชื่อ Class

  • คำสั่งการทำงาน
  • คำสั่งแสดงผล
  • ตัวแปรและข้อมูล

ในการเขียน Source Code ผู้พัฒนาควรจัดรูปแบบคำสั่ง ให้มีระเบียบและอ่านง่าย เช่น การย่อหน้า การตั้งชื่อ Class การตั้งชื่อตัวแปร และการแยกคำสั่งออกเป็นส่วน ๆ เพราะเมื่อโปรแกรมมีขนาดใหญ่ขึ้น ความเป็นระเบียบของ Source Code จะช่วยให้สามารถแก้ไขและบำรุงรักษา โปรแกรมได้ง่ายขึ้น

3. ขั้นตอนที่ 2 : การ Compile โปรแกรม

3.1 ความหมายของการ Compile

หลังจากสร้าง Source Code และบันทึกเป็นไฟล์ .java แล้ว ขั้นตอนต่อไปคือ การคอมไพล์โปรแกรม หรือ Compile

การ Compile คือกระบวนการ ที่นำ Source Code ซึ่งเขียนด้วยภาษา Java ไปตรวจสอบและแปลงให้อยู่ในรูปแบบ Bytecode เพื่อให้สามารถนำไปประมวลผล ผ่าน JVM ได้

ในระหว่างการ Compile Java Compiler จะตรวจสอบ Source Code ว่ามีรูปแบบคำสั่งและไวยากรณ์ ที่ถูกต้องตามกฎของภาษา Java หรือไม่ หากพบข้อผิดพลาด Compiler จะรายงานข้อมูลเกี่ยวกับปัญหา เพื่อให้ผู้พัฒนาสามารถกลับไปแก้ไข Source Code ได้

การ Compile จึงไม่ได้มีหน้าที่เพียง สร้างไฟล์ .class เท่านั้น แต่ยังเป็นขั้นตอนสำคัญ สำหรับตรวจสอบความถูกต้องของ Source Code ก่อนนำโปรแกรมไป Run

3.2 เครื่องมือสำหรับ Compile

การ Compile Source Code สามารถใช้คำสั่ง javac ซึ่งเป็นเครื่องมือของ JDK (Java Development Kit)

คำสั่ง javac จะทำหน้าที่เรียก Java Compiler เพื่ออ่าน Source Code ตรวจสอบไวยากรณ์ และสร้างไฟล์ Bytecode หากไม่พบข้อผิดพลาด จะได้ไฟล์ .class

JDK เป็นชุดเครื่องมือที่ใช้สำหรับ การพัฒนาโปรแกรม Java โดยมีเครื่องมือที่จำเป็น สำหรับการ Compile และเครื่องมืออื่น ๆ ที่เกี่ยวข้องกับการพัฒนาโปรแกรม ดังนั้น หากต้องการ Compile โปรแกรม Java ผ่าน Command Prompt จะต้องติดตั้ง JDK และสามารถเรียกใช้คำสั่ง javac ได้อย่างถูกต้อง

3.5 การตรวจสอบข้อผิดพลาดระหว่าง Compile

หาก Source Code มีข้อผิดพลาดทางไวยากรณ์ หรือมีการเขียนคำสั่งไม่ถูกต้อง Java Compiler จะแสดงข้อความแจ้งเตือน หรือข้อความแสดงข้อผิดพลาด เพื่อช่วยให้ผู้พัฒนาทราบว่า โปรแกรมมีปัญหาบริเวณใด

ข้อความ Error จาก Compiler มักมีข้อมูลที่ช่วยในการค้นหาปัญหา เช่น ชื่อไฟล์ หมายเลขบรรทัด ตำแหน่งของคำสั่ง และลักษณะของข้อผิดพลาด ผู้เรียนจึงควรฝึกอ่านข้อความ Error แทนการแก้ไขแบบสุ่ม

ตัวอย่างปัญหาที่อาจพบได้ ได้แก่ การลืมเครื่องหมาย ; การสะกดชื่อ Class ผิด การใช้ตัวแปรที่ยังไม่ได้ประกาศ การใช้ชนิดข้อมูลไม่ตรงกัน หรือการเขียนโครงสร้างของคำสั่ง ไม่ถูกต้อง

เมื่อพบข้อผิดพลาด ควรอ่านข้อความจาก Compiler ตรวจสอบบรรทัดที่ระบุ แก้ไข Source Code แล้วจึง Compile ใหม่อีกครั้ง

⚠️ หาก Compile ไม่สำเร็จ

1. อ่านข้อความ Error
2. ตรวจสอบบรรทัดที่เกิดปัญหา
3. แก้ไข Source Code
4. บันทึกไฟล์
5. Compile ใหม่อีกครั้ง

3.6 ไฟล์ Bytecode

หาก Source Code ไม่มีข้อผิดพลาดในการ Compile Java Compiler จะสร้างไฟล์ Bytecode ที่มีนามสกุล .class

Bytecode ไม่ใช่ Source Code ที่โปรแกรมเมอร์เขียนโดยตรง แต่เป็นผลลัพธ์จากกระบวนการ Compile ซึ่งจะถูกนำไปประมวลผลผ่าน JVM ในขั้นตอนการ Run โปรแกรม

ข้อดีของ Bytecode คือ ทำให้ Java สามารถแยก Source Code ออกจากสภาพแวดล้อมที่ใช้ประมวลผล โดย JVM ของแต่ละระบบ จะทำหน้าที่จัดการ Bytecode ให้สามารถทำงานภายในระบบนั้นได้

ดังนั้นเมื่อผู้พัฒนาเปลี่ยนเครื่อง หรือเปลี่ยนระบบปฏิบัติการ Bytecode เดิมสามารถนำไปใช้ได้ หากระบบปลายทางมี JVM ที่รองรับสภาพแวดล้อมนั้น

  • เครื่องคอมพิวเตอร์ต้องติดตั้ง JDK
  • ต้องตรวจสอบข้อความ Error หาก Compile ไม่สำเร็จ

นอกจากนี้ควรตรวจสอบว่า คำสั่ง javac สามารถเรียกใช้งานได้จาก Command Prompt หรือ Terminal หากระบบไม่รู้จักคำสั่ง อาจเกิดจากการติดตั้ง JDK หรือการกำหนดค่า Environment ที่ยังไม่ถูกต้อง

4. ขั้นตอนที่ 3 : การ Run โปรแกรม

4.1 ความหมายของการ Run

เมื่อ Compile สำเร็จแล้ว จะได้ไฟล์ .class จากนั้นจึงสามารถ Run โปรแกรมเพื่อดูผลลัพธ์ได้

การ Run เป็นขั้นตอนที่ทำให้โปรแกรม เริ่มทำงานตามคำสั่งที่ผู้พัฒนาเขียนไว้ โดย Bytecode จะถูกโหลดและประมวลผล ผ่าน JVM (Java Virtual Machine)

การ Run จึงเป็นขั้นตอนที่ผู้พัฒนา สามารถตรวจสอบการทำงานจริงของโปรแกรม ได้ เช่น ตรวจสอบว่าการคำนวณถูกต้องหรือไม่ เงื่อนไขทำงานตามที่ออกแบบหรือไม่ และผลลัพธ์ที่แสดงออกมาตรงกับ ความต้องการของโปรแกรมหรือไม่

4.2 รูปแบบคำสั่ง Run 

java FileName

ในการ Run โปรแกรม ไม่ต้องพิมพ์นามสกุล .class ต่อท้ายชื่อ Class

คำสั่ง java จะใช้ชื่อของ Class ที่ต้องการเรียกใช้งาน จากนั้น Java Runtime Environment จะเริ่มกระบวนการทำงานของ Class และ JVM จะเข้ามาประมวลผล Bytecode ที่เกี่ยวข้อง

คำสั่ง Run ไม่ต้องเขียน .class

4.3 ตัวอย่างการ Run โปรแกรม 

java TestJava

คำสั่งดังกล่าวจะสั่งให้ Java ค้นหา Class TestJava และเริ่มการทำงานของโปรแกรม จากเมธอด main()

การเรียกใช้ Class ต้องระบุชื่อให้ถูกต้อง รวมถึงตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ เนื่องจาก Java แยกความแตกต่าง ของตัวอักษรทั้งสองรูปแบบ

4.4 การทำงานของ JVM

หลังจากสั่ง Run โปรแกรม Bytecode ในไฟล์ .class จะถูกนำไปประมวลผลโดย JVM (Java Virtual Machine) เพื่อให้โปรแกรมสามารถทำงาน และแสดงผลลัพธ์ได้

JVM ทำหน้าที่เป็นสภาพแวดล้อม สำหรับการทำงานของ Bytecode และช่วยให้โปรแกรม Java สามารถทำงานบนระบบปฏิบัติการ ที่มี JVM รองรับได้

ในการทำงานจริง JVM จะจัดการองค์ประกอบหลายส่วน ที่จำเป็นต่อการรันโปรแกรม เช่น การโหลด Class การตรวจสอบ Bytecode การจัดการหน่วยความจำ และการประมวลผลคำสั่ง เพื่อให้โปรแกรมสามารถทำงานต่อไปได้

JVM จึงเปรียบเสมือนตัวกลาง ระหว่าง Bytecode ของ Java กับสภาพแวดล้อมของเครื่องคอมพิวเตอร์ ทำให้ผู้พัฒนาไม่จำเป็นต้องเขียนโปรแกรม แยกเป็นคนละชุดสำหรับระบบปฏิบัติการ ทุกประเภท

4.5 จุดเริ่มต้นของโปรแกรม

สำหรับโปรแกรม Java ที่มีเมธอด main() การทำงานของโปรแกรม จะเริ่มต้นจากเมธอดดังกล่าว เมื่อมีการเรียกใช้ Class เพื่อ Run โปรแกรม

เมธอด main() จึงถือเป็นจุดเริ่มต้นที่สำคัญ ของโปรแกรม Java แบบทั่วไป โดยคำสั่งที่อยู่ภายในเมธอด จะถูกดำเนินการตามลำดับ จากนั้นจึงสามารถเรียกใช้ Method หรือ Class อื่น ๆ ตามโครงสร้างของโปรแกรม

5.2 การทำงานของแต่ละขั้นตอน

ขั้นตอนแรกคือการเขียน Source Code และบันทึกเป็นไฟล์ .java ในขั้นตอนนี้ผู้พัฒนาเป็นผู้กำหนด รูปแบบการทำงานของโปรแกรม เช่น การประกาศตัวแปร การรับข้อมูล การคำนวณ การตรวจสอบเงื่อนไข การวนซ้ำ และการแสดงผล

Source Code ถือเป็นต้นฉบับของโปรแกรม เพราะเป็นส่วนที่ผู้พัฒนาสามารถอ่าน ทำความเข้าใจ และแก้ไขได้ หากต้องการเปลี่ยนแปลงการทำงาน ของโปรแกรม ผู้พัฒนาจะต้องกลับมาแก้ไข Source Code ในส่วนที่เกี่ยวข้อง

ขั้นตอนที่สองคือการ Compile โดยใช้คำสั่ง javac เพื่อให้ Java Compiler อ่านและตรวจสอบ Source Code จากนั้นจึงสร้าง Bytecode ซึ่งจัดเก็บอยู่ในไฟล์ .class

การ Compile มีความสำคัญ เพราะเป็นขั้นตอนที่ช่วยตรวจสอบ ความถูกต้องของโครงสร้างคำสั่ง หาก Source Code มีข้อผิดพลาด Compiler จะแจ้งข้อมูล เพื่อให้ผู้พัฒนาสามารถแก้ไขปัญหา ก่อนที่จะนำโปรแกรมไป Run

ขั้นตอนที่สามคือการ Run โดยใช้คำสั่ง java เพื่อเรียกใช้งาน Class จากนั้น JVM จะโหลด และประมวลผล Bytecode ตามคำสั่งที่ถูกสร้างขึ้นจาก Source Code

ขั้นตอนสุดท้ายคือ การตรวจสอบ Output ว่าผลลัพธ์ที่ได้ตรงกับวัตถุประสงค์ ของโปรแกรมหรือไม่ หากผลลัพธ์ไม่ถูกต้อง ผู้พัฒนาต้องวิเคราะห์ว่า ปัญหาเกิดจากส่วนใดของโปรแกรม แล้วกลับไปแก้ไข Source Code ก่อน Compile และ Run ใหม่อีกครั้ง

ดังนั้น กระบวนการพัฒนาโปรแกรม ไม่ได้สิ้นสุดลงทันทีเมื่อ Compile สำเร็จ แต่ยังต้องมีการ Run และทดสอบ เพื่อยืนยันว่าโปรแกรมสามารถทำงาน ได้ตามที่ออกแบบไว้

การทดสอบผลลัพธ์ยังช่วยให้ผู้พัฒนา พบข้อผิดพลาดด้านตรรกะ ซึ่งบางครั้ง Compiler ไม่สามารถตรวจพบได้ เพราะคำสั่งอาจถูกต้องตามไวยากรณ์ แต่การคำนวณหรือขั้นตอนการทำงาน อาจไม่ตรงกับความต้องการ

5.3 หากโปรแกรมเกิดข้อผิดพลาด

ในกรณีที่ Compile ไม่สำเร็จ ผู้พัฒนาจะต้องกลับไปตรวจสอบ Source Code และแก้ไขข้อผิดพลาด จากนั้นจึง Compile ใหม่

ข้อผิดพลาดในขั้นตอน Compile มักเกี่ยวข้องกับรูปแบบคำสั่ง ไวยากรณ์ การประกาศตัวแปร ชนิดข้อมูล ชื่อ Class หรือโครงสร้างของโปรแกรม ผู้พัฒนาควรอ่านข้อความ Error อย่างละเอียดเพื่อหาต้นเหตุของปัญหา

หาก Compile สำเร็จ แต่เมื่อ Run แล้ว ผลลัพธ์ไม่เป็นไปตามที่ต้องการ ผู้พัฒนาจะต้องตรวจสอบตรรกะ และคำสั่งภายในโปรแกรม แล้วแก้ไขและทดสอบใหม่

การทำงานลักษณะนี้เรียกว่า การ Debug หรือการค้นหาและแก้ไขข้อผิดพลาด ซึ่งเป็นทักษะสำคัญของนักพัฒนาโปรแกรม เพราะโปรแกรมที่มีขนาดใหญ่ มักประกอบด้วยคำสั่งจำนวนมาก และอาจเกิดปัญหาได้จากหลายสาเหตุ

Source Code คือคำสั่งที่มนุษย์สามารถอ่าน และแก้ไขได้ง่าย ส่วน Bytecode เป็นผลลัพธ์ที่ได้จากการ Compile ซึ่งถูกออกแบบมาให้ JVM สามารถนำไปประมวลผลได้

Source Code จึงเป็นส่วนที่ผู้พัฒนา ใช้ในการสร้างและแก้ไขโปรแกรม ในขณะที่ Bytecode เป็นรูปแบบที่ถูกสร้างขึ้น เพื่อส่งต่อให้สภาพแวดล้อม ของ Java นำไปใช้งาน

หากต้องการเปลี่ยนแปลงการทำงาน ของโปรแกรม ผู้พัฒนาควรแก้ไข Source Code แล้ว Compile ใหม่ เพื่อสร้าง Bytecode ที่สอดคล้องกับคำสั่งล่าสุด ไม่ควรแก้ไขไฟล์ Bytecode โดยตรง

6.4 หมายเหตุเกี่ยวกับไฟล์ JAR

📌 หมายเหตุเกี่ยวกับ JAR

แต่สามารถใช้สำหรับ จัดแพ็กเกจไฟล์ Class และทรัพยากรต่าง ๆ ของโปรแกรมให้อยู่ในไฟล์เดียว

การจัดเก็บในรูปแบบ JAR ช่วยให้สามารถรวบรวมไฟล์ที่เกี่ยวข้อง กับโปรแกรมไว้ด้วยกัน และสะดวกต่อการนำไปใช้งานหรือแจกจ่าย

ในโปรแกรมที่มีหลาย Class หรือมีทรัพยากรประกอบ เช่น ไฟล์กำหนดค่า รูปภาพ หรือไฟล์ข้อมูล การรวมทรัพยากรเหล่านี้ไว้ใน JAR สามารถช่วยให้การจัดส่งโปรแกรม เป็นระเบียบมากขึ้น

7. สิ่งที่ต้องคำนึงก่อนเขียนโปรแกรมด้วยภาษา Java

ก่อนเริ่มเขียนโปรแกรมด้วยภาษา Java ควรตรวจสอบสภาพแวดล้อม และเครื่องมือที่จำเป็น ให้พร้อมก่อนเริ่มพัฒนาโปรแกรม เพื่อช่วยลดปัญหาที่อาจเกิดขึ้น ในขั้นตอน Compile และ Run

การเตรียมสภาพแวดล้อมที่เหมาะสม ช่วยให้ผู้เรียนสามารถแยกปัญหา ระหว่างปัญหาจาก Source Code กับปัญหาจากเครื่องมือได้ง่ายขึ้น เช่น หากคำสั่ง javac ไม่สามารถใช้งานได้ ปัญหาอาจเกิดจากการติดตั้ง JDK หรือการกำหนดค่า Environment ไม่ใช่ปัญหาจาก Source Code

7.1 ตรวจสอบ JDK และโปรแกรมสำหรับเขียน Source Code

  1. ต้องตรวจสอบว่าในเครื่องคอมพิวเตอร์มี JDK (Java Development Kit) และโปรแกรมที่ใช้เขียนซอร์สโค้ด (Source Code) เช่น โปรแกรม Notepad หรือโปรแกรม EditPlus หรือไม่

    หากไม่มีโปรแกรมดังกล่าว ควรติดตั้งให้เรียบร้อย ก่อนเริ่มพัฒนาโปรแกรม Java

    JDK เป็นส่วนสำคัญสำหรับผู้พัฒนา เพราะมีเครื่องมือที่เกี่ยวข้องกับ การ Compile และการพัฒนาโปรแกรม ในขณะที่ Text Editor ทำหน้าที่เป็นเครื่องมือสำหรับ สร้างและแก้ไข Source Code
💡 ข้อควรรู้

JDK เป็นเครื่องมือสำคัญ สำหรับการพัฒนาโปรแกรม Java เนื่องจากมีเครื่องมือที่จำเป็น สำหรับ Compile และพัฒนาโปรแกรม

7.2 ตรวจสอบ javac.exe และ java.exe

  1. ตรวจสอบโฟลเดอร์และไฟล์ของ JDK ที่ใช้ในการคอมไพล์ (Compile) คือ javac.exe และรันโปรแกรม (Run) คือ java.exe

    โปรแกรมทั้งสองมีหน้าที่แตกต่างกัน โดย javac ใช้สำหรับการ Compile Source Code ส่วน java ใช้สำหรับเรียกใช้งาน โปรแกรม Java ผ่าน JVM

    ตัวอย่างโฟลเดอร์ของไฟล์ Java เช่น 

    C:\j2sdk1.4.1_03\bin

7.3 การกำหนดค่าเครื่องมือ

  1. ทำการติดตั้งและแก้ไขโปรแกรม (Config) เครื่องมือในการเขียนโปรแกรม ด้วยโปรแกรม EditPlus ให้สามารถเรียกใช้คำสั่ง Java ได้อย่างถูกต้อง

    การกำหนดค่าเครื่องมือ มีความสำคัญเพราะช่วยให้โปรแกรม ที่ใช้เขียน Source Code สามารถเรียกใช้คำสั่ง Compile และ Run ได้อย่างสะดวก โดยไม่จำเป็นต้องพิมพ์คำสั่ง ทุกขั้นตอนด้วยตนเอง

7.3.1 ไปที่เมนู Tools

เลือก Tools → Preferences หรือเลือก Tools → Configure User Tools...

เมนูดังกล่าวใช้สำหรับตั้งค่าการทำงาน ของเครื่องมือที่ใช้พัฒนาโปรแกรม โดยผู้ใช้สามารถกำหนดคำสั่ง ที่ต้องการเรียกใช้งาน และตั้งค่าตำแหน่งของโปรแกรม ที่เกี่ยวข้องกับ Java

7.3.2 กำหนด User Toolbar

ไปที่เมนู Tools → User Tool Groups และไปที่ View → Toolbars/Views เลือก User Toolbar

การตั้งค่า Toolbar ช่วยให้ผู้ใช้สามารถเรียกใช้เครื่องมือ ที่ต้องการได้ง่ายขึ้น และสามารถจัดเตรียมคำสั่ง สำหรับ Compile หรือ Run ให้เหมาะกับรูปแบบการทำงานของตนเอง

7.4 สร้างโฟลเดอร์สำหรับ Source Code

ควรสร้างโฟลเดอร์ สำหรับจัดเก็บไฟล์ Source Code โดยเฉพาะ เพื่อให้สามารถค้นหา และจัดการไฟล์โปรแกรมได้ง่าย

การจัดเก็บไฟล์อย่างเป็นระบบ มีความสำคัญเมื่อโปรแกรมมีหลายไฟล์ เพราะช่วยลดปัญหาการสับสน และช่วยให้สามารถระบุตำแหน่ง ของ Source Code ได้อย่างรวดเร็ว

ตัวอย่างเช่น D:\work 

D:\work

7.5 เลือก Directory

เลือก Directory ในโปรแกรม EditPlus ให้ถูกต้องเพื่อใช้อ้างอิง ตำแหน่งของไฟล์ Source Code ในการ Compile และ Run โปรแกรม

หากเลือก Directory ไม่ถูกต้อง โปรแกรมอาจไม่สามารถค้นหาไฟล์ Source Code ที่ต้องการได้ ดังนั้นผู้พัฒนาควรตรวจสอบ ตำแหน่งไฟล์ก่อนใช้คำสั่ง Compile และ Run ทุกครั้ง

7.6 สร้างและกำหนดโฟลเดอร์สำหรับจัดเก็บ Source Code

สร้างและกำหนดโฟลเดอร์สำหรับจัดเก็บไฟล์ Source Code ให้เรียบร้อย เพื่อให้สามารถอ้างอิงตำแหน่งไฟล์ ในการ Compile และ Run โปรแกรมได้ถูกต้อง

การจัดเก็บไฟล์อย่างเป็นระบบ ยังช่วยลดปัญหาการหาไฟล์ไม่พบ และช่วยให้สามารถจัดการ โปรแกรมหลายไฟล์ได้ง่ายขึ้น

เมื่อโปรแกรมมีขนาดใหญ่ขึ้น การแยกไฟล์ตามหน้าที่ และจัดเก็บไว้ในตำแหน่งที่เหมาะสม จะช่วยให้การพัฒนา การแก้ไข และการสำรองข้อมูล ทำได้สะดวกมากขึ้น

7.7 การสร้างโปรแกรม Java

ทดสอบโปรแกรม Java โดยไปที่เมนู File → New → Java

หลังจากสร้างไฟล์ใหม่แล้ว ผู้พัฒนาสามารถเริ่มเขียน Source Code ตามโครงสร้างของภาษา Java และบันทึกไฟล์ในรูปแบบ .java เพื่อเตรียมเข้าสู่ขั้นตอน Compile

7.7.1 ตั้งชื่อ Class

ตั้งชื่อ Class เช่น TestJava

ควรเลือกชื่อที่สื่อความหมาย และต้องคำนึงถึงกฎการตั้งชื่อ ของภาษา Java โดยเฉพาะความสัมพันธ์ ระหว่างชื่อ public class กับชื่อไฟล์

7.7.2 บันทึกไฟล์

บันทึกไฟล์ชื่อเดียวกับชื่อ Class เช่น TestJava.java

หลังจากบันทึกควรตรวจสอบว่า ไฟล์ถูกจัดเก็บใน Directory ที่ต้องการจริง และตรวจสอบนามสกุลไฟล์ ว่าเป็น .java อย่างถูกต้อง

7.7.3 Compile โปรแกรม

เลือก Tools → Compile เพื่อคอมไพล์โปรแกรม

หลังจาก Compile ควรตรวจสอบผลลัพธ์ หากไม่มี Error โดยทั่วไปจะได้ไฟล์ .class ที่สามารถนำไปใช้ในขั้นตอน Run

7.7.4 Run โปรแกรม

เลือก Tools → Run เพื่อรันโปรแกรม

เมื่อ Run โปรแกรม JVM จะเข้ามาประมวลผล Bytecode และโปรแกรมจะแสดงผลลัพธ์ ตามคำสั่งที่ผู้พัฒนาเขียนไว้

7.8 การตรวจสอบโปรแกรมก่อน Run

ก่อน Run โปรแกรม ควรตรวจสอบว่าไฟล์ Source Code ถูกบันทึกเรียบร้อยแล้ว และการ Compile ไม่มีข้อผิดพลาด

  • ตรวจสอบชื่อไฟล์
  • ตรวจสอบชื่อ Class
  • ตรวจสอบเมธอด main()
  • ตรวจสอบข้อความ Error จากการ Compile
  • ตรวจสอบตำแหน่งของไฟล์

การตรวจสอบก่อน Run ช่วยลดปัญหาที่เกิดจากการตั้งค่า หรือการเตรียมไฟล์ไม่ถูกต้อง และช่วยให้ผู้พัฒนาสามารถแยกปัญหา ระหว่าง Compile Error กับปัญหาที่เกิดขึ้นระหว่างการทำงานจริง ของโปรแกรมได้ง่ายขึ้น

8. สรุปบทเรียน

8.1 สรุปกระบวนการพัฒนาโปรแกรม Java

การพัฒนาโปรแกรม Java เริ่มจากการเขียน Source Code และบันทึกเป็นไฟล์ .java

Source Code เป็นส่วนที่ผู้พัฒนา ใช้สำหรับกำหนดการทำงานของโปรแกรม และเป็นส่วนที่สามารถแก้ไข และปรับปรุงได้โดยตรง

จากนั้นใช้คำสั่ง javac เพื่อ Compile Source Code ให้เป็น Bytecode ซึ่งจัดเก็บในไฟล์ .class

การ Compile ยังเป็นขั้นตอน สำหรับตรวจสอบ Source Code และค้นหาข้อผิดพลาดด้านไวยากรณ์ ก่อนนำโปรแกรมไป Run

เมื่อ Compile สำเร็จ จึงใช้คำสั่ง java เพื่อ Run โปรแกรม โดย JVM จะทำหน้าที่ ประมวลผล Bytecode และแสดงผลลัพธ์ของโปรแกรม

หลังจากได้ Output แล้ว ผู้พัฒนาต้องตรวจสอบว่า ผลลัพธ์ตรงกับวัตถุประสงค์หรือไม่ หากไม่ตรงตามที่ต้องการ จะต้องกลับไปตรวจสอบ Source Code แก้ไข และทำกระบวนการ Compile และ Run ใหม่อีกครั้ง

8.3 ตารางสรุปคำศัพท์สำคัญ

Compile

กระบวนการตรวจสอบและแปลง Source Code ให้เป็น Bytecode

Bytecode

JVM

8.5 สิ่งที่นักเรียนควรเข้าใจหลังจบบทเรียน

หลังจากศึกษาเนื้อหาในบทนี้ นักเรียนควรสามารถอธิบาย ขั้นตอนพื้นฐานของการพัฒนาโปรแกรม Java ได้ตั้งแต่การสร้าง Source Code การ Compile การสร้าง Bytecode และการ Run โปรแกรมผ่าน JVM

นอกจากการจำคำสั่งแล้ว นักเรียนควรเข้าใจความสัมพันธ์ ระหว่างแต่ละขั้นตอน ว่า Source Code เป็นจุดเริ่มต้น ของการพัฒนา Compiler ทำหน้าที่ตรวจสอบ และสร้าง Bytecode ส่วน JVM ทำหน้าที่นำ Bytecode ไปประมวลผล จนเกิดเป็น Output

  • อธิบายความหมายของ Source Code ได้
  • อธิบายหน้าที่ของคำสั่ง javac ได้
  • อธิบายความหมายของ Bytecode ได้
  • อธิบายหน้าที่ของไฟล์ .class ได้
  • ใช้คำสั่ง java สำหรับ Run โปรแกรมได้
  • อธิบายบทบาทของ JVM ในการทำงานของโปรแกรม Java ได้
  • สามารถตรวจสอบปัญหาเบื้องต้น เมื่อ Compile โปรแกรมไม่สำเร็จได้
🎯 สรุปท้ายบท

การพัฒนาโปรแกรม Java มีขั้นตอนที่สำคัญตั้งแต่ การเขียน Source Code การ Compile การสร้าง Bytecode และการ Run ผ่าน JVM

Source Code เป็นส่วนที่ผู้พัฒนาเขียน และสามารถแก้ไขได้ จากนั้น Java Compiler จะตรวจสอบและแปลง Source Code เป็น Bytecode ซึ่งจัดเก็บในไฟล์ .class

เมื่อ Run โปรแกรม JVM จะนำ Bytecode ไปประมวลผล และสร้างผลลัพธ์ ที่ผู้ใช้สามารถมองเห็นได้

หากผลลัพธ์ไม่ถูกต้อง ผู้พัฒนาสามารถกลับไปตรวจสอบ Source Code แก้ไขปัญหา Compile ใหม่ และ Run ใหม่ กระบวนการนี้สามารถทำซ้ำ จนกว่าโปรแกรมจะทำงาน ได้ตามวัตถุประสงค์

หากเข้าใจลำดับ

Source Code → Compile → Bytecode → JVM → Output

จะสามารถนำความรู้พื้นฐานนี้ ไปต่อยอดในการเรียนเรื่อง ตัวแปร ชนิดข้อมูล การรับข้อมูล เงื่อนไข การวนซ้ำ Array Method Class และ Object ในบทถัดไปได้
