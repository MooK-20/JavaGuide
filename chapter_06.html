Arrays และการจัดการข้อมูลแบบ Array

6.1 ความหมายของ Array

Array หรืออาร์เรย์ คือ โครงสร้างข้อมูลที่ใช้สำหรับเก็บข้อมูลหลายค่า ที่มีชนิดข้อมูลเดียวกันไว้ภายใต้ชื่อตัวแปรเดียว การใช้ Array ช่วยลดจำนวนตัวแปรที่ต้องประกาศแยกกัน และทำให้สามารถจัดการข้อมูลจำนวนมากได้สะดวกมากขึ้น

ข้อมูลแต่ละค่าภายใน Array จะถูกจัดเก็บตามลำดับ และสามารถเข้าถึงข้อมูลแต่ละตำแหน่งได้ด้วย Index ซึ่งเริ่มต้นจาก 0 เช่น ข้อมูลตัวแรกจะอยู่ที่ Index 0 และข้อมูลตัวถัดไปจะอยู่ที่ Index 1

ในภาษา Java Array จะมีขนาดที่กำหนดไว้ตั้งแต่ตอนสร้าง และสมาชิกภายใน Array จะต้องเป็นชนิดข้อมูลเดียวกัน เช่น int[] ใช้สำหรับเก็บจำนวนเต็มหลายค่า หรือ String[] ใช้สำหรับเก็บข้อความหลายค่า

ตัวอย่างเช่น หากต้องการเก็บคะแนน ของนักเรียน 5 คน เราสามารถใช้ Array ชื่อ scores แทนการสร้างตัวแปร score1, score2, score3, score4 และ score5

💡 แนวคิดสำคัญ

Array สามารถมองได้เหมือน "กล่องหลายช่องที่ใช้ชื่อเดียวกัน" แต่ละช่องจะมีตำแหน่งหรือ Index สำหรับเข้าถึงข้อมูล
🎯 จุดประสงค์การเรียนรู้
  • อธิบายความหมายของ Array ได้
  • อธิบายการทำงานของ Index ได้
  • สามารถประกาศและสร้าง Array ได้
  • สามารถกำหนดค่าเริ่มต้นให้ Array ได้
  • สามารถเข้าถึงและแก้ไขข้อมูลใน Array ได้
  • สามารถใช้ Loop ร่วมกับ Array ได้
  • สามารถคำนวณข้อมูลภายใน Array ได้
  • สามารถใช้งาน Array ชนิด String ได้
  • เข้าใจ Array 2 มิติในระดับพื้นฐาน

6.2 โครงสร้างของ Array

Array ในภาษา Java จะเก็บข้อมูลหลายค่าไว้ในตัวแปรเดียว โดยข้อมูลแต่ละค่าจะมีตำแหน่งที่เรียกว่า Index สำหรับใช้ระบุตำแหน่งและเข้าถึงข้อมูลภายใน Array

ข้อมูลภายใน Array จะถูกจัดเก็บตามลำดับ โดยแต่ละข้อมูลจะมีตำแหน่งของตัวเอง ทำให้โปรแกรมสามารถเลือกเข้าถึงข้อมูล ที่ต้องการได้อย่างชัดเจน การเข้าถึงข้อมูลจะใช้ชื่อของ Array ตามด้วย Index ที่อยู่ภายในเครื่องหมาย [ ]

Index จะเริ่มต้นที่ 0 ไม่ใช่ 1 ดังนั้นข้อมูลตัวแรกจะอยู่ที่ Index 0 ข้อมูลตัวที่สองอยู่ที่ Index 1 และเพิ่มขึ้นตามลำดับ ตัวอย่างเช่น หาก Array มีข้อมูล 5 ค่า ตำแหน่งของข้อมูลจะเริ่มตั้งแต่ Index 0 ไปจนถึง Index 4

การที่ Index เริ่มต้นจาก 0 เป็นหลักการสำคัญของ Array ในภาษา Java ผู้เขียนโปรแกรมจึงควรทำความเข้าใจเรื่อง Index ให้ถูกต้อง เพราะหากระบุตำแหน่งผิด อาจทำให้โปรแกรมเกิดข้อผิดพลาด ขณะทำงานได้

จำนวนสมาชิกของ Array เรียกว่า ขนาดของ Array หรือสามารถตรวจสอบได้ด้วย คุณสมบัติ length ซึ่งจะบอกจำนวนสมาชิกทั้งหมดที่ Array สามารถเก็บได้ อย่างไรก็ตาม ค่า length ไม่ใช่ Index สุดท้าย เนื่องจาก Index เริ่มต้นที่ 0 ดังนั้น Index สุดท้ายจึงมีค่าเท่ากับ length - 1

ตัวอย่างเช่น หากสร้าง Array ที่มีจำนวนสมาชิกทั้งหมด 5 ค่า ค่า length จะเท่ากับ 5 แต่ Index ที่สามารถเข้าถึงได้จะอยู่ระหว่าง 0 ถึง 4 โดย Index 0 เป็นตำแหน่งแรก และ Index 4 เป็นตำแหน่งสุดท้าย

จากตัวอย่างข้างต้น หาก Array ชื่อ numbers มีข้อมูลจำนวน 5 ค่า เราสามารถเข้าถึงข้อมูลแต่ละตำแหน่งได้ เช่น numbers[0] สำหรับข้อมูลตัวแรก numbers[1] สำหรับข้อมูลตัวที่สอง และสามารถเข้าถึงข้อมูลตัวสุดท้ายด้วย numbers[4]

Index ไม่ได้ใช้สำหรับการอ่านข้อมูลเพียงอย่างเดียว แต่ยังสามารถใช้ในการเปลี่ยนแปลงค่าของข้อมูล ที่อยู่ภายใน Array ได้อีกด้วย โดยระบุ Index ของตำแหน่งที่ต้องการ แล้วกำหนดค่าใหม่ให้กับตำแหน่งนั้น

ตัวอย่างเช่น หากต้องการเปลี่ยนข้อมูล ในตำแหน่ง Index 2 โปรแกรมสามารถระบุ numbers[2] แล้วกำหนดค่าใหม่ได้ โดยจำนวนสมาชิกของ Array จะยังคงเท่าเดิม เปลี่ยนเฉพาะค่าของข้อมูลในตำแหน่งนั้น

การเข้าใจโครงสร้างของ Index มีความสำคัญอย่างมากเมื่อทำงานร่วมกับ for Loop เนื่องจากตัวแปรที่ใช้ควบคุม Loop สามารถทำหน้าที่เป็น Index เพื่อเข้าถึงข้อมูลแต่ละตำแหน่งของ Array ได้ทีละค่า

ตัวอย่างเช่น หาก Array มีสมาชิก 5 ค่า โปรแกรมสามารถใช้ตัวแปร i เริ่มต้นจาก 0 แล้วเพิ่มค่าทีละ 1 เพื่อเข้าถึงข้อมูลตั้งแต่ Index 0, 1, 2, 3 และ 4 โดยใช้เงื่อนไข i < numbers.length

วิธีการนี้ช่วยให้สามารถจัดการข้อมูลจำนวนมาก ได้อย่างเป็นระบบ โดยไม่จำเป็นต้องเขียนคำสั่งแยกสำหรับข้อมูล แต่ละตำแหน่ง และยังสามารถนำไปประยุกต์ใช้กับการค้นหา การคำนวณ และการแสดงผลข้อมูลภายใน Array ได้

⚠️ ข้อควรระวังเกี่ยวกับ Index

หาก Array มีสมาชิก 5 ค่า จะสามารถใช้ Index ได้ตั้งแต่ 0 ถึง 4 เท่านั้น

ไม่สามารถเข้าถึง Index 5 ได้ เพราะ Index 5 อยู่นอกขอบเขตของ Array ซึ่งอาจทำให้โปรแกรมเกิดข้อผิดพลาด ArrayIndexOutOfBoundsException

ดังนั้นควรตรวจสอบจำนวนสมาชิกของ Array และกำหนดเงื่อนไขการเข้าถึง Index ให้ถูกต้องเสมอ

สรุปได้ว่า Array ประกอบด้วย ชื่อของ Array ข้อมูลที่จัดเก็บ และตำแหน่ง Index ของข้อมูลแต่ละค่า โดย Index จะเริ่มต้นจาก 0 และเพิ่มขึ้นทีละ 1 ตามลำดับ การเข้าถึงข้อมูลจะใช้รูปแบบ ชื่อArray[Index]

เมื่อเข้าใจเรื่อง Index แล้ว จะสามารถนำความรู้ไปใช้ในการประกาศ Array การเข้าถึงข้อมูล การแก้ไขข้อมูล การใช้ length รวมถึงการใช้ Loop เพื่อประมวลผลข้อมูลหลายค่า ได้อย่างถูกต้องและมีประสิทธิภาพ

Array จะมีจำนวนสมาชิกหรือ ขนาด (Length) ที่กำหนดไว้ และสามารถใช้ Index เพื่อเข้าถึงหรือเปลี่ยนแปลงข้อมูลในแต่ละตำแหน่งได้

ตัวอย่างเช่น Array ที่มีข้อมูล 4 ค่า จะมีตำแหน่งตั้งแต่ Index 0 จนถึง Index 3 เนื่องจาก Index สุดท้ายจะเท่ากับ จำนวนสมาชิก - 1

6.3 การประกาศ Array

การประกาศ Array สามารถเขียนได้หลายรูปแบบ โดยรูปแบบพื้นฐานคือการกำหนดชนิดข้อมูล ตามด้วยเครื่องหมาย [] และชื่อ Array การประกาศในลักษณะนี้เป็นการกำหนดให้ตัวแปร สามารถใช้สำหรับอ้างอิงข้อมูลประเภท Array ได้

การประกาศ Array เป็นการบอกโปรแกรมว่า ต้องการสร้างตัวแปรสำหรับเก็บข้อมูลหลายค่า โดยข้อมูลภายใน Array จะต้องเป็นชนิดข้อมูลเดียวกัน เช่น int สำหรับจำนวนเต็ม double สำหรับตัวเลขทศนิยม char สำหรับตัวอักษร หรือ String สำหรับข้อความ

เครื่องหมาย [] ที่อยู่หลังชนิดข้อมูล เป็นส่วนที่ใช้ระบุว่าตัวแปรดังกล่าวเป็น Array เช่น int[] หมายถึง Array ที่สามารถเก็บข้อมูลชนิดจำนวนเต็ม ส่วน String[] หมายถึง Array ที่ใช้สำหรับเก็บข้อมูลประเภทข้อความ

ชื่อของ Array สามารถตั้งได้ตามกฎการตั้งชื่อตัวแปร ของภาษา Java โดยควรตั้งชื่อให้สื่อความหมายถึงข้อมูล ที่ต้องการจัดเก็บ เช่น numbers สำหรับเก็บตัวเลข scores สำหรับเก็บคะแนน names สำหรับเก็บรายชื่อ และ prices สำหรับเก็บราคาสินค้า

การประกาศ Array เพียงอย่างเดียว ยังไม่ได้กำหนดจำนวนสมาชิกของ Array และยังไม่ได้สร้างพื้นที่สำหรับจัดเก็บข้อมูล เนื่องจากขั้นตอนการประกาศเป็นเพียงการกำหนดชนิด และชื่อของตัวแปรเท่านั้น หากต้องการนำ Array ไปใช้งานจริง จะต้องสร้าง Array และกำหนดขนาด หรือกำหนดค่าเริ่มต้นให้กับ Array ต่อไป

ตัวอย่างเช่น การเขียน int[] numbers; เป็นเพียงการประกาศตัวแปรชื่อ numbers ให้เป็น Array ชนิด int ซึ่งสามารถใช้สำหรับเก็บข้อมูลจำนวนเต็มหลายค่าได้ แต่ในขั้นตอนนี้ยังไม่มีการกำหนดว่า Array จะมีสมาชิกจำนวนกี่ตัว

การประกาศ Array สามารถเขียนเครื่องหมาย [] ไว้หลังชนิดข้อมูลได้ เช่น int[] numbers; ซึ่งเป็นรูปแบบที่นิยมใช้และอ่านง่าย นอกจากนี้ Java ยังอนุญาตให้เขียน int numbers[]; ได้เช่นกัน โดยทั้งสองรูปแบบหมายถึง Array ชนิดเดียวกัน 

int[] numbers;

int numbers[];

แม้ว่าทั้งสองรูปแบบจะสามารถใช้งานได้เหมือนกัน แต่โดยทั่วไปมักนิยมเขียนเครื่องหมาย [] ติดกับชนิดข้อมูล เช่น int[] numbers; เพราะช่วยให้เห็นได้อย่างชัดเจนว่า ตัวแปรที่ประกาศเป็น Array และทำให้รูปแบบของโค้ดอ่านง่ายขึ้น

นอกจากชนิดข้อมูล int แล้ว Java ยังสามารถประกาศ Array สำหรับข้อมูลชนิดอื่นได้อีกหลายชนิด เช่น double, float, char, boolean และ String โดยชนิดข้อมูลที่กำหนดไว้ จะเป็นตัวกำหนดว่าข้อมูลประเภทใด สามารถนำมาเก็บใน Array ได้ 

int[] numbers;

double[] prices;

char[] letters;

boolean[] status;

String[] names;

จากตัวอย่าง numbers สามารถใช้เก็บข้อมูลชนิดจำนวนเต็ม prices สามารถใช้เก็บข้อมูลตัวเลขทศนิยม letters สามารถใช้เก็บตัวอักษร status สามารถใช้เก็บค่าจริงหรือเท็จ และ names สามารถใช้เก็บข้อความหรือชื่อบุคคลได้

การเลือกชนิดข้อมูลให้เหมาะสม เป็นสิ่งสำคัญในการออกแบบ Array เพราะสมาชิกภายใน Array จะต้องเป็นชนิดข้อมูลที่สอดคล้องกับ ชนิดข้อมูลที่ประกาศไว้ เช่น หากประกาศเป็น int[] สมาชิกของ Array จะต้องเป็นข้อมูลจำนวนเต็ม

ในทางกลับกัน หากประกาศเป็น String[] สมาชิกภายใน Array จะใช้สำหรับจัดเก็บข้อความ เช่น ชื่อนักเรียน ชื่อสินค้า ชื่อจังหวัด หรือข้อมูลข้อความอื่น ๆ ที่ต้องการจัดเก็บไว้หลายรายการ

💡 จำง่าย ๆ

ชนิดข้อมูล → กำหนดประเภทของข้อมูล
[] → ระบุว่าเป็น Array
ชื่อ Array → ชื่อที่ใช้สำหรับอ้างอิง Array

ตัวอย่าง
int[] scores;

int = ชนิดข้อมูลจำนวนเต็ม
[] = ระบุว่าเป็น Array

เมื่อประกาศ Array แล้ว ขั้นตอนต่อไปคือการสร้าง Array เพื่อกำหนดพื้นที่สำหรับจัดเก็บข้อมูล โดยสามารถใช้คำสั่ง new พร้อมกับระบุชนิดข้อมูล และจำนวนสมาชิกที่ต้องการ

ตัวอย่างเช่น int[] numbers = new int[5]; เป็นการประกาศและสร้าง Array ชื่อ numbers ที่สามารถจัดเก็บข้อมูลชนิด int ได้จำนวน 5 ค่า โดย Index จะเริ่มต้นตั้งแต่ 0 และสิ้นสุดที่ Index 4 

int[] numbers = new int[5];

อีกวิธีหนึ่งคือสามารถประกาศ Array พร้อมกำหนดค่าเริ่มต้นได้ทันที โดยใช้เครื่องหมายปีกกา { } ภายในจะระบุข้อมูลแต่ละค่าที่ต้องการจัดเก็บ และโปรแกรมจะกำหนดขนาดของ Array ตามจำนวนข้อมูลที่ระบุไว้ 

int[] numbers = {
    10, 20, 30, 40, 50
};

จากตัวอย่าง Array numbers มีข้อมูลทั้งหมด 5 ค่า ดังนั้น Array จะมีขนาดเท่ากับ 5 และสามารถเข้าถึงข้อมูลได้ตั้งแต่ Index 0 ถึง Index 4

การประกาศ Array ที่ถูกต้อง จึงควรพิจารณาทั้งชนิดข้อมูล ชื่อของ Array และรูปแบบการสร้าง Array ให้เหมาะสมกับข้อมูลที่ต้องการจัดเก็บ เพื่อให้สามารถนำ Array ไปใช้กับคำสั่งอื่น ๆ เช่น การเข้าถึงข้อมูล การแก้ไขข้อมูล และการใช้ Loop ได้อย่างถูกต้อง

6.4 การสร้าง Array ด้วย new

หลังจากประกาศ Array แล้ว ขั้นตอนต่อไปคือการสร้าง Array เพื่อจองพื้นที่สำหรับจัดเก็บข้อมูล โดยในภาษา Java สามารถใช้คำสั่ง new ในการสร้าง Array ได้

คำสั่ง new มีหน้าที่สร้างพื้นที่ ในหน่วยความจำสำหรับจัดเก็บสมาชิกของ Array ทำให้โปรแกรมสามารถเตรียมตำแหน่งสำหรับ เก็บข้อมูลตามจำนวนที่ผู้เขียนโปรแกรมกำหนดไว้

ในขั้นตอนการสร้าง Array ผู้เขียนโปรแกรมจะต้องระบุ ชนิดข้อมูล และ จำนวนสมาชิก ที่ต้องการจัดเก็บภายใน Array เช่น หากต้องการเก็บข้อมูลจำนวนเต็ม 5 ค่า สามารถสร้าง Array ชนิด int ที่มีขนาด 5 สมาชิกได้

จำนวนที่อยู่ภายในเครื่องหมาย [ ] จะเป็นตัวกำหนดขนาดของ Array หรือจำนวนสมาชิกที่สามารถจัดเก็บได้ เมื่อสร้าง Array แล้ว ขนาดของ Array จะถูกกำหนดไว้ และไม่สามารถเพิ่มหรือลดจำนวนสมาชิก โดยตรงได้

ตัวอย่างเช่น new int[5] หมายถึงการสร้างพื้นที่สำหรับ Array ชนิด int จำนวน 5 ตำแหน่ง โดยตำแหน่งต่าง ๆ จะถูกระบุด้วย Index ซึ่งเริ่มต้นจาก 0

ดังนั้น Array ที่มีขนาด 5 สมาชิก จะมี Index ตั้งแต่ 0, 1, 2, 3 และ 4 โดย Index 0 เป็นตำแหน่งแรก และ Index 4 เป็นตำแหน่งสุดท้าย

เมื่อสร้าง Array ด้วยคำสั่ง new แล้ว สามารถกำหนดข้อมูลให้กับแต่ละตำแหน่ง ภายหลังได้ โดยใช้ชื่อ Array ร่วมกับ Index ที่ต้องการ เช่น numbers[0] หมายถึงสมาชิกตำแหน่งแรกของ Array

ตัวเลขภายใน [ ] คือจำนวนสมาชิกที่ Array สามารถเก็บได้

ส่วน Index ใช้สำหรับระบุตำแหน่งของข้อมูล โดย Index จะเริ่มต้นที่ 0

รูปแบบพื้นฐานของการสร้าง Array ด้วยคำสั่ง new สามารถเขียนได้ดังนี้

เนื่องจาก Index ของ Array ในภาษา Java เริ่มต้นที่ 0 ดังนั้นเมื่อมีสมาชิกจำนวน 5 ค่า ตำแหน่งที่สามารถใช้งานได้จะเป็น 0, 1, 2, 3 และ 4

6.5 การกำหนดค่าเริ่มต้นให้ Array

เราสามารถกำหนดข้อมูลให้ Array ตั้งแต่ตอนประกาศได้ โดยใช้เครื่องหมาย { } เพื่อระบุค่าที่ต้องการจัดเก็บ

วิธีนี้ช่วยให้สามารถสร้าง Array พร้อมกับกำหนดข้อมูลเริ่มต้นได้ในคำสั่งเดียว โดยไม่จำเป็นต้องใช้คำสั่ง new และกำหนดค่าให้แต่ละ Index แยกกัน

ค่าที่อยู่ภายในเครื่องหมาย { } จะถูกจัดเก็บลงใน Array ตามลำดับที่กำหนด โดยข้อมูลตัวแรกจะถูกเก็บไว้ที่ Index 0 ข้อมูลตัวที่สองจะอยู่ที่ Index 1 และเพิ่มขึ้นตามลำดับ

จำนวนข้อมูลที่กำหนดไว้ภายใน { } จะเป็นตัวกำหนดจำนวนสมาชิก หรือขนาดของ Array โดยอัตโนมัติ ดังนั้นผู้เขียนโปรแกรมไม่จำเป็นต้อง ระบุจำนวนสมาชิกแยกอีกครั้ง

นอกจากนี้ Array ที่กำหนดค่าเริ่มต้นแล้ว ยังสามารถนำไปใช้งานร่วมกับ for Loop หรือ Enhanced for Loop เพื่ออ่านข้อมูลทุกตำแหน่งได้ ทำให้เหมาะสำหรับการจัดการข้อมูล หลายรายการภายในโปรแกรม

6.6 การเข้าถึงข้อมูลใน Array

การเข้าถึงข้อมูลใน Array สามารถทำได้โดยระบุชื่อ Array และ Index ที่ต้องการภายใน เครื่องหมาย [ ]

Index ทำหน้าที่ระบุตำแหน่งของข้อมูล ที่อยู่ภายใน Array โดย Index ของ Array ในภาษา Java จะเริ่มต้นจาก 0 ดังนั้นสมาชิกตัวแรกจะอยู่ที่ Index 0 สมาชิกตัวที่สองจะอยู่ที่ Index 1 และเพิ่มขึ้นตามลำดับ

รูปแบบการเข้าถึงข้อมูลใน Array สามารถเขียนได้ดังนี้ 

ชื่อArray[Index]

ตัวอย่างเช่น หากมี Array ชื่อ numbers ที่เก็บข้อมูลจำนวนเต็ม สามารถระบุ Index เพื่ออ่านข้อมูล แต่ละตำแหน่งได้ 

int[] numbers = {10, 20, 30, 40, 50};

System.out.println(numbers[0]);
System.out.println(numbers[2]);
System.out.println(numbers[4]);

จากตัวอย่าง numbers[0] หมายถึงข้อมูลที่อยู่ในตำแหน่งแรก ซึ่งมีค่าเท่ากับ 10 ส่วน numbers[2] หมายถึงข้อมูลตำแหน่งที่สาม ซึ่งมีค่าเท่ากับ 30

สำหรับ numbers[4] หมายถึงข้อมูลตำแหน่งที่ห้า ซึ่งมีค่าเท่ากับ 50 เนื่องจาก Array เริ่มนับ Index จาก 0 ไม่ใช่ 1

การนำข้อมูลใน Array ไปคำนวณ

ข้อมูลที่เข้าถึงจาก Array สามารถนำไปใช้ในการคำนวณได้เหมือนกับ ตัวแปรทั่วไป เช่น การบวก ลบ คูณ หรือหาร ทั้งนี้ต้องคำนึงถึงชนิดข้อมูล ของสมาชิกใน Array 

int[] numbers = {10, 20, 30};

int result = numbers[0] + numbers[1];

System.out.println(result);

โปรแกรมจะนำค่า numbers[0] ซึ่งเท่ากับ 10 มาบวกกับ numbers[1] ซึ่งเท่ากับ 20 ทำให้ผลลัพธ์ที่ได้คือ 30

6.7 การเปลี่ยนแปลงข้อมูลใน Array

ข้อมูลภายใน Array สามารถแก้ไขได้ โดยระบุ Index ที่ต้องการ แล้วกำหนดค่าใหม่ให้กับตำแหน่งนั้น

การแก้ไขข้อมูลใน Array เป็นการเปลี่ยนค่าของสมาชิกที่มีอยู่เดิม โดยไม่จำเป็นต้องสร้าง Array ใหม่ วิธีการทำงานคือระบุชื่อ Array ตามด้วย Index ที่ต้องการแก้ไข จากนั้นใช้เครื่องหมาย = เพื่อกำหนดค่าใหม่ให้กับสมาชิก

รูปแบบการแก้ไขข้อมูลใน Array สามารถเขียนได้ดังนี้ 

ชื่อArray[Index] = ค่าใหม่;

ตัวอย่างเช่น มี Array ชื่อ numbers ที่เก็บข้อมูลจำนวนเต็ม จำนวน 3 ค่า ได้แก่ 10, 20 และ 30 หากต้องการเปลี่ยนค่าที่ Index 1 สามารถกำหนดค่าใหม่ให้กับ numbers[1] ได้โดยตรง 

int[] numbers = {10, 20, 30};

numbers[1] = 99;

ก่อนการแก้ไข numbers[1] มีค่าเท่ากับ 20 เมื่อโปรแกรมทำงานตามคำสั่ง numbers[1] = 99; ค่า 20 จะถูกแทนที่ด้วยค่า 99 ทำให้ข้อมูลใน Array เปลี่ยนเป็น 10, 99 และ 30

ตัวอย่าง

หลักการทำงานของการแก้ไขข้อมูล

การแก้ไขข้อมูลใน Array จะทำงานกับสมาชิกที่อยู่ในตำแหน่ง Index ที่ระบุเท่านั้น สมาชิกในตำแหน่งอื่นจะไม่ถูกเปลี่ยนแปลง หากไม่มีคำสั่งให้แก้ไข

ตัวอย่างเช่น Array numbers มีข้อมูล 5 ค่า และต้องการเปลี่ยนเฉพาะข้อมูล ที่ Index 2 โปรแกรมจะเปลี่ยนเฉพาะสมาชิก ในตำแหน่งดังกล่าว ส่วน Index 0, 1, 3 และ 4 จะยังคงมีค่าเดิม 

int[] numbers = {10, 20, 30, 40, 50};

numbers[2] = 100;

หลังจากคำสั่งทำงาน Array จะมีข้อมูลเป็น 10, 20, 100, 40, 50 เนื่องจากค่าที่ Index 2 ซึ่งเดิมเป็น 30 ถูกเปลี่ยนเป็น 100

การแก้ไขข้อมูลตาม Index

เนื่องจาก Index ของ Array เริ่มต้นที่ 0 จึงต้องระบุตำแหน่งให้ถูกต้อง ก่อนแก้ไขข้อมูล เช่น หากต้องการแก้ไขข้อมูลตัวแรก ต้องใช้ Index 0 หากต้องการแก้ไขข้อมูลตัวที่สอง ต้องใช้ Index 1

Index ข้อมูลเดิม คำสั่งแก้ไข ข้อมูลใหม่
0 10 numbers[0] = 100; 100
1 20 numbers[1] = 200; 200
2 30 numbers[2] = 300; 300

จากตัวอย่างจะเห็นว่า การระบุ Index เป็นส่วนสำคัญ ของการแก้ไขข้อมูล เพราะ Index จะเป็นตัวบอกว่า ต้องการเปลี่ยนสมาชิกในตำแหน่งใด ของ Array

หมายถึง นำค่า 100 ไปแทนที่ข้อมูลเดิม ที่อยู่ใน Index 2

การแก้ไขข้อมูลหลายตำแหน่ง

หากต้องการแก้ไขข้อมูลมากกว่าหนึ่งตำแหน่ง สามารถเขียนคำสั่งกำหนดค่าใหม่ ให้กับแต่ละ Index ได้ โดยแต่ละคำสั่งจะทำการเปลี่ยนแปลง ข้อมูลในตำแหน่งที่ระบุ 

int[] numbers = {10, 20, 30, 40, 50};

numbers[0] = 100;
numbers[2] = 300;
numbers[4] = 500;

หลังจากทำงานตามคำสั่ง ข้อมูลใน Array จะเปลี่ยนเป็น 100, 20, 300, 40, 500 โดย Index 0, 2 และ 4 ถูกกำหนดค่าใหม่ ส่วน Index 1 และ 3 ยังคงเป็นค่าเดิม

การแก้ไขข้อมูลโดยใช้ตัวแปร

ค่าใหม่ที่นำมากำหนดให้กับสมาชิก ของ Array ไม่จำเป็นต้องเขียนเป็นค่าคงที่ โดยตรงเสมอไป แต่สามารถนำค่าที่เก็บอยู่ในตัวแปร มากำหนดให้กับสมาชิกของ Array ได้ 

int[] numbers = {10, 20, 30};

int newValue = 99;

numbers[1] = newValue;

System.out.println(numbers[1]);

ในตัวอย่างนี้ ตัวแปร newValue มีค่าเท่ากับ 99 จากนั้นนำค่าของตัวแปรดังกล่าว ไปกำหนดให้กับ numbers[1] ทำให้สมาชิกที่ Index 1 มีค่าเป็น 99

การนำข้อมูลเดิมมาคำนวณแล้วแก้ไข

นอกจากการกำหนดค่าคงที่ใหม่แล้ว ยังสามารถนำค่าที่อยู่ใน Array มาคำนวณก่อน แล้วนำผลลัพธ์ กลับไปเก็บไว้ใน Index เดิมได้ เช่น การเพิ่มค่า การลดค่า หรือการคูณข้อมูลด้วยค่าที่กำหนด 

int[] numbers = {10, 20, 30};

numbers[0] = numbers[0] + 5;
numbers[1] = numbers[1] * 2;

System.out.println(numbers[0]);
System.out.println(numbers[1]);

ในคำสั่ง numbers[0] = numbers[0] + 5; โปรแกรมจะนำค่าเดิมของ numbers[0] มาบวก 5 แล้วนำผลลัพธ์ กลับไปเก็บไว้ที่ Index 0

ส่วนคำสั่ง numbers[1] = numbers[1] * 2; จะนำค่าที่อยู่ใน Index 1 มาคูณด้วย 2 แล้วบันทึกผลลัพธ์กลับไปยัง Index เดิม

การแก้ไขข้อมูล String ใน Array

การแก้ไขข้อมูลไม่ได้จำกัดเฉพาะ Array ชนิดตัวเลขเท่านั้น แต่สามารถใช้กับ Array ชนิด String ได้เช่นกัน โดยสามารถเปลี่ยนข้อความ ในตำแหน่งที่ต้องการได้ 

String[] names = {
    "สมชาย",
    "สมหญิง",
    "มานะ"
};

names[1] = "มาลี";

System.out.println(names[1]);

จากตัวอย่าง ข้อมูลที่ Index 1 เดิมคือ "สมหญิง" จะถูกเปลี่ยนเป็น "มาลี" โดยสมาชิกในตำแหน่งอื่น ยังคงเป็นข้อมูลเดิม

การแก้ไขข้อมูลด้วย for Loop

หากต้องการแก้ไขข้อมูลหลายสมาชิก ที่มีรูปแบบเดียวกัน สามารถใช้ for Loop เพื่อเข้าถึงสมาชิกแต่ละตำแหน่ง และกำหนดค่าใหม่ได้

ตัวแปรที่ใช้ควบคุม Loop สามารถทำหน้าที่เป็น Index ทำให้โปรแกรมสามารถแก้ไขข้อมูล ตั้งแต่ตำแหน่งแรก ไปจนถึงตำแหน่งสุดท้าย ได้โดยไม่ต้องเขียนคำสั่งซ้ำหลายครั้ง 

int[] numbers = {10, 20, 30, 40, 50};

for (int i = 0; i < numbers.length; i++) {

    numbers[i] = numbers[i] + 10;

}

โปรแกรมจะเริ่มทำงานที่ Index 0 และวนไปยัง Index ถัดไป จนครบทุกสมาชิก โดยแต่ละรอบจะนำข้อมูลเดิม มาบวกเพิ่ม 10 แล้วนำผลลัพธ์กลับไปเก็บ ในตำแหน่งเดิม

จากข้อมูลเดิม 10, 20, 30, 40, 50 หลังจากทำงานเสร็จ จะกลายเป็น 20, 30, 40, 50, 60

การแก้ไขข้อมูลตามเงื่อนไข

สามารถใช้คำสั่ง if ร่วมกับ Array เพื่อเลือกแก้ไข เฉพาะข้อมูลที่ตรงตามเงื่อนไข ได้ เช่น ต้องการเพิ่มคะแนน ให้เฉพาะคะแนนที่มีค่าน้อยกว่า 50 

int[] scores = {40, 70, 50, 80, 30};

for (int i = 0; i < scores.length; i++) {

    if (scores[i] < 50) {
        scores[i] = scores[i] + 10;
    }

}

โปรแกรมจะตรวจสอบคะแนน ทีละตำแหน่ง หากคะแนนน้อยกว่า 50 โปรแกรมจะเพิ่มคะแนนให้ 10 คะแนน แต่ถ้าคะแนนมากกว่าหรือเท่ากับ 50 จะไม่มีการเปลี่ยนแปลงข้อมูล

Array มีขนาดคงที่

สิ่งสำคัญที่ควรเข้าใจคือ การแก้ไขข้อมูลใน Array ไม่ได้เป็นการเพิ่มสมาชิกใหม่ และไม่ได้ทำให้ขนาดของ Array เปลี่ยนแปลง

ตัวอย่างเช่น Array มีขนาด 5 จะมี Index ตั้งแต่ 0 ถึง 4 แม้จะเปลี่ยนค่าของสมาชิก ทุกตำแหน่งแล้ว Array ก็ยังคงมีสมาชิกจำนวน 5 ค่า เช่นเดิม 

int[] numbers = {10, 20, 30, 40, 50};

numbers[0] = 100;
numbers[1] = 200;
numbers[2] = 300;
numbers[3] = 400;
numbers[4] = 500;

System.out.println(numbers.length);

ผลลัพธ์ของ numbers.length ยังคงเป็น 5 เพราะการแก้ไขข้อมูล ไม่ได้เปลี่ยนจำนวนสมาชิก ของ Array

ข้อควรระวังเรื่อง Index

ก่อนแก้ไขข้อมูลควรตรวจสอบว่า Index ที่ต้องการใช้งาน อยู่ในช่วงของ Array หาก Array มีสมาชิกจำนวน 5 ค่า Index ที่สามารถใช้งานได้คือ 0, 1, 2, 3 และ 4

หากพยายามเข้าถึง Index ที่ไม่มีอยู่ โปรแกรมจะเกิดข้อผิดพลาด ที่เรียกว่า ArrayIndexOutOfBoundsException 

int[] numbers = {10, 20, 30, 40, 50};

numbers[5] = 99;

ตัวอย่างนี้ไม่สามารถทำงานได้ เนื่องจาก Array มีสมาชิก 5 ค่า จึงมี Index สูงสุดเพียง 4 ดังนั้นการใช้ numbers[5] จึงเป็นการอ้างอิงตำแหน่ง ที่ไม่มีอยู่ใน Array

Index ที่ถูกต้องคือ
0 ถึง length - 1

ดังนั้นไม่ควรใช้ Index ที่มีค่ามากกว่าหรือเท่ากับ length

การตรวจสอบข้อมูลหลังจากแก้ไข

หลังจากแก้ไขข้อมูลแล้ว สามารถใช้คำสั่ง System.out.println() เพื่อตรวจสอบค่าที่อยู่ใน Index หรือใช้ Loop เพื่อแสดงข้อมูล ทั้งหมดภายใน Array 

int[] numbers = {10, 20, 30};

numbers[1] = 99;

for (int i = 0; i < numbers.length; i++) {

    System.out.println(
        "Index " + i +
        " = " + numbers[i]
    );

}

วิธีนี้เหมาะสำหรับการตรวจสอบว่า โปรแกรมได้เปลี่ยนข้อมูล ในตำแหน่งที่ต้องการจริงหรือไม่ และช่วยให้เห็นความสัมพันธ์ระหว่าง Index กับค่าที่จัดเก็บอยู่ภายใน Array

✅ สรุปการเปลี่ยนแปลงข้อมูลใน Array

การแก้ไขข้อมูลใน Array สามารถทำได้โดยระบุชื่อ Array และ Index ที่ต้องการ แล้วกำหนดค่าใหม่ด้วยเครื่องหมาย =

รูปแบบคือ

ชื่อArray[Index] = ค่าใหม่;

การแก้ไขจะเปลี่ยนเฉพาะสมาชิก ในตำแหน่งที่ระบุ ไม่ส่งผลต่อสมาชิกตำแหน่งอื่น และไม่ทำให้จำนวนสมาชิกของ Array เพิ่มขึ้นหรือลดลง

นอกจากนี้ยังสามารถใช้ ตัวแปร, การคำนวณ, if และ for Loop ร่วมกับการแก้ไขข้อมูล เพื่อสร้างโปรแกรมที่สามารถ ประมวลผลข้อมูลหลายรายการ ได้อย่างมีประสิทธิภาพ 
public class Mainn {

    public static void main(String[] args) {

        int[] numbers = {10, 20, 30};

        System.out.println(numbers[1]);

        numbers[1] = 99;

        System.out.println(numbers[1]);

    }

}
ตัวอย่าง

ในตัวอย่างนี้ numbers[1] เดิมมีค่าเท่ากับ 20 และถูกเปลี่ยนเป็น 99

✅ หลักการสำคัญ

สามารถแก้ไขสมาชิกของ Array ได้โดยใช้รูปแบบ

ชื่อArray[Index] = ค่าใหม่;

6.8 การใช้ length ตรวจสอบจำนวนสมาชิก

Array ในภาษา Java มีคุณสมบัติ length สำหรับตรวจสอบจำนวนสมาชิก ที่อยู่ภายใน Array 

public class Mainn {

    public static void main(String[] args) {

        int[] numbers = {10, 20, 30, 40, 50};

        System.out.println(
            "จำนวนสมาชิก = " + numbers.length

    }

}

6.9 การใช้ for Loop กับ Array

การใช้ Array มักทำงานร่วมกับ for loop เพื่อวนอ่านข้อมูลทีละตำแหน่ง เนื่องจาก Array สามารถเก็บข้อมูลได้หลายค่า การใช้ Loop จึงช่วยลดการเขียนคำสั่งซ้ำ ๆ และทำให้สามารถจัดการข้อมูลจำนวนมาก ได้อย่างเป็นระบบ

ในการใช้ for loop กับ Array ตัวแปรที่ใช้ควบคุม Loop มักทำหน้าที่เป็น Index ของ Array โดยเริ่มต้นจากค่า 0 และเพิ่มค่าขึ้นทีละ 1 จนกว่าจะครบจำนวนสมาชิกที่มีอยู่ใน Array

ตัวอย่างเช่น หาก Array มีข้อมูล 5 ค่า Index ที่สามารถใช้งานได้คือ 0, 1, 2, 3 และ 4 ดังนั้น Loop จะต้องทำงานทั้งหมด 5 รอบ เพื่อเข้าถึงข้อมูลทุกตำแหน่ง

โดยทั่วไปสามารถใช้คุณสมบัติ length ของ Array เพื่อกำหนดเงื่อนไขของ Loop แทนการกำหนดจำนวนรอบด้วยตัวเลขโดยตรง วิธีนี้ช่วยให้โปรแกรมสามารถทำงานกับ Array ที่มีจำนวนสมาชิกแตกต่างกันได้ 

int[] numbers = {10, 20, 30, 40, 50};

for (int i = 0; i < numbers.length; i++) {

    System.out.println(numbers[i]);

}

จากตัวอย่าง ตัวแปร i ใช้สำหรับเก็บค่า Index ของ Array โดยเริ่มต้นที่ 0 และจะเพิ่มขึ้นทีละ 1 จากคำสั่ง i++

ในแต่ละรอบของ Loop โปรแกรมจะนำค่า i ไปใช้เป็น Index เพื่อเข้าถึงข้อมูลภายใน Array ผ่านรูปแบบ numbers[i]

เมื่อ i = 0 โปรแกรมจะเข้าถึง numbers[0] ซึ่งเป็นข้อมูลตัวแรก จากนั้นเมื่อ i = 1 โปรแกรมจะเข้าถึง numbers[1] และทำงานต่อไปเรื่อย ๆ จนถึงตำแหน่งสุดท้าย

ตัวอย่าง

ส่วนประกอบของ for loop ที่ใช้กับ Array

คำสั่ง for loop ที่ใช้ร่วมกับ Array ประกอบด้วยส่วนสำคัญ 3 ส่วน ได้แก่ การกำหนดค่าเริ่มต้น การตรวจสอบเงื่อนไข และการเพิ่มค่าของตัวแปร Loop 

for (int i = 0; i < numbers.length; i++) {

    System.out.println(numbers[i]);

}

ส่วนแรกคือ int i = 0 ใช้กำหนดค่าเริ่มต้นของตัวแปร i ให้เป็น 0 เนื่องจาก Index ของ Array เริ่มต้นจาก 0

ส่วนที่สองคือ i < numbers.length ใช้ตรวจสอบว่า ตัวแปร i ยังอยู่ในช่วงของ Index ที่สามารถเข้าถึงได้หรือไม่ โดย length จะบอกจำนวนสมาชิกทั้งหมด ของ Array

ส่วนที่สามคือ i++ ใช้เพิ่มค่าของตัวแปร i ขึ้นทีละ 1 เพื่อให้ Loop สามารถเลื่อนไปยัง Index ถัดไปของ Array

💡 จำง่าย ๆ

i < numbers.length → ทำงานตราบใดที่ Index ยังไม่เกินขนาด Array

i++ → เลื่อนไปยัง Index ถัดไป

ลำดับการทำงานของ for loop กับ Array

เมื่อโปรแกรมทำงาน จะเริ่มจากการกำหนดค่าให้ตัวแปร i เป็น 0 จากนั้นตรวจสอบเงื่อนไข หากเงื่อนไขเป็นจริง โปรแกรมจะทำคำสั่งภายใน Loop แล้วจึงเพิ่มค่า i ก่อนกลับไปตรวจสอบเงื่อนไขอีกครั้ง

i = 0
→
ตรวจสอบเงื่อนไข
→
numbers[i]
→
i++

กระบวนการดังกล่าวจะทำซ้ำจนกว่า เงื่อนไข i < numbers.length จะเป็นเท็จ จากนั้นโปรแกรมจะออกจาก Loop และทำงานต่อจากคำสั่งหลัง Loop

การแสดงข้อมูลทุกตัวใน Array

ประโยชน์ที่สำคัญของการใช้ for loop กับ Array คือ สามารถนำข้อมูลทุกสมาชิก มาแสดงผลได้โดยไม่ต้องเขียน System.out.println() แยกสำหรับแต่ละ Index

หากมีข้อมูลจำนวนมาก การใช้ Loop จะช่วยลดจำนวนคำสั่ง ทำให้โค้ดสั้นลง อ่านง่ายขึ้น และสามารถปรับเปลี่ยนขนาดของ Array ได้สะดวกมากขึ้น 

int[] scores = {80, 75, 90, 85, 70};

for (int i = 0; i < scores.length; i++) {

    System.out.println(
        "คะแนนคนที่ " + (i + 1) +
        " = " + scores[i]
    );

}

ในตัวอย่างนี้ โปรแกรมสามารถแสดงคะแนนของนักเรียน ทุกคนได้โดยใช้ Loop เพียงชุดเดียว โดย scores[i] จะเปลี่ยนตำแหน่งไปตามค่า ของตัวแปร i

การใช้ for loop เพื่อคำนวณข้อมูลใน Array

นอกจากการนำข้อมูลมาแสดงผลแล้ว for loop ยังสามารถใช้ประมวลผลข้อมูล ภายใน Array ได้ เช่น การหาผลรวม การนับจำนวนข้อมูล การค้นหาค่า หรือการตรวจสอบข้อมูลตามเงื่อนไข 

int[] numbers = {10, 20, 30, 40, 50};

int sum = 0;

for (int i = 0; i < numbers.length; i++) {

    sum += numbers[i];

}

System.out.println("ผลรวม = " + sum);

โปรแกรมจะอ่านข้อมูลจาก Array ทีละตำแหน่ง แล้วนำค่าที่อ่านได้ มาบวกสะสมไว้ในตัวแปร sum จนกว่าจะอ่านข้อมูลครบทุกสมาชิก

✅ ข้อดีของการใช้ for loop กับ Array
  • สามารถอ่านข้อมูลทุกตำแหน่งได้อย่างเป็นระบบ
  • ลดการเขียนคำสั่งซ้ำ ๆ
  • สามารถทำงานกับ Array ที่มีจำนวนสมาชิกหลายค่าได้
  • สามารถนำข้อมูลไปคำนวณหรือประมวลผลได้
  • สามารถใช้ Index เพื่อเข้าถึงตำแหน่งที่ต้องการได้
  • สามารถใช้ร่วมกับคำสั่ง if เพื่อค้นหาหรือตรวจสอบข้อมูลได้

การใช้ for loop ร่วมกับ if

เราสามารถใช้ for loop ร่วมกับคำสั่ง if เพื่อค้นหาข้อมูลที่ตรงตามเงื่อนไข ภายใน Array ได้ เช่น การตรวจสอบว่ามีคะแนนใด มากกว่าหรือเท่ากับ 80 หรือไม่ 

int[] scores = {60, 75, 85, 90, 70};

for (int i = 0; i < scores.length; i++) {

    if (scores[i] >= 80) {

        System.out.println(
            "คะแนนที่ผ่านเกณฑ์ = " + scores[i]
        );

    }

}

ในตัวอย่างนี้ Loop จะตรวจสอบคะแนน ทุกตำแหน่งใน Array และคำสั่ง if จะตรวจสอบว่าคะแนนมีค่ามากกว่าหรือเท่ากับ 80 หรือไม่ หากตรงตามเงื่อนไข โปรแกรมจะแสดงคะแนนนั้นออกมา

⚠️ ข้อควรระวัง

ในการใช้ for loop กับ Array ควรตรวจสอบเงื่อนไข ให้ถูกต้อง โดยทั่วไปควรใช้

i < array.length

ไม่ควรใช้

i <= array.length เพราะ Index สุดท้ายของ Array จะมีค่าเท่ากับ length - 1

ตัวอย่างเช่น หาก Array มีสมาชิก จำนวน 5 ค่า ค่า length จะเท่ากับ 5 แต่ Index สุดท้ายคือ 4 ดังนั้นเงื่อนไข i < 5 จะทำให้ Loop ทำงานที่ Index 0 ถึง 4 ได้อย่างถูกต้อง

💡 จุดสำคัญที่ควรจำ

6.10 การใช้ Enhanced for Loop

Java มีรูปแบบ Enhanced for Loop หรือบางครั้งเรียกว่า for-each ซึ่งเป็นรูปแบบของ Loop ที่ออกแบบมาเพื่อช่วยในการอ่านข้อมูล จาก Array หรือโครงสร้างข้อมูลที่สามารถวนซ้ำได้ โดยไม่จำเป็นต้องจัดการค่า Index ด้วยตนเอง

Enhanced for Loop เหมาะสำหรับกรณีที่ต้องการ อ่านข้อมูลสมาชิกทุกตัวภายใน Array ตามลำดับตั้งแต่สมาชิกตัวแรก ไปจนถึงสมาชิกตัวสุดท้าย โดยโปรแกรมจะนำข้อมูลแต่ละตัว มาเก็บไว้ในตัวแปรที่กำหนด แล้วนำไปใช้งานภายใน Loop

แตกต่างจาก for Loop แบบปกติ ที่ผู้เขียนโปรแกรมต้องสร้างตัวแปร สำหรับเก็บ Index เช่น i และต้องเขียนเงื่อนไข เพื่อควบคุมตำแหน่งของข้อมูล แต่ Enhanced for Loop จะช่วยจัดการการเลื่อนไปยังสมาชิกถัดไป ให้โดยอัตโนมัติ

รูปแบบการเขียน Enhanced for Loop

รูปแบบพื้นฐานของ Enhanced for Loop สามารถเขียนได้ดังนี้ 

for (ชนิดข้อมูล ตัวแปร : Array) {

    // คำสั่งที่ต้องการ

}

ส่วนประกอบของคำสั่งประกอบด้วย ชนิดข้อมูล ซึ่งต้องสอดคล้องกับชนิดข้อมูล ของสมาชิกใน Array ตามด้วยชื่อตัวแปร สำหรับรับข้อมูลแต่ละสมาชิก และเครื่องหมาย : ซึ่งหมายถึงการวนอ่านข้อมูล จาก Array ที่ระบุ

ในแต่ละรอบของ Loop ตัวแปรที่กำหนดไว้จะได้รับค่า ของสมาชิกแต่ละตัวใน Array ตามลำดับ โดยเริ่มจากสมาชิกตัวแรก และทำงานต่อไปจนกว่าจะอ่านข้อมูล ครบทุกสมาชิก 

int[] numbers = {10, 20, 30, 40, 50};

for (int number : numbers) {

    System.out.println(number);

}

จากตัวอย่าง numbers เป็น Array ชนิด int ที่มีข้อมูลทั้งหมด 5 ค่า ส่วนตัวแปร number จะทำหน้าที่รับค่าของสมาชิก ใน Array ทีละตัว

ในรอบแรก ตัวแปร number จะได้รับค่า 10 ซึ่งเป็นสมาชิกตัวแรก จากนั้นในรอบที่สองจะได้รับค่า 20 และทำงานต่อไปตามลำดับ จนถึงค่า 50 ซึ่งเป็นสมาชิกตัวสุดท้าย

ลำดับการทำงานของ Enhanced for Loop

ตัวอย่างเช่น หากมี Array {10, 20, 30} Enhanced for Loop จะนำข้อมูลมาใช้งานตามลำดับ คือ 10 → 20 → 30 โดยผู้เขียนโปรแกรมไม่จำเป็นต้องระบุ numbers[0], numbers[1] และ numbers[2] ด้วยตนเอง

การใช้ Enhanced for Loop แสดงข้อมูล

การใช้งานที่พบได้บ่อยที่สุดคือ การวนอ่านข้อมูลทุกตัว แล้วนำข้อมูลมาแสดงผล ซึ่งเหมาะกับ Array ที่ต้องการ แสดงข้อมูลทั้งหมดโดยไม่จำเป็นต้องรู้ ตำแหน่ง Index ของแต่ละสมาชิก 

String[] names = {
    "สมชาย",
    "สมหญิง",
    "มานะ",
    "มาลี"
};

for (String name : names) {

    System.out.println(name);

}

ในตัวอย่างนี้ Array names ใช้เก็บข้อมูลชนิด String ดังนั้นตัวแปร name ภายใน Enhanced for Loop จึงต้องเป็นชนิด String เพื่อรับค่าข้อความจาก Array

โปรแกรมจะอ่านชื่อทีละชื่อ และนำชื่อที่อ่านได้ ไปใช้งานภายใน Loop จนครบทั้ง 4 รายการ

การใช้ Enhanced for Loop กับข้อมูลตัวเลข

Enhanced for Loop สามารถใช้กับ Array ชนิดตัวเลข เช่น int, double และชนิดข้อมูลอื่น ๆ ได้เช่นเดียวกัน 

double[] prices = {
    25.50,
    30.00,
    45.75,
    50.00
};

for (double price : prices) {

    System.out.println(
        "ราคา = " + price
    );

}

ตัวแปร price จะรับค่าราคาทีละค่า จาก Array prices ทำให้สามารถนำราคาแต่ละรายการ ไปแสดงผลหรือประมวลผลต่อได้

การใช้ Enhanced for Loop เพื่อหาผลรวม

Enhanced for Loop ไม่ได้ใช้เฉพาะการแสดงข้อมูลเท่านั้น แต่ยังสามารถใช้ในการคำนวณ ข้อมูลสมาชิกภายใน Array ได้ เช่น การหาผลรวมของคะแนน หรือผลรวมของราคาสินค้า 

int[] scores = {
    80, 75, 90, 85, 70
};

int sum = 0;

for (int score : scores) {

    sum += score;

}

System.out.println(
    "ผลรวม = " + sum
);

ในแต่ละรอบ ตัวแปร score จะได้รับคะแนนจาก Array แล้วนำไปบวกกับตัวแปร sum ซึ่งใช้สำหรับเก็บผลรวม เมื่อ Loop ทำงานครบทุกสมาชิก ตัวแปร sum จะมีผลรวมของข้อมูลทั้งหมด

💡 แนวคิดสำคัญ

Enhanced for Loop เหมาะสำหรับการ อ่านข้อมูลทุกสมาชิก ใน Array ตามลำดับ

โปรแกรมจะนำสมาชิกแต่ละตัว มาเก็บไว้ในตัวแปรที่กำหนด และเปลี่ยนเป็นสมาชิกถัดไป โดยอัตโนมัติ

จึงไม่จำเป็นต้องเขียน Index หรือกำหนด length ด้วยตนเอง

เปรียบเทียบ for Loop กับ Enhanced for Loop

การวนอ่านข้อมูลจาก Array สามารถทำได้ทั้ง for Loop แบบปกติและ Enhanced for Loop แต่รูปแบบการใช้งานมีความแตกต่างกัน 

int[] numbers = {10, 20, 30, 40, 50};

// for Loop แบบปกติ
for (int i = 0; i < numbers.length; i++) {

    System.out.println(numbers[i]);

}

// Enhanced for Loop
for (int number : numbers) {

    System.out.println(number);

}

for Loop แบบปกติ จะมีตัวแปร i สำหรับควบคุม Index ทำให้สามารถทราบได้ว่า ข้อมูลที่กำลังทำงานอยู่ อยู่ที่ตำแหน่งใดของ Array

ส่วน Enhanced for Loop จะเน้นการอ่านค่าของสมาชิก โดยตรงและไม่จำเป็นต้องจัดการ Index ด้วยตนเอง จึงทำให้โค้ดมีความกระชับ และอ่านได้ง่ายกว่าในกรณี ที่ต้องการอ่านข้อมูลทุกตัว

หัวข้อ for Loop Enhanced for Loop
การใช้ Index สามารถใช้ Index ได้โดยตรง ไม่ต้องจัดการ Index โดยตรง
ความสั้นของโค้ด เขียนมากกว่า เขียนสั้นกว่า
การอ่านข้อมูลทุกตัว ทำได้ เหมาะสมมาก
การเข้าถึงตำแหน่งเฉพาะ เหมาะสม ไม่เหมาะเท่า for ปกติ
การควบคุม Index ควบคุมได้ ไม่จำเป็นต้องควบคุมเอง

ข้อดีของ Enhanced for Loop

Enhanced for Loop ช่วยลดความซับซ้อนของโค้ด โดยเฉพาะโปรแกรมที่ต้องการ อ่านข้อมูลทุกสมาชิกใน Array เนื่องจากไม่ต้องสร้างตัวแปร สำหรับควบคุม Index และไม่ต้องเขียนเงื่อนไข เปรียบเทียบกับ length ด้วยตนเอง

✅ ข้อดีของ Enhanced for Loop
  • เขียนโค้ดได้สั้นและอ่านง่าย
  • ไม่จำเป็นต้องจัดการ Index ด้วยตนเอง
  • เหมาะสำหรับการอ่านข้อมูลทุกสมาชิก
  • ลดโอกาสเกิดข้อผิดพลาด จากการกำหนด Index ผิด
  • สามารถใช้กับ Array ที่มีข้อมูลจำนวนมากได้สะดวก
  • สามารถนำข้อมูลแต่ละสมาชิก ไปคำนวณหรือประมวลผลต่อได้

ข้อจำกัดของ Enhanced for Loop

แม้ Enhanced for Loop จะใช้งานได้ง่ายและสะดวก แต่ก็มีข้อจำกัดบางประการ โดยเฉพาะกรณีที่โปรแกรม จำเป็นต้องทราบ Index ของข้อมูลแต่ละตำแหน่ง

หากต้องการเข้าถึงข้อมูลเฉพาะตำแหน่ง เช่น ต้องการอ่านข้อมูลที่ Index 2 หรือจำเป็นต้องใช้ Index ในการคำนวณบางอย่าง การใช้ for Loop แบบปกติจะเหมาะสมกว่า

ดังนั้นการเลือกใช้ Loop ควรพิจารณาจากลักษณะของงาน หากต้องการเพียงอ่านข้อมูล ทุกตัวตามลำดับ สามารถเลือกใช้ Enhanced for Loop เพื่อให้โค้ดกระชับและเข้าใจง่าย

⚠️ ข้อควรจำ

Enhanced for Loop ไม่ได้มีตัวแปร Index ให้ใช้งานโดยตรงเหมือน for Loop แบบปกติ

หากงานจำเป็นต้องรู้ว่า ข้อมูลอยู่ที่ Index ใด หรือจำเป็นต้องควบคุมตำแหน่ง ของสมาชิกด้วยตนเอง ควรเลือกใช้ for Loop แบบปกติ

การเลือกใช้ Loop ให้เหมาะสม

การเลือกใช้ Loop ควรขึ้นอยู่กับวัตถุประสงค์ ของโปรแกรม หากต้องการแสดงข้อมูลทั้งหมด หรืออ่านข้อมูลทุกตัวใน Array Enhanced for Loop เป็นตัวเลือกที่เหมาะสม เนื่องจากเขียนง่ายและไม่ต้อง จัดการ Index

แต่ถ้าต้องการเข้าถึงสมาชิก ตามตำแหน่งที่กำหนด ต้องการเปลี่ยนค่าข้อมูล ตาม Index หรือต้องการควบคุมการเพิ่ม หรือลดค่าของ Index ควรเลือกใช้ for Loop แบบปกติ

💡 จำง่าย ๆ

for Loop → เหมาะเมื่อจำเป็นต้องใช้ Index หรือควบคุมตำแหน่งข้อมูล

Enhanced for Loop → เหมาะเมื่อเพียงต้องการ อ่านข้อมูลทุกตัวใน Array

โดยสรุป Enhanced for Loop เป็นรูปแบบการวนซ้ำที่ช่วยให้ การอ่านข้อมูลจาก Array ทำได้ง่ายและเป็นระเบียบมากขึ้น โดยโปรแกรมจะนำสมาชิก แต่ละตัวมาเก็บไว้ในตัวแปร ตามลำดับโดยอัตโนมัติ

การเข้าใจ Enhanced for Loop จะช่วยให้สามารถเขียนโปรแกรม ที่ทำงานกับข้อมูลจำนวนมาก ได้สะดวกขึ้น และยังเป็นพื้นฐานสำคัญ สำหรับการทำงานกับโครงสร้างข้อมูล อื่น ๆ ในภาษา Java ที่สามารถวนอ่านสมาชิก ได้ในลักษณะเดียวกัน 

public class Mainn {

    public static void main(String[] args) {

        int[] numbers = {10, 20, 30, 40, 50};

        for (int number : numbers) {

            System.out.println(number);

        }

    }

}

6.11 การหาผลรวมของข้อมูลใน Array

Array สามารถนำมาใช้กับการคำนวณข้อมูล ได้หลากหลายรูปแบบ เช่น การหาผลรวมคะแนน ผลรวมยอดขาย ผลรวมจำนวนสินค้า หรือผลรวมของข้อมูลตัวเลขต่าง ๆ ที่จัดเก็บอยู่ภายใน Array

เนื่องจาก Array สามารถเก็บข้อมูลตัวเลข ได้หลายค่าไว้ภายใต้ชื่อเดียวกัน เราจึงสามารถใช้ Loop เพื่ออ่านข้อมูลทีละสมาชิก แล้วนำค่าของแต่ละสมาชิก มาคำนวณร่วมกันได้

การหาผลรวมของข้อมูลใน Array เป็นตัวอย่างสำคัญของการนำ Array มาทำงานร่วมกับ Loop โดยโปรแกรมจะอ่านข้อมูล จากสมาชิกตัวแรก ไปจนถึงสมาชิกตัวสุดท้าย และนำค่าทั้งหมดมาบวกสะสมกัน

แนวคิดการหาผลรวม

หลักการพื้นฐานของการหาผลรวม คือการสร้างตัวแปรขึ้นมา สำหรับเก็บค่าผลรวม โดยกำหนดค่าเริ่มต้นเป็น 0 จากนั้นใช้ Loop วนอ่านข้อมูลแต่ละตัว แล้วนำข้อมูลที่อ่านได้ มาบวกเพิ่มเข้าไปในตัวแปรผลรวม

ตัวแปรที่ใช้เก็บผลรวม มักตั้งชื่อว่า sum เพื่อให้สื่อความหมายว่า เป็นตัวแปรที่ใช้สำหรับเก็บ ผลรวมของข้อมูล

sum = 0
→
อ่านข้อมูล
→
นำมาบวกกับ sum
→
ได้ผลรวม

ตัวอย่างเช่น หากมีข้อมูล 10, 20, 30, 40 และ 50 โปรแกรมจะนำข้อมูลแต่ละค่ามาบวกกัน จนได้ผลรวมเท่ากับ 150

การสร้างตัวแปรสำหรับเก็บผลรวม

ก่อนเริ่มคำนวณ ควรสร้างตัวแปรสำหรับเก็บผลรวม และกำหนดค่าเริ่มต้นเป็น 0 เพราะยังไม่มีข้อมูลใด ถูกนำมาคำนวณ 

int sum = 0;

คำสั่งนี้สร้างตัวแปรชื่อ sum ชนิด int และกำหนดค่าเริ่มต้นเป็น 0 จากนั้นสามารถนำตัวแปรนี้ ไปใช้เก็บผลรวมของข้อมูล ใน Array ได้

การใช้ for Loop หาผลรวม

เมื่อต้องการนำข้อมูลทุกตัว ใน Array มาคำนวณ สามารถใช้ for Loop เพื่อวนเข้าถึงสมาชิก แต่ละตำแหน่งของ Array แล้วนำค่าที่ได้ มาบวกกับตัวแปร sum 

int[] numbers = {10, 20, 30, 40, 50};

int sum = 0;

for (int i = 0; i < numbers.length; i++) {

    sum += numbers[i];

}

System.out.println(
    "ผลรวม = " + sum
);

ในตัวอย่างนี้ Array ชื่อ numbers มีข้อมูลจำนวน 5 ค่า จากนั้นสร้างตัวแปร sum เพื่อใช้เก็บผลรวม และกำหนดค่าเริ่มต้นเป็น 0

คำสั่ง sum += numbers[i]; เป็นการนำค่าของสมาชิก ที่อยู่ในตำแหน่งปัจจุบัน มาบวกเพิ่มให้กับ sum

คำสั่ง sum += numbers[i]; สามารถเขียนในรูปแบบเต็มได้ว่า sum = sum + numbers[i]; ซึ่งมีความหมายเหมือนกัน เพียงแต่รูปแบบ += ช่วยให้เขียนคำสั่งได้สั้นลง

💡 จำง่าย ๆ

sum = 0; → กำหนดค่าเริ่มต้นของผลรวม

sum += numbers[i]; → นำข้อมูลแต่ละตัวมาบวกสะสม

System.out.println(sum); → แสดงผลรวมที่คำนวณได้

ลำดับการคำนวณผลรวม

หาก Array มีข้อมูล {10, 20, 30, 40, 50} การทำงานของโปรแกรม สามารถอธิบายเป็นลำดับได้ดังนี้

รอบ Index ข้อมูล ค่า sum หลังคำนวณ
เริ่มต้น - - 0
รอบที่ 1 0 10 10
รอบที่ 2 1 20 30
รอบที่ 3 2 30 60
รอบที่ 4 3 40 100
รอบที่ 5 4 50 150

จากตารางจะเห็นได้ว่า ตัวแปร sum จะเก็บค่าผลรวมสะสม และจะเปลี่ยนแปลงในแต่ละรอบ จนกระทั่งอ่านข้อมูล ใน Array ครบทุกตำแหน่ง

การหาผลรวมด้วย Enhanced for Loop

นอกจากการใช้ for Loop แบบปกติแล้ว เรายังสามารถใช้ Enhanced for Loop เพื่อหาผลรวมได้ โดยวิธีนี้ไม่จำเป็นต้อง ใช้ตัวแปร Index เนื่องจากโปรแกรมจะนำสมาชิก แต่ละตัวมาให้โดยอัตโนมัติ 

int[] numbers = {10, 20, 30, 40, 50};

int sum = 0;

for (int number : numbers) {

    sum += number;

}

System.out.println(
    "ผลรวม = " + sum
);

ในตัวอย่างนี้ ตัวแปร number จะรับค่าของสมาชิก ใน Array ทีละตัว จากนั้นนำค่าดังกล่าว มาบวกสะสมในตัวแปร sum

การใช้ Enhanced for Loop เหมาะกับกรณีที่ต้องการ อ่านข้อมูลทุกตัว และนำข้อมูลทั้งหมด มาคำนวณโดยไม่จำเป็นต้องทราบ Index ของสมาชิกแต่ละตัว

ตัวอย่าง

การหาผลรวมคะแนนนักเรียน

การหาผลรวมของ Array สามารถนำไปประยุกต์ใช้กับ ระบบคะแนนนักเรียนได้ เช่น การเก็บคะแนนของนักเรียน หลายคนไว้ใน Array แล้วนำคะแนนทั้งหมด มาคำนวณหาผลรวม 

int[] scores = {
    80, 75, 90, 85, 70
};

int sum = 0;

for (int score : scores) {

    sum += score;

}

System.out.println(
    "ผลรวมคะแนน = " + sum
);

จากตัวอย่าง Array scores ใช้เก็บคะแนนของนักเรียน จำนวน 5 ค่า โปรแกรมจะอ่านคะแนน ทีละค่าแล้วนำมาบวกสะสม ในตัวแปร sum

เมื่อนำคะแนน 80 + 75 + 90 + 85 + 70 มารวมกัน จะได้ผลรวมคะแนนเท่ากับ 400

การหาผลรวมยอดขาย

แนวคิดเดียวกันสามารถนำไปใช้ ในระบบร้านค้าได้ เช่น เก็บยอดขายสินค้า แต่ละรายการไว้ใน Array แล้วนำข้อมูลทั้งหมด มาคำนวณหายอดขายรวม 

double[] sales = {
    120.50,
    250.00,
    180.75,
    300.00
};

double total = 0;

for (double sale : sales) {

    total += sale;

}

System.out.println(
    "ยอดขายรวม = " + total
);

ในตัวอย่างนี้ใช้ชนิดข้อมูล double เนื่องจากยอดขายอาจมีค่า เป็นทศนิยม และใช้ตัวแปร total สำหรับเก็บยอดขายสะสม

การหาผลรวมโดยใช้ Index

หากต้องการทราบตำแหน่งของข้อมูล ขณะที่กำลังคำนวณ สามารถใช้ for Loop แบบปกติได้ เพราะตัวแปร Loop สามารถนำมาใช้เป็น Index ของ Array ได้โดยตรง 

int[] numbers = {5, 10, 15, 20};

int sum = 0;

for (int i = 0; i < numbers.length; i++) {

    System.out.println(
        "Index " + i +
        " = " + numbers[i]
    );

    sum += numbers[i];

}

System.out.println(
    "ผลรวม = " + sum
);

วิธีนี้เหมาะสำหรับกรณีที่ ต้องการใช้ทั้งข้อมูล และตำแหน่ง Index ไปพร้อมกัน เช่น การแสดงหมายเลขรายการ หรือการอ้างอิงข้อมูล ตามตำแหน่งใน Array

การหาผลรวมด้วยข้อมูลที่ผู้ใช้ป้อน

Array สามารถทำงานร่วมกับ Scanner เพื่อรับข้อมูลจากผู้ใช้ แล้วนำข้อมูลที่รับเข้ามา มาหาผลรวมได้ ซึ่งเป็นรูปแบบที่สามารถ นำไปประยุกต์ใช้กับโปรแกรมจริง ได้หลายประเภท 

import java.util.Scanner;

public class Mainn {

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        int[] numbers = new int[3];

        int sum = 0;

        for (int i = 0; i < numbers.length; i++) {

            System.out.print(
                "กรอกตัวเลขที่ " + (i + 1) + ": "
            );

            numbers[i] = input.nextInt();

            sum += numbers[i];

        }

        System.out.println(
            "ผลรวม = " + sum
        );

    }

}

โปรแกรมจะสร้าง Array สำหรับเก็บตัวเลขจำนวน 3 ค่า จากนั้นใช้ for Loop รับข้อมูลจากผู้ใช้ทีละค่า และเก็บข้อมูลลงใน Array ตามตำแหน่ง Index

หลังจากรับข้อมูลแต่ละค่าแล้ว โปรแกรมจะนำค่าดังกล่าว มาบวกเพิ่มให้กับตัวแปร sum ทำให้เมื่อรับข้อมูลครบ ก็จะได้ผลรวมของข้อมูลทั้งหมด

💡 แนวคิดการนำไปประยุกต์ใช้

การหาผลรวมจาก Array สามารถนำไปใช้กับงานต่าง ๆ เช่น

• ผลรวมราคาสินค้า
• ยอดขายสินค้ารวม
• จำนวนสินค้าที่ขายได้
• ผลรวมค่าใช้จ่าย

Array ชนิด int ไม่สามารถนำ String มาเก็บเป็นสมาชิกโดยตรงได้

6.21 สรุปบทเรียน

Array เป็นโครงสร้างข้อมูลพื้นฐานที่สำคัญ ในภาษา Java ใช้สำหรับเก็บข้อมูลหลายค่า ที่มีชนิดข้อมูลเดียวกัน ภายใต้ชื่อตัวแปรเดียว

สิ่งสำคัญที่ต้องเข้าใจคือ Index ของ Array จะเริ่มต้นที่ 0 และตำแหน่งสุดท้ายจะเท่ากับ length - 1

การจัดการข้อมูลใน Array สามารถทำได้โดยการเข้าถึงข้อมูล การแก้ไขค่า การใช้ length และการใช้ for Loop หรือ Enhanced for Loop

Array ยังสามารถนำไปประยุกต์ใช้ กับการคำนวณผลรวม ค่าเฉลี่ย ค่าสูงสุด ค่าต่ำสุด และการจัดการข้อมูลในรูปแบบต่าง ๆ

นอกจากนี้ Java ยังรองรับ Array หลายมิติ ซึ่งเหมาะสำหรับข้อมูลที่มีลักษณะ เป็นตารางหรือมีหลายแถวหลายคอลัมน์

🎯 สิ่งที่ควรรู้หลังเรียนจบ
  • อธิบายความหมายของ Array ได้
  • เข้าใจการทำงานของ Index
  • สามารถประกาศ Array ได้
  • สามารถกำหนดค่าเริ่มต้นให้ Array ได้
  • สามารถเข้าถึงข้อมูลใน Array ได้
  • สามารถแก้ไขข้อมูลใน Array ได้
  • สามารถใช้ length ได้
  • สามารถใช้ for Loop กับ Array ได้
  • สามารถใช้ Enhanced for Loop ได้
  • สามารถหาผลรวมและค่าเฉลี่ยจาก Array ได้
  • สามารถหาค่าสูงสุดและค่าต่ำสุดได้
  • เข้าใจ Array 2 มิติในระดับพื้นฐาน
