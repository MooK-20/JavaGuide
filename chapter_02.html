บทที่ 2

ขั้นตอนการติดตั้งเครื่องมือ

บทนำ

ก่อนเริ่มเขียนโปรแกรมภาษา Java ผู้เรียนจำเป็นต้องติดตั้งเครื่องมือ สำหรับการพัฒนาโปรแกรมให้พร้อมใช้งาน เนื่องจากคอมพิวเตอร์ทั่วไปยังไม่สามารถ Compile และ Run โปรแกรม Java ได้โดยตรงหากไม่มีเครื่องมือที่เหมาะสม

เครื่องมือพื้นฐานที่สำคัญสำหรับการพัฒนาโปรแกรม Java คือ JDK (Java Development Kit) ซึ่งเป็นชุดเครื่องมือที่ช่วยในการเขียน Compile และทดสอบโปรแกรม Java โดยภายใน JDK จะมีเครื่องมือสำคัญ เช่น javac สำหรับ Compile ไฟล์ Java และ java สำหรับเรียกใช้งานโปรแกรมที่ Compile แล้ว

นอกจาก JDK แล้ว ผู้เรียนควรมีโปรแกรม สำหรับเขียน Source Code เช่น Text Editor หรือ IDE เพื่อช่วยให้การเขียน และตรวจสอบโปรแกรมทำได้สะดวกมากขึ้น

แนวคิดสำคัญ

การเริ่มต้นพัฒนาโปรแกรม Java สามารถสรุปเป็นลำดับได้ดังนี้

ติดตั้ง JDK → ตรวจสอบ JDK → ติดตั้งโปรแกรมเขียนโค้ด → สร้างไฟล์ Java → Compile → Run

เครื่องมือที่ใช้สำหรับพัฒนา Java

การเขียนโปรแกรม Java จำเป็นต้องมีเครื่องมือ ที่ช่วยในการสร้างและประมวลผลโปรแกรม โดยเครื่องมือแต่ละชนิดมีหน้าที่แตกต่างกัน

เครื่องมือ หน้าที่
JDK ชุดเครื่องมือสำหรับพัฒนาโปรแกรม Java ประกอบด้วย Compiler และเครื่องมือ ที่จำเป็นสำหรับการพัฒนา Java
Java Compiler ใช้แปลง Source Code ที่เขียนด้วยภาษา Java ให้เป็น Java Bytecode
JVM ทำหน้าที่ประมวลผล Java Bytecode เพื่อให้โปรแกรม Java สามารถทำงานได้
Text Editor ใช้สำหรับสร้างและแก้ไขไฟล์ Source Code
IDE โปรแกรมที่รวมเครื่องมือสำหรับเขียน Compile และ Debug โปรแกรมไว้ในที่เดียว

JDK คืออะไร

JDK (Java Development Kit) คือชุดเครื่องมือสำหรับการพัฒนาโปรแกรมภาษา Java ที่ใช้สำหรับเขียน พัฒนา Compile และทดสอบโปรแกรม โดย JDK ถือเป็นเครื่องมือพื้นฐานที่จำเป็นสำหรับผู้ที่ต้องการ เริ่มต้นพัฒนาโปรแกรมด้วยภาษา Java

ภายใน JDK มีเครื่องมือหลายประเภทที่ช่วยสนับสนุนกระบวนการ พัฒนาโปรแกรม ตั้งแต่การสร้าง Source Code การตรวจสอบโค้ด การ Compile ไปจนถึงการเรียกใช้งานโปรแกรมที่เขียนขึ้น โดยเครื่องมือที่สำคัญ ได้แก่ javac และ java

คำสั่ง javac เป็น Java Compiler ทำหน้าที่แปลงไฟล์ Source Code ที่มีนามสกุล .java ให้เป็น Bytecode ซึ่งโดยทั่วไปจะมีนามสกุล .class เพื่อให้ Java Runtime สามารถนำไปประมวลผลได้

ส่วนคำสั่ง java ใช้สำหรับเรียกใช้งานโปรแกรม Java หลังจากที่ Source Code ผ่านกระบวนการ Compile แล้ว โดย Java จะทำงานผ่าน Java Virtual Machine หรือ JVM ซึ่งช่วยให้โปรแกรม Java สามารถทำงานบนระบบปฏิบัติการ ที่รองรับ Java ได้

สำหรับผู้เริ่มต้นเขียนโปรแกรม Java การติดตั้ง JDK ถือเป็นขั้นตอนสำคัญก่อนเริ่มเขียนโปรแกรม เนื่องจากหากไม่มี JDK จะไม่สามารถใช้เครื่องมือ สำหรับ Compile Source Code ด้วยคำสั่ง javac ได้ตามปกติ

นอกจากการ Compile และ Run โปรแกรมแล้ว JDK ยังมีเครื่องมืออื่น ๆ ที่ช่วยในการพัฒนาและตรวจสอบโปรแกรม ทำให้นักพัฒนาสามารถสร้างโปรแกรม Java ได้อย่างเป็นระบบ และสามารถตรวจสอบปัญหาที่เกิดขึ้นระหว่างการพัฒนาได้

กระบวนการทำงานพื้นฐานของ Java สามารถอธิบายได้ว่า ผู้เขียนโปรแกรมจะเริ่มจากการสร้าง Source Code ซึ่งจัดเก็บไว้ในไฟล์ .java จากนั้นใช้ Compiler ในการแปลง Source Code ให้เป็น Bytecode และจึงเรียกใช้งาน Bytecode ผ่าน Java Runtime และ JVM

JDK ประกอบด้วยเครื่องมือสำคัญ

Java Compiler (javac) ใช้สำหรับ Compile Source Code จากไฟล์ .java ให้เป็น Bytecode

Java Launcher (java) ใช้สำหรับเรียกใช้งานโปรแกรม Java ที่ผ่านการ Compile แล้ว

Java Runtime Environment เป็นสภาพแวดล้อมที่ใช้สำหรับการทำงานของโปรแกรม Java

Java Virtual Machine (JVM) ทำหน้าที่ประมวลผล Bytecode และเป็นส่วนสำคัญที่ช่วยให้ Java สามารถทำงาน บนระบบปฏิบัติการที่แตกต่างกันได้

Development Tools เป็นเครื่องมือที่ช่วยในการพัฒนา ตรวจสอบ และจัดการโปรแกรม Java

ขั้นตอนการติดตั้ง JDK

การติดตั้ง JDK เป็นขั้นตอนแรกในการเตรียมสภาพแวดล้อม สำหรับการพัฒนาโปรแกรม Java โดยผู้เรียนควรติดตั้ง JDK ให้เรียบร้อยก่อนเริ่มเขียนและ Compile โปรแกรม

ขั้นตอนการติดตั้งอาจมีรายละเอียดแตกต่างกันเล็กน้อย ตามระบบปฏิบัติการและเวอร์ชันของ JDK ที่เลือกใช้ ดังนั้นควรอ่านข้อมูลในแต่ละหน้าต่างอย่างละเอียด และตรวจสอบตัวเลือกต่าง ๆ ก่อนดำเนินการต่อ

ภาพด้านล่างแสดงลำดับขั้นตอนการติดตั้ง และการเตรียม Java ตามลำดับ ผู้เรียนสามารถศึกษาภาพประกอบแต่ละขั้นตอน เพื่อทำความเข้าใจลำดับการติดตั้งได้

STEP 01

เริ่มต้นการเตรียมเครื่องมือ

ตรวจสอบหน้าจอและเริ่มต้นขั้นตอน สำหรับการเตรียมเครื่องมือที่จำเป็น ก่อนเริ่มพัฒนาโปรแกรม Java โดยควรตรวจสอบให้แน่ใจว่าเครื่องคอมพิวเตอร์ พร้อมสำหรับการติดตั้ง JDK

STEP 02

ดำเนินการตามขั้นตอนการติดตั้ง

กรอกข้อมูลตามขั้นตอน และตรวจสอบรายละเอียดต่าง ๆ ที่โปรแกรมติดตั้งแสดงขึ้นมา เพื่อให้การติดตั้ง JDK ดำเนินไปอย่างถูกต้อง

STEP 03

ตรวจสอบตัวเลือกการติดตั้ง

ตรวจสอบรายละเอียดและตัวเลือก ที่ปรากฏในหน้าต่างติดตั้ง ก่อนดำเนินการต่อ โดยควรอ่านข้อมูลแต่ละรายการ เพื่อให้เข้าใจว่าระบบกำลังติดตั้งส่วนใด ลงในเครื่องคอมพิวเตอร์

STEP 04

ยืนยันการตั้งค่าการติดตั้ง

ตรวจสอบการตั้งค่าที่กำหนดไว้ แล้วดำเนินการติดตั้งต่อไป ขั้นตอนนี้ควรตรวจสอบตำแหน่ง และรายละเอียดการติดตั้งให้เหมาะสม ก่อนยืนยันการทำงาน

STEP 05

เข้าสู่ขั้นตอนการติดตั้ง

ระบบเข้าสู่ขั้นตอนการติดตั้ง ให้รอการทำงานของโปรแกรม จนกว่าจะดำเนินการเสร็จ และเลือก Product ตามขั้นตอน ที่ปรากฏบนหน้าจอ

STEP 06

ตรวจสอบหน้าต่างการตั้งค่า

ตรวจสอบรายละเอียดที่ปรากฏ และดำเนินการตามขั้นตอนที่ระบบกำหนด หากมีตัวเลือกเพิ่มเติมควรตรวจสอบ ให้เรียบร้อยก่อนดำเนินการในขั้นตอนถัดไป

STEP 07

ตรวจสอบการตั้งค่าเพิ่มเติม

ตรวจสอบรายการตั้งค่าที่แสดง และเลือกค่าที่เหมาะสมกับการติดตั้ง โดยควรตรวจสอบรายละเอียดของแต่ละรายการ เพื่อป้องกันการตั้งค่าที่ไม่ตรงกับสภาพแวดล้อม ของเครื่องคอมพิวเตอร์

STEP 08

ดำเนินการตั้งค่าระบบ

ดำเนินการตั้งค่าตามหน้าต่าง ที่ปรากฏบนหน้าจอ เพื่อเตรียม Java ให้พร้อมใช้งาน หลังจากกำหนดค่าต่าง ๆ แล้ว ให้ตรวจสอบข้อมูลอีกครั้งก่อนดำเนินการต่อ

STEP 09

ตรวจสอบค่าที่เกี่ยวข้องกับ Java

ตรวจสอบรายการที่เกี่ยวข้องกับ การติดตั้งและการตั้งค่าของ Java ให้เรียบร้อย โดยเฉพาะข้อมูล ที่เกี่ยวข้องกับตำแหน่งการติดตั้ง เพื่อให้สามารถเรียกใช้งาน Java จากระบบได้อย่างถูกต้อง

STEP 10

ตรวจสอบการตั้งค่าระบบ

ตรวจสอบข้อมูลที่ระบบแสดง และดำเนินการต่อเมื่อค่าต่าง ๆ พร้อมใช้งาน การตรวจสอบในขั้นตอนนี้ ช่วยลดปัญหาที่อาจเกิดขึ้น หลังจากติดตั้งโปรแกรมเสร็จ

STEP 11

ตรวจสอบการติดตั้ง

ตรวจสอบผลจากขั้นตอนก่อนหน้า เพื่อให้แน่ใจว่าการติดตั้ง ดำเนินการอย่างถูกต้อง และไม่มีข้อผิดพลาดที่ทำให้ ไม่สามารถใช้งาน Java ได้

STEP 12

สิ้นสุดขั้นตอนการติดตั้ง

เมื่อระบบดำเนินการติดตั้งเสร็จเรียบร้อย ให้ตรวจสอบว่าการติดตั้งเสร็จสมบูรณ์ จากนั้น Click ปุ่ม Close เพื่อปิดหน้าต่างการติดตั้ง และเข้าสู่ขั้นตอนการตรวจสอบ Java

การตรวจสอบการติดตั้ง Java

หลังจากติดตั้ง JDK แล้ว ผู้เรียนควรตรวจสอบการติดตั้ง ผ่าน Command Prompt บน Windows เพื่อยืนยันว่าระบบสามารถเรียกใช้คำสั่ง Java ได้อย่างถูกต้อง

การตรวจสอบสามารถทำได้โดยใช้คำสั่ง java -version และ javac -version ซึ่งเป็นคำสั่งพื้นฐานที่ใช้ตรวจสอบ เวอร์ชันของ Java และ Java Compiler ที่สามารถเรียกใช้งานผ่านระบบได้ 

java -version
javac -version
STEP 13

เปิด Command Prompt

เปิด Command Prompt บน Windows เพื่อใช้ตรวจสอบการติดตั้ง Java และดำเนินการตามคำสั่งต่าง ๆ โดยขั้นตอนนี้เป็นการเตรียมพื้นที่ สำหรับตรวจสอบการทำงานของ Java ผ่าน Command Line

STEP 14

ตรวจสอบ Java Version

พิมพ์คำสั่ง java -version แล้วกด Enter เพื่อดูเวอร์ชัน ของ Java ที่ติดตั้งอยู่ในเครื่อง หากระบบสามารถแสดงข้อมูลเวอร์ชัน แสดงว่าสามารถเรียกใช้คำสั่ง Java ผ่าน Command Prompt ได้

STEP 15

ตรวจสอบผลการติดตั้ง Java

ตรวจสอบผลลัพธ์ที่ระบบแสดง หากมีข้อมูลเวอร์ชันของ Java แสดงว่าสามารถเรียกใช้ Java ได้ และสามารถเตรียมเข้าสู่ขั้นตอน การเขียนและ Compile โปรแกรม Java ต่อไป

การตั้งค่า Environment Variable

ในระบบ Windows จำเป็นต้องตรวจสอบ Environment Variable และ PATH เพื่อให้สามารถเรียกใช้คำสั่ง Java จาก Command Prompt ได้อย่างสะดวก

ตัวแปร PATH มีหน้าที่ช่วยให้ระบบปฏิบัติการ สามารถค้นหาโปรแกรมหรือคำสั่งที่ต้องการ จากตำแหน่งที่กำหนดไว้ได้ ดังนั้นการตั้งค่า PATH ที่ถูกต้อง จึงมีความสำคัญต่อการเรียกใช้คำสั่ง java และ javac

STEP 16

เปิดหน้าต่าง Environment Variables

ที่แท็ป Advanced คลิกปุ่ม Environment Variables… เพื่อเข้าสู่หน้าต่างสำหรับจัดการ ตัวแปรสภาพแวดล้อมของระบบ ซึ่งเป็นส่วนที่ใช้กำหนดค่าที่เกี่ยวข้อง กับการทำงานของโปรแกรม

STEP 17

ตรวจสอบตัวแปรของระบบ

ให้ไปเลือกส่วน System Variables ซึ่งเป็นส่วนที่ใช้จัดการตัวแปร ที่เกี่ยวข้องกับระบบ Windows และสามารถใช้ตรวจสอบค่าที่จำเป็น สำหรับการเรียกใช้งาน Java

STEP 18

ตรวจสอบค่า PATH

Double Click เพื่อกำหนดตั้งค่า (Set Path) และตรวจสอบว่ามีส่วนของ Java Path หรือไม่ หากไม่มีตำแหน่งที่เกี่ยวข้องกับ Java อาจทำให้ Command Prompt ไม่สามารถค้นหาคำสั่ง Java ได้

STEP 19

ตรวจสอบรายการ PATH

จากตัวอย่าง จะมี javapath เรียบร้อย ไม่ต้องติดตั้งเพิ่ม หากไม่มี ให้ตรวจสอบตำแหน่งไฟล์ Java ที่ติดตั้งอยู่ในเครื่อง โดยสามารถเข้าไปที่ Program Files / Common Files / Oracle / Java และตรวจสอบตำแหน่งของไฟล์ Java เพื่อนำตำแหน่งไปใช้ในการกำหนด PATH

STEP 20

เพิ่มหรือปรับค่าที่จำเป็น

กดปุ่ม Ctrl + C เพื่อคัดลอก ตำแหน่งที่ต้องการนำไปใช้ในการตั้งค่า โดยควรตรวจสอบให้แน่ใจว่าตำแหน่ง ที่คัดลอกเป็นตำแหน่งของ Java ที่ถูกต้องก่อนนำไปกำหนดใน PATH

STEP 21

ตรวจสอบค่าที่กำหนด

ตรวจสอบรายการและตำแหน่ง ที่กำหนดไว้ให้เรียบร้อย ก่อนปิดหน้าต่างการตั้งค่า เพื่อให้แน่ใจว่า PATH มีข้อมูลที่เกี่ยวข้องกับ Java และไม่มีการกำหนดค่าผิดตำแหน่ง

STEP 22

ยืนยันการตั้งค่า

กดปุ่ม New จากนั้นกด Ctrl + V เพื่อวางตำแหน่ง ที่คัดลอกไว้ แล้วกด OK เพื่อยืนยันการตั้งค่า จากนั้นปิดหน้าต่างที่เกี่ยวข้อง จนเสร็จสิ้นกระบวนการ

การเตรียมโปรแกรมสำหรับเขียน Java

หลังจากติดตั้ง JDK และตรวจสอบการทำงานของ Java เรียบร้อยแล้ว ขั้นตอนต่อไปคือการเตรียมโปรแกรม สำหรับเขียน Source Code ในที่นี้ใช้ Visual Studio Code หรือ VSC เป็นโปรแกรมสำหรับสร้าง แก้ไข และจัดการไฟล์ Source Code ของ Java

Visual Studio Code ช่วยให้ผู้เรียนสามารถจัดการ ไฟล์และโฟลเดอร์ของโปรเจกต์ได้ง่าย รวมถึงสามารถติดตั้ง Extensions เพื่อเพิ่มความสามารถในการเขียนโปรแกรม Java เช่น การช่วยตรวจสอบโค้ด การแสดงข้อผิดพลาด และการช่วย Run โปรแกรม

หลังจากนั้นให้ไปติดตั้ง VSC ในที่นี้ได้ติดตั้งไว้เรียบร้อย เพื่อใช้ในการเรียนในรายวิชา การพัฒนาเว็บและการเขียนโปรแกรม โดยผู้เรียนสามารถใช้โปรแกรมดังกล่าว เป็นเครื่องมือหลักสำหรับสร้างไฟล์ Java ในบทเรียนต่อไป

STEP 23

เปิด Visual Studio Code

เปิดโปรแกรม Visual Studio Code เพื่อเตรียมสร้างและแก้ไขไฟล์ Source Code ของ Java โดยโปรแกรมจะทำหน้าที่เป็นพื้นที่ สำหรับเขียนและจัดการไฟล์ของโปรเจกต์

STEP 24

ขั้นตอนการสร้าง Folder

ไปคลิกเมนู File → Add Folder to Workspace … เพื่อเพิ่มโฟลเดอร์สำหรับจัดเก็บไฟล์ และใช้เป็นพื้นที่ทำงานของโปรเจกต์ Java

STEP 25

สร้างหรือเปิดโฟลเดอร์โปรเจกต์

สร้างหรือเปิดโฟลเดอร์สำหรับจัดเก็บ Source Code ของโปรแกรม Java โดยสามารถสร้าง Folder เพื่อใช้เก็บไฟล์ Java ในตำแหน่งใดก็ได้ที่ผู้เรียนสามารถเข้าถึงได้สะดวก

STEP 26

เลือกโฟลเดอร์สำหรับโปรเจกต์

เลือกตำแหน่งโฟลเดอร์ที่ต้องการ ใช้เป็นพื้นที่สำหรับเก็บไฟล์ Java โดยควรเลือก Folder ที่สามารถ จดจำตำแหน่งได้ง่าย และสะดวกต่อการเปิดใช้งานในครั้งต่อไป

STEP 27

ตรวจสอบโฟลเดอร์โปรเจกต์

จากตัวอย่าง ทำการสร้าง Folder เก็บไฟล์ไว้ที่ Drive D Folder ชื่อ Data_Java65it1 เพื่อใช้เป็นพื้นที่จัดเก็บ Source Code และไฟล์ที่เกี่ยวข้องกับการเรียน Java

STEP 28

เตรียมสร้างไฟล์ Java

เตรียมพื้นที่สำหรับสร้างไฟล์ Source Code ที่มีนามสกุล .java โดยไฟล์ Java จะเป็นพื้นที่สำหรับ เขียนคำสั่งและโครงสร้างของโปรแกรม ที่จะนำไป Compile และ Run ต่อไป

STEP 29

ขั้นตอนการติดตั้ง Extensions เพื่อรองรับการเขียนโปรแกรมด้วยภาษา Java

ติดตั้ง Extensions ที่จำเป็น เพื่อให้ Visual Studio Code สามารถรองรับการเขียนโปรแกรม ด้วยภาษา Java ได้อย่างเหมาะสม Extensions ช่วยเพิ่มความสามารถ เช่น การตรวจสอบ Syntax การแสดงข้อผิดพลาด และการช่วยจัดการโปรแกรม Java

STEP 30

เปิดไฟล์ Java

คลิก Explore → Untitled Workspace จากนั้นเลือก Folder ที่สร้างไว้ ตัวอย่างคือ Data_Java64it1 เพื่อเปิดโฟลเดอร์ใน Visual Studio Code และเตรียมสร้างไฟล์ Java

STEP 31

สร้างไฟล์สำหรับเขียนโปรแกรม

คลิกขวาที่โฟลเดอร์ เพื่อสร้างไฟล์ใหม่ โดยไฟล์ที่สร้างสำหรับภาษา Java ควรมีนามสกุล .java เพื่อให้โปรแกรมสามารถตรวจสอบ และจัดการไฟล์ในรูปแบบ Java ได้

STEP 32

ตั้งชื่อไฟล์

ตั้งชื่อไฟล์ตามที่ต้องการ และตรวจสอบนามสกุลของไฟล์ ให้เป็น .java จากนั้นกดปุ่ม Enter เพื่อยืนยันชื่อไฟล์

STEP 33

ตั้งชื่อ class

การสร้างไฟล์ใหม่จะเป็นการสร้างพื้นที่ สำหรับเขียนโปรแกรม Java โดยชื่อ class ที่ประกาศในกรณีของ public class ควรสอดคล้องกับชื่อไฟล์ Java ตัวอย่างเช่น หากไฟล์ชื่อ Test1.java สามารถประกาศ class เป็น Test1 ได้

STEP 34

ตรวจสอบชื่อ class

ชื่อ class คือ test1 ซึ่งเป็นส่วนหนึ่งของโครงสร้างภาษา Java ชื่อ class ควรตั้งให้สื่อความหมาย และควรตรวจสอบการใช้ตัวพิมพ์เล็ก และตัวพิมพ์ใหญ่ให้ถูกต้อง เนื่องจาก Java แยกตัวพิมพ์เล็ก และตัวพิมพ์ใหญ่ออกจากกัน

STEP 35

สร้าง function main

สร้างเมธอด main() ซึ่งเป็นจุดเริ่มต้นการทำงานของโปรแกรม Java เมื่อเรียกใช้งานโปรแกรม ระบบจะเริ่มต้นการทำงานจากเมธอดนี้ โดยรูปแบบพื้นฐานคือ public static void main(String[] args)

STEP 36

ตรวจสอบผลการทำงาน

ตรวจสอบผลลัพธ์หลังจากดำเนินการ และเตรียมเข้าสู่ขั้นตอนการ Run โปรแกรม Java หากโครงสร้างโปรแกรมถูกต้อง สามารถดำเนินการ Compile และเรียกใช้งานโปรแกรมได้

สรุปบทเรียน

การพัฒนาโปรแกรม Java จำเป็นต้องเตรียม เครื่องมือและสภาพแวดล้อมให้พร้อมก่อนเริ่มเขียนโปรแกรม โดย JDK (Java Development Kit) เป็นเครื่องมือสำคัญสำหรับการพัฒนา Java เนื่องจากภายในมีเครื่องมือสำหรับ Compile และจัดการโปรแกรม Java

หลังจากติดตั้ง JDK แล้ว ควรตรวจสอบการทำงานของ Java ผ่าน Command Prompt ด้วยคำสั่ง java -version และ javac -version เพื่อยืนยันว่าระบบสามารถเรียกใช้ Java และ Java Compiler ได้

หากระบบไม่สามารถเรียกใช้คำสั่ง java หรือ javac อาจต้องตรวจสอบการตั้งค่า Environment Variable และ PATH เพื่อให้ระบบสามารถค้นหาตำแหน่ง ของโปรแกรม Java ได้

จากนั้นจึงเตรียมโปรแกรมสำหรับเขียน Source Code เช่น Visual Studio Code และสร้างโฟลเดอร์สำหรับจัดเก็บไฟล์ เพื่อให้สามารถจัดการโปรเจกต์ และไฟล์ Java ได้อย่างเป็นระบบ

Source Code ของ Java จะถูกจัดเก็บ ในไฟล์ที่มีนามสกุล .java เช่น Main.java จากนั้นสามารถใช้คำสั่ง javac Main.java เพื่อ Compile Source Code ให้เป็น Bytecode

เมื่อต้องการ Run โปรแกรม ให้ใช้คำสั่ง java Main เพื่อเรียกใช้งานโปรแกรม โดย Java จะเริ่มต้นการทำงาน จากเมธอด main()

ดังนั้นลำดับพื้นฐานของการพัฒนาโปรแกรม Java คือ การติดตั้ง JDK การตรวจสอบ Java การตั้งค่า PATH หากจำเป็น การเตรียมโปรแกรมสำหรับเขียนโค้ด การสร้างไฟล์ .java การเขียน Source Code การ Compile และการ Run โปรแกรม
