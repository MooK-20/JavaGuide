บทที่ 4

การสร้างและเรียกใช้งาน Classes

การเขียนโปรแกรมภาษาจาวาเริ่มต้นจากการสร้าง Class และเขียนคำสั่งต่าง ๆ ตามโครงสร้างของภาษาจาวา โดยผู้เรียนสามารถใช้โปรแกรมสำหรับเขียน Source Code เช่น Visual Studio Code (VS Code) ในการสร้าง แก้ไข และตรวจสอบโปรแกรม การทำความเข้าใจโครงสร้างของโปรแกรมตั้งแต่เริ่มต้น จะช่วยให้ผู้เรียนสามารถเขียนโปรแกรมได้อย่างเป็นระบบ และสามารถพัฒนาโปรแกรมที่มีความซับซ้อนมากขึ้นในอนาคต

โปรแกรมภาษาจาวาโดยทั่วไปจะประกอบด้วย Class ซึ่งเป็นโครงสร้างสำคัญที่ใช้จัดเก็บข้อมูล และคำสั่งต่าง ๆ ของโปรแกรม ภายใน Class สามารถประกาศตัวแปร สร้างเมธอด และเขียนคำสั่งสำหรับประมวลผลข้อมูลได้ โดยโปรแกรมที่สามารถเริ่มทำงานได้โดยตรง มักจะมีเมธอด main() ซึ่งทำหน้าที่เป็นจุดเริ่มต้นของการทำงาน

1. การเริ่มต้นเขียนโปรแกรมภาษาจาวา

โจทย์ : เริ่มสร้าง Class ชื่อ Class โดยแนะนำให้ขึ้นต้นด้วยตัวอักษรพิมพ์ใหญ่ ตัวอย่างเช่น Data1 พิมพ์คำว่า class ตามด้วยชื่อ Class และใช้เครื่องหมาย { } เพื่อกำหนดขอบเขตของ Class เมื่อสร้าง Class แล้ว ภายใน Class สามารถเรียกใช้คำสั่ง สำหรับแสดงผลทางหน้าจอได้

Class เปรียบเสมือนโครงสร้างหลักของโปรแกรม ที่ใช้รวบรวมข้อมูลและพฤติกรรมที่เกี่ยวข้องกัน การตั้งชื่อ Class ควรสื่อความหมายถึงหน้าที่ หรือสิ่งที่ Class นั้นทำงานเกี่ยวข้องด้วย เพื่อช่วยให้ผู้เขียนโปรแกรมและผู้ที่มาศึกษาโค้ดภายหลัง สามารถทำความเข้าใจโปรแกรมได้ง่ายขึ้น

เครื่องหมาย { } เรียกว่า Curly Braces หรือวงเล็บปีกกา ใช้สำหรับกำหนดขอบเขตของ Class และขอบเขตของเมธอดต่าง ๆ คำสั่งที่อยู่ภายในวงเล็บปีกกาจะถือว่าอยู่ภายใต้ขอบเขตนั้น ดังนั้นผู้เรียนควรตรวจสอบการเปิดและปิดวงเล็บ ให้ครบถ้วนอยู่เสมอ

1.1 สร้าง Class ชื่อ class 

class Data1 {

}
ตัวอย่าง

ขั้นตอนที่ 1 เริ่มสร้าง Class ชื่อ Data1 แนะนำให้ขึ้นต้นด้วยตัวอักษรพิมพ์ใหญ่ โดยพิมพ์คำว่า class ตามด้วยชื่อ Class และใช้เครื่องหมาย { เพื่อกำหนดขอบเขตของ Class จากนั้นปิด Class ด้วยเครื่องหมาย } ภายใน Class สามารถเขียนคำสั่งต่าง ๆ ที่ต้องการให้โปรแกรมทำงานได้

การตั้งชื่อ Class ควรใช้ชื่อที่สื่อความหมาย และควรหลีกเลี่ยงชื่อที่ทำให้เกิดความสับสน เช่น ชื่อที่เป็นคำสงวนของภาษา Java นอกจากนี้หาก Class มีชื่อว่า Data1 ไฟล์ Java ที่ประกาศเป็น public class โดยทั่วไปควรมีชื่อไฟล์สอดคล้องกันเป็น Data1.java

1.2 เปิด function main 

public static void main(String[] args) {

}
ตัวอย่าง

ขั้นตอนที่ 2 เปิด function main โดยสามารถพิมพ์ main แล้วกดปุ่ม Tab เพื่อยอมรับการสร้างโครงสร้าง main จาก Extension ที่ติดตั้งไว้ใน Visual Studio Code

เมธอด main เป็นจุดเริ่มต้นของโปรแกรม Java เมื่อสั่งให้โปรแกรมทำงาน Java Virtual Machine หรือ JVM จะเริ่มประมวลผลคำสั่งที่อยู่ภายใน main() ตามลำดับจากบนลงล่าง ดังนั้นคำสั่งที่ต้องการให้ทำงานเมื่อเริ่มโปรแกรม สามารถเขียนไว้ภายในเมธอดนี้ได้

ส่วนประกอบของ public static void main(String[] args) มีหน้าที่แตกต่างกัน โดย public ใช้กำหนดการเข้าถึงเมธอด static ทำให้สามารถเรียกใช้เมธอดได้โดยไม่ต้องสร้าง Object void หมายถึงเมธอดนี้ไม่มีค่าที่ส่งกลับ และ String[] args ใช้รับข้อมูลที่ส่งเข้ามา จาก Command Line

2. โครงสร้างภาษาจาวา

ในภาษาจาวาจะใช้เมธอด print และ println ในการแสดงผลทางจอภาพ โดยเมธอดทั้งสองอยู่ภายใน Object ของ out และ out อยู่ภายใน Class ของ System รูปแบบการใช้งานเมธอดทั้งสองคือ

การแสดงผลเป็นพื้นฐานสำคัญของการเขียนโปรแกรม เพราะช่วยให้ผู้เขียนโปรแกรมสามารถตรวจสอบผลลัพธ์ จากการประมวลผลของโปรแกรมได้ เช่น ตรวจสอบค่าตัวแปร ตรวจสอบผลการคำนวณ หรือแสดงข้อความเพื่อแจ้งข้อมูลให้กับผู้ใช้งาน

คำสั่ง หน้าที่
System.out.print(data); แสดงข้อความทางจอภาพ โดยไม่มีการขึ้นบรรทัดใหม่
System.out.println(data); แสดงข้อความทางจอภาพ และขึ้นบรรทัดใหม่

หากต้องการแสดงข้อความหลายรายการ ผู้เขียนโปรแกรมสามารถเลือกใช้ print หรือ println ตามรูปแบบผลลัพธ์ที่ต้องการ โดย print จะคงเคอร์เซอร์ไว้ที่บรรทัดเดิม ส่วน println จะเลื่อนเคอร์เซอร์ไปยังบรรทัดถัดไป หลังจากแสดงข้อมูลเสร็จ

2.1 คำสั่ง System.out.print()

ใช้สำหรับแสดงข้อความทางจอภาพ โดยหลังจากแสดงข้อความแล้ว เคอร์เซอร์จะไม่ขึ้นบรรทัดใหม่ จึงเหมาะสำหรับการแสดงข้อมูล ที่ต้องการให้อยู่ต่อเนื่องกันในบรรทัดเดียว

นอกจากข้อความแล้ว print() ยังสามารถใช้แสดงค่าตัวแปร ตัวเลข และผลลัพธ์จากนิพจน์ต่าง ๆ ได้ โดยข้อมูลที่ส่งเข้าไปภายในวงเล็บ จะเป็นข้อมูลที่ต้องการให้โปรแกรมแสดงผล 

System.out.print("Hello ");
System.out.print("Java");
ตัวอย่าง

สามารถพิมพ์ sysout แล้วกด Tab เพื่อสร้างคำสั่ง System.out.println() หรือเลือกใช้คำสั่ง System.out.print() เมื่อต้องการให้ข้อความยังคงอยู่ในบรรทัดเดียวกัน

2.2 คำสั่ง System.out.println()

ใช้สำหรับแสดงข้อความทางจอภาพ และเมื่อแสดงข้อความเสร็จแล้ว เคอร์เซอร์จะเลื่อนไปยังบรรทัดใหม่ จึงเหมาะสำหรับการแสดงข้อมูล ที่ต้องการจัดให้อยู่คนละบรรทัด

println() สามารถใช้แสดงข้อความ ตัวเลข ค่าของตัวแปร รวมถึงผลลัพธ์จากการคำนวณได้ โดยสามารถใช้เครื่องหมาย + เพื่อเชื่อมข้อความกับค่าของตัวแปร และแสดงผลออกมาในรูปแบบที่เข้าใจง่าย

ตัวอย่าง
ผลลัพธ์ 
System.out.println("tsuwannee");
System.out.println("ยินดีต้อนรับ");
ตัวอย่าง

ข้อสังเกต บรรทัดที่ 7 ใช้คำสั่งแสดงผล โดยแสดงข้อมูลในรูปแบบข้อความ ข้อความที่ต้องการแสดงผล จะต้องอยู่ภายในเครื่องหมาย " " เช่น "test" เพื่อให้ Java ทราบว่าข้อมูลดังกล่าวเป็น String

📌 ข้อสังเกต

การแสดงข้อมูลแบบข้อความ จะต้องเขียนข้อความไว้ภายในเครื่องหมาย " "

ตัวอย่างเช่น "test"

หากต้องการแสดงตัวเลขโดยตรง เช่น 100 สามารถเขียนโดยไม่ต้องใช้เครื่องหมายคำพูด เพราะ Java จะมองว่าเป็นข้อมูลตัวเลข แต่ถ้าเขียน "100" Java จะมองว่าเป็นข้อมูลชนิด String

🔤 3. Escape Sequence

คำสั่ง print และ println สามารถใช้ Escape Sequence ในการแสดงผลได้ โดยใช้เครื่องหมาย \ (Backslash) นำหน้าด้วยอักขระควบคุมหนึ่งตัว

Escape Sequence มีประโยชน์ในการควบคุมรูปแบบ ของข้อความที่แสดงบนหน้าจอ โดยเฉพาะกรณีที่ต้องการขึ้นบรรทัดใหม่ จัดระยะห่างด้วย Tab หรือแสดงเครื่องหมายพิเศษ ที่มีความหมายเฉพาะในภาษา Java

Escape Sequence ความหมาย
\n ขึ้นบรรทัดใหม่
\t แท็บในแนวนอน
\b ถอยหลัง 1 ช่อง
\r เลื่อนเคอร์เซอร์ไปทางซ้ายสุด
\\ แสดงตัวอักษร Backslash
\' แสดงตัวอักษร Single Quote
\" แสดงตัวอักษร Double Quote

การเลือกใช้ Escape Sequence ควรเลือกให้เหมาะกับรูปแบบข้อมูล เช่น หากต้องการแบ่งข้อความออกเป็นหลายบรรทัด สามารถใช้ \n หากต้องการจัดตำแหน่งข้อมูลให้เป็นระเบียบ สามารถใช้ \t และหากต้องการแสดงเครื่องหมายคำพูด ภายในข้อความ สามารถใช้ \"

System.out.println("Name\tScore");
System.out.println("\"Java\"");

📝 4. การเขียนหมายเหตุภาษาจาวา

การเขียนหมายเหตุในภาษาจาวา มี 2 รูปแบบหลัก คือ // และ /* ... */

หมายเหตุ หรือ Comment ใช้สำหรับอธิบายรายละเอียดของโปรแกรม เช่น อธิบายว่าคำสั่งแต่ละส่วนทำหน้าที่อะไร อธิบายตัวแปร หรือบันทึกข้อมูลที่ช่วยให้ ผู้เขียนโปรแกรมสามารถกลับมาทำความเข้าใจโค้ดได้ง่ายขึ้น Comment จะไม่ถูกนำไปประมวลผลเป็นคำสั่งของโปรแกรม

รูปแบบ การใช้งาน
// หมายเหตุ 1 บรรทัด
/* ... */ หมายเหตุหลายบรรทัด หรือกำหนดช่วงข้อมูล

📊 5. ชนิดของข้อมูล ตัวแปร และค่าคงที่

ในการเขียนโปรแกรมจำเป็นต้องมีการจัดเก็บข้อมูล เพื่อใช้ในการประมวลผล เช่น ชื่อนักเรียน อายุ คะแนน เงินเดือน หรือสถานะต่าง ๆ ภาษาจาวาจึงกำหนดชนิดข้อมูล เพื่อให้โปรแกรมทราบว่าข้อมูลแต่ละตัว มีรูปแบบและลักษณะอย่างไร

การเลือกชนิดข้อมูลให้เหมาะสม มีความสำคัญต่อการทำงานของโปรแกรม เพราะช่วยให้สามารถจัดเก็บและประมวลผลข้อมูลได้ถูกต้อง รวมถึงช่วยให้โปรแกรมมีโครงสร้างที่ชัดเจน และสามารถดูแลรักษาได้ง่าย

5.1 ชนิดของข้อมูล (Data Type)

ชนิดข้อมูลในภาษาจาวาแบ่งเป็น 2 ประเภทใหญ่ ๆ คือ Primitive Data Type และ Reference Data Type โดยทั้งสองประเภทมีลักษณะการจัดเก็บ และการนำข้อมูลไปใช้งานแตกต่างกัน

5.1.1 ชนิดข้อมูลแบบพื้นฐาน (Primitive Data Type)

หมายถึงชนิดข้อมูลพื้นฐานของภาษา Java ใช้สำหรับเก็บค่าข้อมูลโดยตรง โดยมีทั้งหมด 8 ชนิด ได้แก่ boolean, byte, short, int, long, float, double และ char

ชนิดข้อมูล ขนาด (bit) ค่าที่เก็บได้
boolean JVM กำหนด true หรือ false
byte 8 -128 ถึง 127
short 16 -32768 ถึง 32767
int 32 -2147483648 ถึง 2147483647
long 64 -9223372036854775808 ถึง 9223372036854775807
float 32 ประมาณ -3.4E38 ถึง 3.4E38
double 64 ประมาณ -1.7E308 ถึง 1.7E308
char 16 0 ถึง 65535

ในการเลือกใช้งานชนิดข้อมูล ควรพิจารณาจากลักษณะของข้อมูล เช่น หากเป็นจำนวนเต็มทั่วไป มักใช้ int หากเป็นจำนวนที่มีทศนิยม สามารถใช้ double และหากเป็นค่าที่มีเพียงสองสถานะ เช่น ใช่หรือไม่ใช่ สามารถใช้ boolean

5.1.2 ชนิดข้อมูลแบบอ้างอิง (Reference Data Type)

ชนิดข้อมูลแบบอ้างอิงมีความแตกต่างกับชนิดข้อมูลพื้นฐาน เนื่องจากตัวแปรประเภทนี้ใช้เก็บค่าที่เป็นการอ้างอิง ไปยัง Object ที่อยู่ในหน่วยความจำ ตัวอย่างเช่น String, Array, List, Set และ Stack

ข้อมูลประเภท Reference Data Type มักเกี่ยวข้องกับ Object ที่สร้างขึ้นจาก Class จึงสามารถมีคุณสมบัติและเมธอดต่าง ๆ สำหรับนำข้อมูลไปใช้งาน ตัวอย่างเช่น String สามารถใช้เมธอดสำหรับตรวจสอบความยาวข้อความ เปรียบเทียบข้อความ หรือจัดการข้อมูลข้อความได้

💡 การจัดเก็บข้อมูลแบบอ้างอิง

Execution Stack เก็บค่าอ้างอิงที่ชี้ไปยัง Heap Memory

Heap Memory เก็บ Object ที่สร้างขึ้นมาจาก Class

การเข้าใจแนวคิดเรื่อง Stack และ Heap จะช่วยให้ผู้เรียนเข้าใจการทำงานของตัวแปร และ Object ในภาษา Java ได้ดีขึ้น

5.2 ตัวแปร (Variable)

ตัวแปรคือชื่อที่ตั้งหรือนิยามขึ้นมา เพื่อใช้สำหรับเก็บข้อมูล สำหรับนำไปใช้ในโปรแกรม โดยตัวแปรควรตั้งชื่อให้สอดคล้อง กับงานที่กำลังทำ

ตัวแปรสามารถกำหนดค่าในตอนประกาศ หรือกำหนดค่าภายหลังได้ และในระหว่างการทำงานของโปรแกรม ค่าที่เก็บอยู่ในตัวแปรสามารถเปลี่ยนแปลงได้ หากตัวแปรนั้นไม่ได้ถูกกำหนดเป็นค่าคงที่ด้วย final

ตัวแปรแต่ละตัวจะมีทั้งชื่อ ชนิดข้อมูล และค่า โดยชนิดข้อมูลจะกำหนดว่าตัวแปรสามารถเก็บข้อมูลประเภทใด ส่วนชื่อของตัวแปรจะใช้สำหรับอ้างถึงข้อมูลนั้น ภายในขอบเขตที่ตัวแปรสามารถเข้าถึงได้

5.2.1 ประเภทของตัวแปรพื้นฐาน

ประเภท ชนิดข้อมูล
Character char, String
Floating-Point float, double
Integers byte, short, int, long
Boolean boolean

การเลือกประเภทตัวแปรควรสัมพันธ์กับข้อมูลที่ต้องการจัดเก็บ เช่น คะแนน อายุ หรือจำนวนสินค้า สามารถใช้ int ได้เมื่อข้อมูลเป็นจำนวนเต็ม หากเป็นราคาหรือข้อมูลที่มีทศนิยม อาจเลือกใช้ double ส่วนข้อมูลที่เป็นสถานะ เช่น เปิดหรือปิด สามารถใช้ boolean ได้

5.2.2 รูปแบบการตั้งชื่อ (กรณีเขียนโปรแกรมด้วย Text Editor VS Code)

การตั้งชื่อเป็นส่วนสำคัญของการเขียนโปรแกรม เพราะชื่อที่ดีจะช่วยให้ผู้เขียนโปรแกรม เข้าใจหน้าที่ของ Class ตัวแปร และค่าคงที่ได้โดยไม่จำเป็นต้องอ่านคำสั่งทั้งหมด ควรเลือกชื่อที่สื่อความหมาย และใช้รูปแบบการตั้งชื่อให้สม่ำเสมอ

  1. ชื่อ Class ควรกำหนดตัวอักษรแรกเป็นตัวพิมพ์ใหญ่ และหากชื่อประกอบด้วยหลายคำ สามารถใช้ตัวพิมพ์ใหญ่ขึ้นต้นคำใหม่ เช่น StudentData
  2. ชื่อตัวแปร แนะนำให้ขึ้นต้นด้วยตัวพิมพ์เล็ก และหากมีหลายคำสามารถใช้รูปแบบ camelCase เช่น studentName หรือ totalScore
  3. ค่าคงที่ โดยทั่วไปนิยมใช้ตัวพิมพ์ใหญ่ และใช้เครื่องหมายขีดล่าง เพื่อแบ่งคำ เช่น MAX_SCORE

5.2.3 รูปแบบการประกาศตัวแปร

การประกาศตัวแปรในภาษา Java สามารถเขียนได้ในรูปแบบ ชนิดข้อมูล ตามด้วยชื่อตัวแปร และสามารถกำหนดค่าเริ่มต้นได้ทันที 

ชนิดข้อมูล ชื่อตัวแปร;

ชนิดข้อมูล ชื่อตัวแปร = ค่าเริ่มต้น;
ตัวอย่าง

5.2.4 กฎการตั้งชื่อตัวแปร

การตั้งชื่อตัวแปรต้องเป็นไปตามกฎของภาษา Java เพื่อให้ Compiler สามารถตรวจสอบและแปลโปรแกรมได้อย่างถูกต้อง นอกจากนี้ควรเลือกชื่อที่สื่อความหมาย และหลีกเลี่ยงการใช้ชื่อสั้นจนไม่ทราบความหมาย

  1. ขึ้นต้นด้วยตัวอักษร A-Z หรือ a-z หรือเครื่องหมาย _
  2. ตัวอักษรถัดไปสามารถเป็นตัวอักษร ตัวเลข หรือ _
  3. ห้ามใช้คำสงวนของ Java เป็นชื่อตัวแปร
  4. ห้ามขึ้นต้นด้วยตัวเลข
  5. Java แยกความแตกต่างระหว่างตัวพิมพ์เล็ก และตัวพิมพ์ใหญ่ เช่น score และ Score ถือเป็นชื่อคนละตัวกัน
ชนิดตัวแปร ชื่อตัวแปร เก็บค่า
String name ชื่อ
String nameStudent ชื่อนักเรียน
int salary เงินเดือน
int score คะแนน

5.2.5 การใช้คำสั่งแสดงผลตัวแปร

เช่น ต้องการเขียนโปรแกรม กำหนดค่าคะแนนย่อยเรื่องตัวแปร กำหนดชื่อตัวแปร scoreVariable กำหนดค่าเท่ากับ 25 และกำหนดค่าคะแนนย่อยเรื่องการแสดงผลข้อมูล โดยกำหนดชื่อตัวแปร scoreDisplay กำหนดค่าเท่ากับ 20 

int scoreVariable = 25;
int scoreDisplay = 20;

System.out.println("คะแนนย่อยเรื่องตัวแปร = " + scoreVariable);
System.out.println("คะแนนย่อยเรื่องการแสดงผลข้อมูล = " + scoreDisplay);
ตัวอย่าง

บรรทัดที่ 1 กำหนดชื่อตัวแปร scoreVariable และกำหนดค่าเท่ากับ 25

บรรทัดที่ 2 กำหนดชื่อตัวแปร scoreDisplay และกำหนดค่าเท่ากับ 20

คำสั่ง System.out.println() ใช้สำหรับแสดงข้อมูลของตัวแปร โดยสามารถใช้เครื่องหมาย + เชื่อมข้อความกับค่าที่เก็บอยู่ในตัวแปร

การเชื่อมข้อความกับตัวแปรด้วยเครื่องหมาย + เรียกว่า String Concatenation ซึ่งช่วยให้สามารถแสดงข้อความอธิบาย พร้อมกับค่าของตัวแปรในบรรทัดเดียวกันได้

ผลลัพธ์

ข้อสังเกต จากผลลัพธ์ หากแสดงเพียงตัวเลข เช่น 25 และ 20 ผู้ที่อ่านผลลัพธ์อาจไม่สามารถทราบได้ทันที ว่าตัวเลขดังกล่าวเกี่ยวข้องกับข้อมูลอะไร ดังนั้นควรเพิ่มข้อความอธิบาย เพื่อให้ผลลัพธ์มีความหมายและเข้าใจได้ง่ายขึ้น

จากตัวอย่างสามารถเพิ่มข้อความ เช่น คะแนนย่อยเรื่องตัวแปร และคะแนนย่อยเรื่องการแสดงผลข้อมูล โดยใช้เครื่องหมาย + เชื่อมข้อความกับตัวแปร

ระหว่างข้อความ String กับค่าที่ต้องการแสดงผลจากตัวแปร ให้ใช้เครื่องหมาย + เพื่อเชื่อมข้อมูลเข้าด้วยกัน ซึ่งเป็นรูปแบบสำคัญที่ใช้ในการแสดงผลข้อมูลใน Java

5.2.7 ชนิดของตัวแปร

ตัวแปรยังสามารถพิจารณาตามขอบเขตการใช้งาน หรือ Scope ได้ โดยขอบเขตจะกำหนดว่าตัวแปรสามารถถูกเรียกใช้งาน จากส่วนใดของโปรแกรมได้บ้าง การเข้าใจ Scope มีความสำคัญ เพราะช่วยป้องกันการเรียกใช้ตัวแปรผิดตำแหน่ง และช่วยจัดโครงสร้างโปรแกรมให้เป็นระบบ

ประเภท ความหมาย
Global Variable ตัวแปรที่ประกาศไว้นอกฟังก์ชัน ซึ่งสามารถนำไปใช้งานในส่วนต่าง ๆ ตามขอบเขตที่กำหนด
Local Variable ตัวแปรที่ประกาศภายในฟังก์ชัน และสามารถใช้งานภายในขอบเขต ของฟังก์ชันหรือบล็อกนั้น

ในการเขียนโปรแกรมควรพิจารณาขอบเขตของตัวแปร ให้เหมาะสมกับการใช้งาน หากข้อมูลจำเป็นต้องใช้เฉพาะในเมธอดใดเมธอดหนึ่ง ควรประกาศเป็น Local Variable เพื่อให้ขอบเขตของข้อมูลชัดเจน และลดโอกาสที่จะเกิดผลกระทบกับส่วนอื่นของโปรแกรม

5.3 ค่าคงที่

ค่าคงที่คือค่าที่กำหนดไว้ และไม่ต้องการให้มีการเปลี่ยนแปลง ระหว่างการทำงานของโปรแกรม ในภาษา Java สามารถใช้คำสั่ง final เพื่อกำหนดตัวแปรให้ไม่สามารถกำหนดค่าใหม่ได้ หลังจากได้รับค่าแล้ว

ค่าคงที่เหมาะสำหรับข้อมูลที่มีค่าคงเดิม เช่น จำนวนวันในหนึ่งสัปดาห์ ค่าคะแนนเต็ม หรือค่าที่ใช้เป็นขนาดของข้อมูล การใช้ค่าคงที่ช่วยลดการเขียนค่าซ้ำ ๆ และช่วยให้สามารถแก้ไขค่าที่ต้องการใช้ร่วมกัน ได้ง่ายขึ้น

5.3.1 รูปแบบการประกาศค่าคงที่ 

final ชนิดตัวแปร ชื่อตัวแปร;

5.3.2 ตัวอย่างค่าคงที่ 

final int SIZE = 50;

System.out.println(SIZE);

จากตัวอย่าง SIZE เป็นค่าคงที่ชนิด int และกำหนดค่าเริ่มต้นเป็น 50 เมื่อโปรแกรมนำ SIZE ไปใช้งาน จะสามารถอ่านค่าดังกล่าวได้ แต่ไม่ควรกำหนดค่าใหม่ให้กับตัวแปรที่ประกาศด้วย final

⚠️ ข้อควรจำ

เมื่อกำหนดตัวแปรด้วยคำสั่ง final แล้ว ไม่สามารถกำหนดค่าใหม่ให้กับตัวแปรนั้นได้

การตั้งชื่อค่าคงที่โดยทั่วไปนิยมใช้ ตัวพิมพ์ใหญ่ และใช้เครื่องหมาย _ เพื่อแบ่งคำ เช่น MAX_SCORE หรือ DEFAULT_SIZE

📌 สรุปบทเรียน

การเขียนโปรแกรมภาษาจาวาเริ่มต้นจากการสร้าง Class และกำหนดเมธอด main() เพื่อเป็นจุดเริ่มต้นการทำงานของโปรแกรม โดยคำสั่งต่าง ๆ จะถูกเขียนอยู่ภายในขอบเขต ของ Class และเมธอดที่เกี่ยวข้อง

การแสดงผลทางหน้าจอสามารถใช้ System.out.print() และ System.out.println() โดย print() จะไม่ขึ้นบรรทัดใหม่ ส่วน println() จะเลื่อนไปยังบรรทัดใหม่ หลังจากแสดงข้อมูล

ผู้เรียนสามารถใช้ Escape Sequence เพื่อควบคุมรูปแบบการแสดงผล เช่น \n สำหรับขึ้นบรรทัดใหม่ และ \t สำหรับการเว้นระยะ Tab

การเขียนหมายเหตุหรือ Comment สามารถใช้ // สำหรับหมายเหตุหนึ่งบรรทัด และ /* ... */ สำหรับหมายเหตุหลายบรรทัด ซึ่งช่วยให้ Source Code อ่านง่าย และสามารถดูแลรักษาได้สะดวก

ภาษาจาวามีชนิดข้อมูล Primitive Data Type และ Reference Data Type โดย Primitive Data Type ประกอบด้วยข้อมูลพื้นฐาน 8 ชนิด ส่วน Reference Data Type ใช้สำหรับอ้างอิง Object และข้อมูลประเภทต่าง ๆ เช่น String และ Array

ตัวแปรใช้สำหรับเก็บข้อมูลที่โปรแกรมต้องนำไปใช้งาน และสามารถกำหนดค่าใหม่ได้ตามการทำงานของโปรแกรม การตั้งชื่อตัวแปรควรสื่อความหมาย และต้องปฏิบัติตามกฎการตั้งชื่อของภาษา Java

การแสดงค่าของตัวแปรร่วมกับข้อความ สามารถใช้เครื่องหมาย + เพื่อเชื่อม String กับค่าของตัวแปร ทำให้ผลลัพธ์มีความชัดเจน และช่วยให้ผู้ใช้งานเข้าใจข้อมูลที่แสดงได้ง่ายขึ้น

ตัวแปรมีขอบเขตการใช้งาน ซึ่งสามารถพิจารณาได้จากตำแหน่งที่ประกาศตัวแปร เช่น Local Variable ที่ใช้งานภายในขอบเขตที่กำหนด การกำหนด Scope อย่างเหมาะสม ช่วยให้โปรแกรมมีโครงสร้างที่เป็นระเบียบ

ค่าคงที่สามารถกำหนดด้วยคำสั่ง final เพื่อป้องกันการกำหนดค่าใหม่ หลังจากได้รับค่าแล้ว และโดยทั่วไปนิยมตั้งชื่อค่าคงที่ ด้วยตัวอักษรพิมพ์ใหญ่ เพื่อให้สามารถสังเกตได้ง่าย

ความรู้เกี่ยวกับ Class, main(), การแสดงผล ชนิดข้อมูล ตัวแปร ขอบเขตของตัวแปร และค่าคงที่ เป็นพื้นฐานสำคัญสำหรับการเขียนโปรแกรม Java ผู้เรียนควรฝึกเขียนและทดลองแก้ไขค่าต่าง ๆ เพื่อทำความเข้าใจการทำงานของโปรแกรม และสามารถนำความรู้ไปประยุกต์ใช้ กับโปรแกรมที่มีความซับซ้อนมากขึ้นได้
