ความรู้เบื้องต้นภาษา Java

ความหมายของภาษา Java

Java คือภาษาโปรแกรมระดับสูงที่ได้รับการออกแบบมา เพื่อใช้พัฒนาโปรแกรมคอมพิวเตอร์ได้หลากหลายรูปแบบ โดยมีจุดเด่นด้านความสามารถในการทำงานข้ามแพลตฟอร์ม และสนับสนุนแนวคิดการเขียนโปรแกรมเชิงวัตถุ หรือ Object-Oriented Programming ซึ่งเป็นแนวคิดสำคัญ ที่ใช้ในการออกแบบและพัฒนาโปรแกรมขนาดเล็กจนถึงระบบขนาดใหญ่

ภาษา Java มีรูปแบบไวยากรณ์ที่เป็นระบบ และมีโครงสร้างที่ช่วยให้ผู้พัฒนาสามารถแบ่งโปรแกรม ออกเป็นส่วนต่าง ๆ ได้อย่างชัดเจน จึงเหมาะสำหรับการเรียนรู้หลักการเขียนโปรแกรม และสามารถนำความรู้ไปประยุกต์ใช้ในการพัฒนาซอฟต์แวร์ ในระดับที่ซับซ้อนมากขึ้นได้

Java คืออะไร

Java เป็นภาษาโปรแกรมที่ใช้สำหรับสร้างซอฟต์แวร์ และระบบคอมพิวเตอร์หลายประเภท โดยมีจุดเด่นด้านการทำงานข้ามแพลตฟอร์ม การเขียนโปรแกรมเชิงวัตถุ การจัดการหน่วยความจำ และการมี Library และ API จำนวนมาก สำหรับช่วยในการพัฒนาโปรแกรม

ประวัติความเป็นมาของภาษา Java

ภาษา Java เริ่มต้นการพัฒนาในช่วงต้นทศวรรษ 1990 โดยทีมวิศวกรของบริษัท Sun Microsystems ซึ่งมี James Gosling เป็นหนึ่งในบุคคลสำคัญของโครงการ ภาษาในช่วงเริ่มต้นมีชื่อว่า Oak ก่อนที่จะเปลี่ยนชื่อเป็น Java ในเวลาต่อมา

Java ได้รับการออกแบบโดยมีแนวคิดให้โปรแกรม สามารถนำไปทำงานบนระบบคอมพิวเตอร์ที่แตกต่างกันได้ โดยไม่จำเป็นต้องเขียนโปรแกรมใหม่ทั้งหมด แนวคิดนี้เป็นพื้นฐานของคำว่า Write Once, Run Anywhere ซึ่งเป็นหนึ่งในแนวคิดสำคัญที่ทำให้ Java ได้รับความนิยมอย่างกว้างขวาง

Java เปิดตัวต่อสาธารณะอย่างเป็นทางการในปี 1995 และได้รับการนำไปใช้งานในหลายด้าน เช่น ระบบซอฟต์แวร์ระดับองค์กร ระบบ Server โปรแกรม Desktop ระบบเครือข่าย และระบบประมวลผลข้อมูล

พัฒนาการที่สำคัญของ Java
  • เริ่มต้นพัฒนาในช่วงต้นทศวรรษ 1990
  • พัฒนาโดยทีมงานของ Sun Microsystems
  • James Gosling เป็นบุคคลสำคัญในการพัฒนาภาษา
  • ภาษาในช่วงแรกมีชื่อว่า Oak
  • Java เปิดตัวอย่างเป็นทางการในปี 1995
  • ต่อมา Java ถูกนำไปใช้งานอย่างแพร่หลายในระบบซอฟต์แวร์หลายประเภท

คุณลักษณะสำคัญของภาษา Java

ภาษา Java มีคุณลักษณะหลายประการที่ช่วยให้เหมาะสม สำหรับการพัฒนาโปรแกรม โดยเฉพาะโปรแกรมที่ต้องการ ความสามารถในการทำงานบนระบบที่แตกต่างกัน และโปรแกรมที่มีโครงสร้างขนาดใหญ่

คุณลักษณะ รายละเอียด
Simple Java มีโครงสร้างภาษาและไวยากรณ์ที่เป็นระบบ ช่วยให้สามารถเรียนรู้หลักการเขียนโปรแกรมได้ง่ายขึ้น
Object-Oriented สนับสนุนแนวคิดการเขียนโปรแกรมเชิงวัตถุ โดยใช้ Class และ Object เป็นองค์ประกอบสำคัญ
Platform Independent โปรแกรม Java สามารถทำงานบนระบบที่แตกต่างกันได้ หากระบบนั้นมีสภาพแวดล้อม Java ที่รองรับ
Robust มีระบบจัดการข้อผิดพลาด การตรวจสอบข้อมูล และการจัดการหน่วยความจำอัตโนมัติ
Secure Java มีคุณสมบัติและกลไกหลายอย่าง ที่ช่วยสนับสนุนการพัฒนาโปรแกรมอย่างปลอดภัย
Portable Bytecode สามารถนำไปทำงานบนระบบต่าง ๆ ที่รองรับ Java ได้
Multithreaded รองรับการทำงานหลาย Thread เพื่อให้โปรแกรมสามารถจัดการงานหลายส่วน ได้อย่างมีประสิทธิภาพ
Distributed สามารถนำไปใช้พัฒนาระบบที่มีการทำงาน ผ่านเครือข่ายและระบบแบบกระจายได้

แนวคิด Write Once, Run Anywhere

แนวคิด Write Once, Run Anywhere หรือ WORA เป็นแนวคิดสำคัญของ Java ซึ่งหมายถึงการเขียนโปรแกรมและ Compile ให้เป็น Bytecode จากนั้นสามารถนำ Bytecode ไปทำงานบนระบบปฏิบัติการที่แตกต่างกัน ได้ หากระบบนั้นมี Java Virtual Machine หรือ JVM ที่สามารถประมวลผล Bytecode ได้

แนวคิดดังกล่าวช่วยลดปัญหาการเขียนโปรแกรม แยกสำหรับแต่ละระบบปฏิบัติการ ทำให้ Java เหมาะกับระบบที่ต้องการ ความสามารถในการนำโปรแกรมไปใช้งาน ในสภาพแวดล้อมที่แตกต่างกัน

Java Virtual Machine

Java Virtual Machine หรือ JVM คือสภาพแวดล้อมที่ใช้สำหรับประมวลผล Java Bytecode โดย JVM ทำหน้าที่เป็นตัวกลาง ระหว่าง Bytecode ของ Java กับระบบปฏิบัติการและฮาร์ดแวร์ของเครื่อง

การมี JVM ทำให้โปรแกรม Java สามารถทำงานบนระบบปฏิบัติการที่แตกต่างกันได้ โดย JVM ของแต่ละระบบจะรับผิดชอบ การประมวลผล Bytecode ให้เหมาะสมกับระบบนั้น

ความสัมพันธ์ของ Java กับ JVM

โปรแกรม Java จะถูก Compile ให้เป็น Bytecode จากนั้น JVM จะทำหน้าที่ประมวลผล Bytecode เพื่อให้โปรแกรมสามารถทำงานบนระบบเป้าหมายได้

JDK, JRE และ JVM

ในการเรียนรู้และพัฒนาโปรแกรม Java ควรทำความเข้าใจคำว่า JDK, JRE และ JVM เนื่องจากแต่ละส่วนมีหน้าที่แตกต่างกัน และเกี่ยวข้องกับกระบวนการพัฒนา และการทำงานของโปรแกรม Java

องค์ประกอบ ชื่อเต็ม หน้าที่
JDK Java Development Kit ชุดเครื่องมือสำหรับพัฒนาโปรแกรม Java รวมเครื่องมือสำหรับ Compile และเครื่องมือที่จำเป็นสำหรับการพัฒนา
JRE Java Runtime Environment สภาพแวดล้อมสำหรับการเรียกใช้งานโปรแกรม Java
JVM Java Virtual Machine ทำหน้าที่ประมวลผล Java Bytecode

การเขียนโปรแกรมเชิงวัตถุ

Java เป็นภาษาที่สนับสนุน Object-Oriented Programming หรือ OOP ซึ่งเป็นแนวคิดในการออกแบบโปรแกรม โดยมององค์ประกอบของระบบเป็นวัตถุ หรือ Object ที่มีข้อมูลและพฤติกรรมของตนเอง

แนวคิด OOP ช่วยให้โปรแกรมมีโครงสร้างที่ชัดเจน สามารถแบ่งโปรแกรมออกเป็นส่วนต่าง ๆ ทำให้การพัฒนา การดูแลรักษา และการนำส่วนประกอบกลับมาใช้ซ้ำ ทำได้สะดวกมากขึ้น

Class

Class คือแม่แบบหรือโครงสร้าง ที่ใช้กำหนดข้อมูลและพฤติกรรม ของ Object โดยภายใน Class สามารถประกอบด้วยตัวแปร และ Method ต่าง ๆ

Object

Object คือสิ่งที่ถูกสร้างขึ้น จาก Class แต่ละ Object สามารถมีข้อมูลหรือสถานะที่แตกต่างกันได้ แม้ว่าจะสร้างมาจาก Class เดียวกัน

Data Member

Data Member คือสมาชิกของ Class ที่ใช้เก็บข้อมูลหรือสถานะของ Object เช่น ชื่อ อายุ รหัสนักเรียน คะแนน หรือข้อมูลอื่น ๆ ที่เกี่ยวข้องกับ Object

Method Member

Method Member คือสมาชิกของ Class ที่ใช้กำหนดพฤติกรรมหรือการทำงาน ของ Object เช่น การแสดงข้อมูล การคำนวณ หรือการเปลี่ยนแปลงสถานะ

หลักการสำคัญของ OOP

การเขียนโปรแกรมเชิงวัตถุมีหลักการสำคัญ ที่ช่วยในการออกแบบโครงสร้างโปรแกรม โดย Java สนับสนุนหลักการสำคัญ หลายประการ

หลักการ ความหมาย
Encapsulation การห่อหุ้มข้อมูลและการทำงาน ไว้ภายใน Class พร้อมควบคุมการเข้าถึงข้อมูล
Inheritance การสืบทอดคุณสมบัติ และพฤติกรรมจาก Class อื่น เพื่อนำไปพัฒนาต่อยอด
Polymorphism ความสามารถในการทำงาน ได้หลายรูปแบบ โดยการทำงานอาจแตกต่างกัน ตามชนิดของ Object
Abstraction การซ่อนรายละเอียด ที่ไม่จำเป็น และแสดงเฉพาะส่วนสำคัญ ที่ผู้ใช้งานจำเป็นต้องทราบ

State, Behavior และ Identity

Object สามารถอธิบายลักษณะสำคัญได้ ด้วยแนวคิด State, Behavior และ Identity ซึ่งช่วยให้เข้าใจองค์ประกอบของ Object ได้ชัดเจนมากขึ้น

องค์ประกอบ ความหมาย
State สถานะหรือข้อมูลของ Object ซึ่งสามารถเปลี่ยนแปลงได้ ตามการทำงานของโปรแกรม
Behavior พฤติกรรมหรือการทำงาน ที่ Object สามารถดำเนินการได้
Identity เอกลักษณ์ที่ใช้ระบุว่า Object แต่ละตัวเป็นคนละ Object

ข้อดีของภาษา Java

Java มีข้อดีหลายประการ จึงได้รับความนิยมในการเรียนการสอน และการพัฒนาซอฟต์แวร์

  • สามารถทำงานบนระบบปฏิบัติการที่แตกต่างกันได้ เมื่อมีสภาพแวดล้อม Java ที่รองรับ
  • สนับสนุนการเขียนโปรแกรมเชิงวัตถุ
  • มี Library และ API จำนวนมาก สำหรับช่วยในการพัฒนาโปรแกรม
  • มีระบบจัดการหน่วยความจำอัตโนมัติ
  • มีระบบ Exception Handling สำหรับจัดการข้อผิดพลาด
  • รองรับการพัฒนาโปรแกรมหลายรูปแบบ
  • เหมาะกับการพัฒนาโปรแกรม ที่มีโครงสร้างขนาดกลางและขนาดใหญ่
  • มีเครื่องมือสำหรับการพัฒนา การทดสอบ และการ Debug โปรแกรม

ข้อจำกัดของภาษา Java

แม้ว่า Java จะมีข้อดีหลายประการ แต่ก็มีข้อจำกัดบางอย่าง ที่ควรทำความเข้าใจก่อนนำไปใช้งาน

  • โปรแกรมต้องอาศัย JVM หรือสภาพแวดล้อม Java ที่เหมาะสม
  • การใช้หน่วยความจำอาจมากกว่า โปรแกรมที่พัฒนาเป็น Native Code ในบางลักษณะงาน
  • การเริ่มต้น JVM อาจมีค่าใช้จ่ายด้านเวลา ในบางสภาพแวดล้อม
  • โปรแกรมบางประเภท อาจต้องใช้ทรัพยากรระบบค่อนข้างมาก
  • ผู้เริ่มต้นอาจต้องใช้เวลา ทำความเข้าใจกับแนวคิด OOP และโครงสร้างของ Java

ลักษณะสำคัญของภาษา Java

Java เป็นภาษา Case Sensitive

Java เป็นภาษาที่แยกความแตกต่าง ระหว่างตัวอักษรพิมพ์ใหญ่ และตัวอักษรพิมพ์เล็ก ดังนั้นชื่อที่มีตัวพิมพ์แตกต่างกัน จะถือว่าเป็นชื่อที่แตกต่างกัน

ผู้เรียนจึงควรตรวจสอบการใช้ตัวพิมพ์ใหญ่ และตัวพิมพ์เล็กให้ถูกต้อง โดยเฉพาะชื่อ Class, Method และตัวแปร

Java ใช้เครื่องหมาย Semicolon

คำสั่งในภาษา Java โดยทั่วไปจะสิ้นสุดด้วยเครื่องหมาย Semicolon ซึ่งเขียนด้วยสัญลักษณ์ เครื่องหมายนี้ช่วยให้ Compiler สามารถแยกคำสั่งแต่ละคำสั่งออกจากกันได้

Java ใช้เครื่องหมายปีกกา

เครื่องหมายปีกกาใช้สำหรับกำหนดขอบเขต ของ Class, Method และโครงสร้างคำสั่ง ต่าง ๆ ทำให้สามารถแบ่งส่วนของโปรแกรม ได้อย่างชัดเจน

Source Code และ Bytecode

Source Code คือชุดคำสั่ง ที่โปรแกรมเมอร์เขียนขึ้น เพื่อสร้างโปรแกรม Java โดย Source Code ของ Java จะถูกจัดเก็บในไฟล์ที่มีนามสกุล .java

เมื่อ Source Code ผ่านกระบวนการ Compile โดย Java Compiler แล้ว จะถูกแปลงเป็น Bytecode ซึ่งโดยทั่วไปจะจัดเก็บในไฟล์ ที่มีนามสกุล .class

Bytecode ไม่ได้ผูกกับระบบปฏิบัติการใด โดยตรง แต่ JVM ของแต่ละระบบ จะทำหน้าที่นำ Bytecode ไปประมวลผลให้เหมาะสมกับระบบนั้น

ความสัมพันธ์ของไฟล์ Java

Source Code เป็นโปรแกรมที่นักพัฒนาเขียน จากนั้น Compiler จะแปลงเป็น Bytecode และ JVM จะนำ Bytecode ไปประมวลผล

โครงสร้างของ Class

Class เป็นองค์ประกอบพื้นฐานที่สำคัญ ของการเขียนโปรแกรม Java โดย Class ใช้สำหรับกำหนดโครงสร้าง ของข้อมูลและพฤติกรรมของ Object

ภายใน Class สามารถประกอบด้วย Data Member, Method Member, Constructor และสมาชิกอื่น ๆ ที่เกี่ยวข้องกับการทำงานของ Class

Data Member

ใช้เก็บข้อมูลหรือสถานะของ Object เช่น ข้อมูลชื่อ อายุ รหัส หรือข้อมูลอื่นที่จำเป็น

Method Member

ใช้กำหนดพฤติกรรม หรือการทำงานของ Object เช่น การคำนวณ การตรวจสอบข้อมูล หรือการแสดงผล

Constructor

Constructor คือส่วนที่ใช้สำหรับกำหนด การเริ่มต้นของ Object โดยจะทำงานเมื่อมีการสร้าง Object จาก Class

การตั้งชื่อ Identifier

Identifier คือชื่อที่ใช้ระบุองค์ประกอบต่าง ๆ ภายในโปรแกรม เช่น Class, Method, Variable และสมาชิกของ Class

การตั้งชื่อที่ดีควรสื่อความหมาย อ่านแล้วเข้าใจว่าชื่อนั้น ใช้สำหรับอะไร และควรปฏิบัติตามกฎการตั้งชื่อ ของภาษา Java

  • สามารถใช้ตัวอักษร ตัวเลข เครื่องหมายขีดล่าง และเครื่องหมาย $ ตามกฎของ Java
  • ไม่ควรขึ้นต้น Identifier ด้วยตัวเลข
  • ตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก ถือว่าแตกต่างกัน
  • ไม่สามารถใช้คำสงวนของ Java เป็น Identifier
  • ควรตั้งชื่อให้สื่อความหมาย และอ่านเข้าใจได้ง่าย

ระดับการเข้าถึงสมาชิกของ Class

Java มี Access Modifier สำหรับควบคุมการเข้าถึง Class, Method และ Data Member ซึ่งเป็นส่วนสำคัญของแนวคิด Encapsulation

Access Modifier ลักษณะการเข้าถึง
public สามารถเข้าถึงได้จากส่วนอื่น ตามขอบเขตที่ Java กำหนด
private สามารถเข้าถึงได้ภายใน Class ที่ประกาศสมาชิกนั้น
protected เกี่ยวข้องกับการเข้าถึงภายใน Package และ Class ที่สืบทอด ตามกฎของ Java
default หากไม่ระบุ Access Modifier การเข้าถึงจะอยู่ภายใน Package ตามกฎของ Java

คำสำคัญ final และ static

final

final เป็น Keyword ที่ใช้กำหนดว่า สมาชิกบางประเภทไม่ควรถูกเปลี่ยนแปลง หลังจากกำหนดค่าแล้ว โดยเฉพาะเมื่อใช้กับตัวแปร จะไม่สามารถกำหนดค่าใหม่ให้ตัวแปรนั้นได้

static

static ใช้กำหนดสมาชิกที่เป็นของ Class โดยตรงแทนที่จะเป็นของ Object แต่ละตัว สมาชิกที่เป็น static สามารถใช้งานร่วมกัน ในระดับ Class ได้

Method ในภาษา Java

Method คือส่วนของโปรแกรม ที่ใช้กำหนดการทำงาน หรือพฤติกรรมของ Class การแบ่งการทำงานออกเป็น Method ช่วยให้โปรแกรมมีโครงสร้าง และสามารถนำการทำงานบางส่วน กลับมาใช้ซ้ำได้

Method สามารถรับข้อมูลเข้ามา ผ่าน Parameter และสามารถส่งค่ากลับ ผ่าน Return Value ได้ หรือบาง Method อาจไม่ส่งค่ากลับ

Method main()

main() เป็น Method ที่มีความสำคัญ สำหรับโปรแกรม Java ที่ถูกเรียกใช้งาน ผ่าน Java launcher โดยเป็นจุดเริ่มต้นของการทำงาน ของโปรแกรมในรูปแบบดังกล่าว

เมื่อโปรแกรมเริ่มทำงาน ระบบจะเข้าสู่ Method main() จากนั้นคำสั่งต่าง ๆ ที่อยู่ในกระบวนการทำงาน จะถูกดำเนินการตามลำดับ

การแสดงผลทางหน้าจอ

Java มีคลาสและ Method สำหรับแสดงข้อมูลออกทาง Console ซึ่งเหมาะสำหรับการแสดงข้อความ ผลลัพธ์จากการประมวลผล หรือใช้ตรวจสอบการทำงานของโปรแกรม

การแสดงผลทาง Console เป็นพื้นฐานสำคัญสำหรับผู้เริ่มต้น เนื่องจากช่วยให้สามารถสังเกตผลลัพธ์ และตรวจสอบการทำงานของโปรแกรมได้ง่าย

Escape Sequence

Escape Sequence คือชุดอักขระพิเศษ ที่ใช้กำหนดรูปแบบการแสดงข้อความ โดยใช้เครื่องหมาย Backslash ร่วมกับตัวอักษรหรือสัญลักษณ์บางชนิด

Escape Sequence ความหมาย
\n ขึ้นบรรทัดใหม่
\t เว้นระยะในลักษณะ Tab
\r Carriage Return
\" ใช้แสดงเครื่องหมายคำพูด
\\ ใช้แสดงเครื่องหมาย Backslash

กระบวนการ Compile โปรแกรม Java

การ Compile คือกระบวนการแปลง Source Code ที่โปรแกรมเมอร์เขียน ให้อยู่ในรูปแบบ Bytecode ที่ JVM สามารถนำไปประมวลผลได้

Java Compiler เป็นเครื่องมือสำคัญ ในกระบวนการ Compile โดย Compiler จะตรวจสอบโครงสร้าง และไวยากรณ์ของโปรแกรม หากพบข้อผิดพลาด จะรายงานให้ผู้พัฒนาทราบ เพื่อแก้ไขก่อนนำโปรแกรมไปใช้งาน

ลำดับการทำงานของโปรแกรม Java

ขั้นตอน รายละเอียด
Source Code โปรแกรมเมอร์เขียนคำสั่ง Java และจัดเก็บเป็นไฟล์ .java
Compile Java Compiler ตรวจสอบ และแปลง Source Code ให้เป็น Bytecode
Bytecode ผลลัพธ์จากการ Compile โดยทั่วไปจัดเก็บเป็นไฟล์ .class
JVM JVM นำ Bytecode ไปประมวลผลบนระบบเป้าหมาย
ผลลัพธ์ โปรแกรมทำงานและแสดงผล ตามคำสั่งที่กำหนด

การจัดการหน่วยความจำ

Java มีระบบจัดการหน่วยความจำอัตโนมัติ โดยมี Garbage Collector ทำหน้าที่ตรวจสอบ Object ที่ไม่สามารถใช้งานต่อได้ และสามารถนำหน่วยความจำ ที่ไม่จำเป็นกลับมาใช้ใหม่

การจัดการหน่วยความจำอัตโนมัติ ช่วยลดภาระของโปรแกรมเมอร์ ในการจัดการหน่วยความจำด้วยตนเอง และช่วยลดโอกาสเกิดข้อผิดพลาด จากการจัดการหน่วยความจำบางประเภท

Library และ API ของ Java

Java มี Library และ API จำนวนมากที่ช่วยให้โปรแกรมเมอร์ สามารถนำความสามารถที่มีอยู่แล้ว มาใช้งานได้โดยไม่ต้องพัฒนาทุกส่วน ตั้งแต่เริ่มต้น

Library และ API มีบทบาทสำคัญ ในการพัฒนาโปรแกรม เนื่องจากช่วยลดเวลาในการพัฒนา และทำให้สามารถนำส่วนประกอบ ที่ผ่านการออกแบบและพัฒนาแล้ว มาใช้ในโปรแกรมได้

การนำภาษา Java ไปใช้งาน

Java สามารถนำไปประยุกต์ใช้ ในการพัฒนาซอฟต์แวร์ได้หลายประเภท เนื่องจากเป็นภาษาที่มีความสามารถ ครอบคลุมและมี Library สนับสนุนจำนวนมาก

  • โปรแกรม Desktop
  • Web Application
  • ระบบ Server
  • ระบบซอฟต์แวร์ระดับองค์กร
  • ระบบฐานข้อมูล
  • ระบบเครือข่าย
  • ระบบแบบกระจาย
  • ระบบประมวลผลข้อมูล
  • โปรแกรมที่ทำงานบน Cloud
  • ระบบซอฟต์แวร์สำหรับอุปกรณ์และแพลตฟอร์มต่าง ๆ ที่มีสภาพแวดล้อม Java รองรับ

เครื่องมือสำหรับพัฒนา Java

การพัฒนาโปรแกรม Java สามารถใช้เครื่องมือหลายประเภท โดยเครื่องมือแต่ละชนิด มีหน้าที่แตกต่างกัน

เครื่องมือ หน้าที่
JDK ชุดเครื่องมือสำหรับพัฒนาโปรแกรม Java
Java Compiler ใช้ Compile Source Code ให้เป็น Bytecode
JVM ใช้ประมวลผล Bytecode
Text Editor ใช้สำหรับเขียนและแก้ไข Source Code
IDE โปรแกรมที่รวมเครื่องมือสำหรับเขียน Compile, Run และ Debug ไว้ในสภาพแวดล้อมเดียวกัน

ความสำคัญของการเรียนรู้ภาษา Java

การเรียนรู้ภาษา Java ไม่ได้ช่วยเพียงแค่การเขียนโปรแกรม แต่ยังช่วยให้ผู้เรียนเข้าใจแนวคิด และกระบวนการพัฒนาซอฟต์แวร์ เช่น ตัวแปร ชนิดข้อมูล เงื่อนไข การทำซ้ำ Method Class Object และ OOP

ความรู้พื้นฐานเหล่านี้ สามารถนำไปต่อยอดในการเรียนรู้ การพัฒนาโปรแกรมในระดับที่สูงขึ้น รวมถึงการพัฒนาโปรแกรมที่เชื่อมต่อ กับฐานข้อมูล การสร้างระบบเครือข่าย การพัฒนา Web Application และการพัฒนาระบบซอฟต์แวร์ขนาดใหญ่

สิ่งที่ควรรู้หลังจากศึกษาบทนี้

  • เข้าใจความหมายของภาษา Java
  • เข้าใจประวัติและพัฒนาการของ Java
  • เข้าใจแนวคิด Write Once, Run Anywhere
  • เข้าใจหน้าที่ของ JVM
  • เข้าใจความแตกต่างระหว่าง JDK, JRE และ JVM
  • เข้าใจแนวคิด Object-Oriented Programming
  • เข้าใจความหมายของ Class และ Object
  • เข้าใจ Data Member และ Method Member
  • เข้าใจหลักการ Encapsulation
  • เข้าใจหลักการ Inheritance
  • เข้าใจหลักการ Polymorphism
  • เข้าใจหลักการ Abstraction
  • เข้าใจ State, Behavior และ Identity
  • เข้าใจ Source Code และ Bytecode
  • เข้าใจกระบวนการ Compile และการทำงานของ JVM
  • เข้าใจพื้นฐานการจัดการหน่วยความจำของ Java
  • รู้จัก Library, API และเครื่องมือสำหรับพัฒนา Java
  • เข้าใจลักษณะสำคัญของภาษา Java

สรุปความรู้เบื้องต้นภาษา Java

Java เป็นภาษาโปรแกรมระดับสูง ที่สนับสนุนการเขียนโปรแกรมเชิงวัตถุ และสามารถนำไปพัฒนาซอฟต์แวร์ ได้หลากหลายประเภท

จุดเด่นสำคัญของ Java คือความสามารถในการทำงานข้ามแพลตฟอร์ม ผ่านแนวคิด Write Once, Run Anywhere โดยใช้ JVM เป็นสภาพแวดล้อม สำหรับประมวลผล Bytecode

Java สนับสนุนแนวคิด OOP ซึ่งประกอบด้วย Class และ Object และมีหลักการสำคัญ ได้แก่ Encapsulation, Inheritance, Polymorphism และ Abstraction

Source Code ของ Java จะถูกจัดเก็บในไฟล์ .java และเมื่อผ่านการ Compile จะได้ Bytecode ซึ่งโดยทั่วไปจัดเก็บในไฟล์ .class

JDK เป็นชุดเครื่องมือสำหรับการพัฒนา โปรแกรม Java ส่วน JVM ทำหน้าที่ประมวลผล Bytecode และ Java ยังมี Library และ API จำนวนมากที่ช่วยในการพัฒนาโปรแกรม

การทำความเข้าใจพื้นฐานเหล่านี้ เป็นพื้นฐานสำคัญสำหรับการเรียนรู้ การเขียนโปรแกรม Java ในบทต่อไป

ความรู้สำคัญก่อนเข้าสู่บทถัดไป

ผู้เรียนควรเข้าใจว่า Java เป็นภาษาโปรแกรมที่สนับสนุน OOP สามารถทำงานข้ามแพลตฟอร์ม และมี JVM เป็นส่วนสำคัญ ในการประมวลผล Bytecode

นอกจากนี้ควรเข้าใจคำศัพท์พื้นฐาน เช่น Class, Object, Method, Data Member, Source Code, Bytecode, JDK, JRE และ JVM รวมถึงหลักการสำคัญของ OOP เพื่อใช้เป็นพื้นฐานสำหรับการเรียน การเขียนโปรแกรม Java ในบทต่อไป
