☕
รู้จักภาษา Java

เข้าใจความหมาย คุณสมบัติ และแนวทางการใช้งานภาษา Java

🧩
เข้าใจโครงสร้างโปรแกรม Java

สามารถอ่านและอธิบายโครงสร้างพื้นฐาน ของโปรแกรม Java ได้

📦
ใช้ตัวแปรและชนิดข้อมูล

สามารถประกาศตัวแปร และเลือกใช้ชนิดข้อมูลให้เหมาะสมกับงาน

➗
ใช้ตัวดำเนินการ

สามารถใช้ตัวดำเนินการทางคณิตศาสตร์ การเปรียบเทียบ และตรรกะได้

⌨️
รับข้อมูลและแสดงผล

สามารถรับข้อมูลจากผู้ใช้ และแสดงผลลัพธ์ของโปรแกรมได้

🔀
ใช้คำสั่งเงื่อนไข

สามารถใช้ if, else และคำสั่งเงื่อนไข เพื่อควบคุมการทำงานของโปรแกรมได้

🔁
ใช้ Loop

สามารถเขียนโปรแกรมที่ทำงานซ้ำ ด้วยคำสั่ง Loop ได้

📊
จัดการข้อมูลด้วย Array

สามารถจัดเก็บและประมวลผลข้อมูลหลายค่า ด้วย Array ได้

📝
จัดการข้อมูล String

สามารถสร้างและจัดการข้อมูลข้อความ ด้วย String ได้

⚙️
สร้างและเรียกใช้ Method

สามารถแบ่งโปรแกรมออกเป็นส่วนย่อย ด้วย Method เพื่อให้โค้ดเป็นระบบมากขึ้น

🏗️
เข้าใจแนวคิด OOP

เข้าใจแนวคิด Object-Oriented Programming และสามารถนำไปประยุกต์ใช้กับโปรแกรมได้

🛠️
จัดการข้อผิดพลาดของโปรแกรม

สามารถใช้ Exception Handling เพื่อจัดการข้อผิดพลาดของโปรแกรม

🖥️
สร้างโปรแกรม GUI

สามารถสร้างโปรแกรมแบบกราฟิก และออกแบบส่วนติดต่อผู้ใช้เบื้องต้นได้

🗄️
เชื่อมต่อฐานข้อมูล

เข้าใจการเชื่อมต่อ Java กับฐานข้อมูล และสามารถนำข้อมูลมาใช้งานได้
